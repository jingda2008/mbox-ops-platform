## 行为变化

员工先登记预约名额而不预绑物理桌，到店后核对1—20个真实开放桌次和人数，一次完整关联整组。新协议预约必须完成入座才可完成；历史无协议预约不补造关系。旧员工/native/guest桌号创建只保留原成功请求恢复，新意图会明确要求更新。Web与Android新版入口同步提供；恢复仍绑定原身份、原键和正文，不因404或丢回执生成新请求。协议不自动开台、合并顾客身份、收款退款或支持部分入座后追加。

Web销售读取公开DTO，保留负净额、小数数量、全部结果的渐进展示以及销售/利润独立权限。联系方式法定依据原合同3—500字与两张表对齐，不缩短既有请求。

新金融事实在一致父子行锁下由数据库私有序列赋序；批准补收捕获当时成功且可用的原退款集合。恢复沿原退款、授权消费、之后创建的原付款和本地确认账本验证，不以墙钟回拨破坏新事实的先后。旧字段保持NULL并沿保守旧证据核验，不给历史金额/因果顺序回填假事实。单笔回调与查单先锁桌次再锁订单，并再次确认归属；并发失败与生产错扣款分别判断。
