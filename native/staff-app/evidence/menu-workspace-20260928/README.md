# 点菜 / 加菜菜单工作区修复

更新时间：2026-09-28 11:09 CST

## 问题与修改

用户反馈原生点菜/加菜没有像网页版进入菜单。iPhone 现场复现时处于演练模式，原按钮可以跳转，但仅进入五个样例商品的简化列表；营业菜单另走一套界面，iOS 原为 sheet，两套体验不一致。

- 双端演练、营业入口改为全屏菜单，展示当前桌号；营业入口捕获原桌次，桌次变化关闭原入口。
- 分类快捷切换、菜品/编码模糊搜索、商品图、价格/规格说明、套餐选择、已选份数与独立购物车；缺图用中性图标，不伪造商品照片。
- 返回桌台保留原员工/原桌次草稿；保留既有售罄、库存、渠道、套餐选择、数量限制及原请求恢复路径。
- 营业商品仍读取已有 assisted-order-products 接口的 productSnapshot；图片仅接受现有公共媒体或菜单资源路径。
- 仅修改 native/staff-app 与文档；本次未修改网页/服务端/数据库，未提交、推送或发布。工作区另有此前变更，不属于本条修复。
