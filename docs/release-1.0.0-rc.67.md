# M-BOX 1.0.0-rc.67 现场履约质量与发布可靠性

## 业务内容

本版本完整保留`1.0.0-rc.66`已经独立复审通过的现场履约升级：

- 制作岗位一次点击完成，系统明确记录自动接单，不伪造人工开始时间。
- 配送岗位一次点击送达，服务端原子写入推定取货、确认送达、订单、任务和审计状态。
- 调酒师、厨房、服务员按有效岗位、工位和责任范围隔离队列，经理保留监督视图。
- 异常、超时、本人配送、候补配送和制作任务稳定排序，计时刷新不打乱当前操作。
- 个人入库、盘点、补做和存酒权限分别控制，直接授权不扩大为全部库存管理权。
- 正式预约、已到店、已入座历史和现场临客分离，临客不生成虚假预约。
- 普通任务、经理协助和AI执行总线均保留请求ID、有效岗位、工位和阶段审计。

## 发布流水线修复

- 标签CI仍只构建一次`linux/amd64`不可变镜像。
- 标签镜像包直接暂存在草稿GitHub预发布，不占用Actions临时制品额度。
- 完整标签CI成功后，发布任务重新下载同一镜像包并核验提交SHA、镜像摘要和压缩包校验和。
- 只有全部核验通过才把草稿转换为正式预发布；失败时不得进入阿里云部署。
- 阿里云继续执行数据库风险分级备份、零流量候选容器、健康检查、切流和自动回滚。

## 边界

- 本版本仍是验证环境候选，不代表真实打印机、真实支付/退款、物理POS或正式微信渠道验收完成。
- 现场弱网、真实员工设备和连续营业高峰仍需门店执行。
- 部署完成后必须补充线上提交SHA、镜像摘要、数据库备份、切流、观察和回滚证据。
