# M-BOX 1.0.0-rc.71 规范化现场验证版本

## 目标

本候选将规范化系统作为阿里云验证环境的唯一运行版本，并修复激活脚本仍调用旧整店运行态迁移入口的问题。规范化镜像只执行镜像内实际存在的迁移器，继续保留数据库备份、迁移摘要比对、候选容器健康检查、切流和自动回滚。

## 保留能力

- 员工在已开台桌位执行协助点单。
- 具备`order.gift`权限的人员按服务端岗位额度赠送现场商品并填写原因。
- 员工首页与岗位入口按权限精简，现场、任务、预约、出品及经营模块不再堆叠无关功能。
- 客户菜单恢复统一商品详情、直接加购、推荐比较、搜索、备注和购物车结算体验。
- 手机协助点单保留底部购物车，但商品列表预留安全滚动区，不遮挡商品加购按钮。
- 客户预约改为两步申请流程，只收集位置偏好，不开放具体桌位自选；门店确认后预约才正式生效。
- 预约成功后编号写入页面地址，刷新可以恢复；查询异常保留申请回执并引导客户避免重复提交。
- 桌台关台前检查未结订单，防止挂桌账漏收。
- 支付待处理意图增加单订单唯一约束，避免并发创建多个未完成支付意图。
- 生日、召回和日常运营权益继续留在客户运营权益域，不进入现场桌台操作。
- 质量、性能和启动证据不依赖GitHub Actions临时制品额度，校验后归档私有OSS。

## 发布边界

- 本版本用于阿里云开发验证环境，不代表商业生产验收完成。
- 星驿真实支付、退款、物理打印、弱网和连续真实营业班次仍需独立现场验收。
- 员工“立即结算”在真实支付通道联调完成前明确禁用；当前只允许挂桌账，并由关台门禁防止漏收。
- 支付与硬件未安装不阻止本验证版本部署，但相关能力不得标记为已完成。
