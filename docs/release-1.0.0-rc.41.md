# M-BOX 1.0.0-rc.41 取消出品说明改为选填

## 目标

减少店长和授权主管取消未送达出品时的输入步骤，现场选择明确取消原因后即可处理，不再强制填写情况说明。

## 本轮升级

- 出品履约中的“情况说明”改为“情况说明（选填）”。
- 结台前未送达商品核对中的情况说明同步改为选填。
- 未填写说明时，确认取消按钮保持可用。
- 服务端接口允许空说明，避免前端可操作但后台拒绝。
- 未填写时由系统生成明确的默认记录，并继续保存取消原因、操作人、岗位、时间和账务边界。
- 审计记录区分“员工主动填写”和“系统默认说明”。
- 选择“其他原因”但未填写说明时同样可以完成，系统会标记为未补充情况说明。

## 保持不变

- 只有领班、店长、运营负责人或老板等授权岗位可以取消出品。
- 已送达商品不能使用取消制作流程。
- 取消出品不会自动退款、改单、冲销或改变桌账。
- 已收款商品仍会提示有权限人员到收银工作台处理。

## 验证

- 新增空情况说明的服务端审计与幂等验证。
- 浏览器流程验证店长不填写说明即可取消未送达酒水。
- 213 条经营 TC 的商业发布门禁结论不因本轮操作简化而改变。
