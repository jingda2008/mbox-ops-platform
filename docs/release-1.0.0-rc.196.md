# M-BOX 1.0.0-rc.196

本版修复员工网页手机端“我的已制作”错版，并补齐库存盘点的复核工作流。历史订单和商品纵向排列，长单号可换行；商品处理入口保留。

库存页新增“盘点复核”，展示提交人、账面与实盘差异、当前账面及审核记录。有`inventory.count.approve`权限的同事可审核他人盘点或填写原因退回；仅有盘点权限的员工查看本人提交和处理结果。沿用服务端门店隔离、禁止自审和审批时库存快照检查；盘点后有库存流水时提示退回重盘。读取失败有重试入口，操作使用既有可恢复请求机制，不自动审批真实单据。

范围为员工网页与后台查询，schema仍为202；微信原生小程序包未改变，无需为本修复重复上传。截图中的设备登录失效属于独立会话校验，保留恢复登录入口与安全限制，未证明为误判。继承rc195回调代码及可选配置规则，不擅自启用服务号事件处理。

验证与发布证据见[修复记录](staff-history-stock-review-20260914.md)。正式交付须在最终检查、不可变CI、标准部署与健康身份核验后另记；真实手机及岗位操作验收不由本地测试替代。
