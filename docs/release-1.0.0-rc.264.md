# 1.0.0-rc.264 营业概览触控与财务仪表盘发布

财务仪表盘已由 PR #383 合并到 `edd6d059`：营业概览可改日期并显示总金额，费用分类增加人工费用。标签 `v1.0.0-rc.264` 已指向该提交，但当时 `package.json` 仍是 `1.0.0-rc.263`，发布检查因版本不一致失败。随后正式 CI 的 `normalized_browser` 在经营数据页报出手机触控不达标：日期输入「营业概览日期」和「前一天 / 后一天」高度为 36px，门禁要求宽和高均不少于 44px。

本候选做两件事：

1. 经营数据页营业概览的日期输入和前一天、后一天按钮，命中区域提高到至少 44×44 CSS 像素。颜色、圆角、字号和换日逻辑不变。
2. 发布元数据从 `1.0.0-rc.263` 对齐到 `1.0.0-rc.264`。

数据库仍是 schema 274，没有新迁移，不回填。本文件供合并后由发布人把标签 `v1.0.0-rc.264` 改指到包含本元数据的合并提交。本 PR 不打标签、不移动或删除已有标签、不合并、不部署。生产仍以已发布版本为准，回滚基线不变。
