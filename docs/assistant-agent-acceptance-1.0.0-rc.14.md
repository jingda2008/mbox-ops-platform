## 本轮证据

- 自动化：7 个 AI 相关专项测试文件，覆盖规划器、会话、API、运行配置、页面能力脱敏、确定性工作流和销售归属。
- 真实 Gemini：直接回答、候选澄清、连续会话和开台计划均使用 `gemini-3.5-flash` 验证。
- 浏览器：Tom 在隔离状态中确认五步计划后，L04 显示“待点单 0 分钟 · Tom”，页面返回“L04 临客已开台”。
- 视觉：390x844 视口面板宽 390px、无横向溢出；对话区内容完整可读。
