# M-Box 商业化视觉 V1

## 定位

客户页面负责品牌、商品吸引力和情绪价值；员工、店长页面负责判断速度和执行效率。视觉升级不能改变现有业务流程，也不能用装饰图片挤占经营信息。

## 本版内容

- 客户端统一为 `M-BOX LIVEHOUSE · 上海陆家嘴` 品牌头部。
- 桌台、服务专员和营业状态形成明确的第一屏信息。
- 商品照片面积增大，标签、价格和加入按钮层级加强。
- 加购按钮使用品牌红，微信支付使用微信绿，已收到和异常使用红色确认体系。
- 服务入口保持大按钮，生日、支付、投诉使用不同状态色。
- 店长和员工端只统一品牌与顶部识别，不增加背景图和装饰模块。
- 手机端隐藏重复桌台信息，保留固定购物车和支付入口。
- 增加 `超嗨部落母品牌 + M-Box 场所品牌` 层级：M-Box 始终为页面主体，超嗨通过小手、爱心和彩色短线分散露出。
- 超嗨部落名称、口号、标识、活动关键词和展示位置由运营后台配置，并纳入配置发布与回滚。

## 员工端视觉系统

- 使用深黑绿侧栏作为夜店运营框架，工作区保持浅灰白高密度画布，黄铜色仅用于品牌识别、选中态和关键分隔。
- 信息、成功、提醒、风险分别使用蓝、绿、琥珀、红，不用单一品牌色代替业务状态。
- 页面级区域和连续列表以边框、分隔线和浅底色建立层级；指标、待办和导航行不再形成卡片套卡片。
- 常规工作区不使用浮层阴影；阴影仅保留给确实脱离页面层级的登录框、抽屉和模态对话框。
- 员工端元数据正文不小于 11px，字段标签、顶栏辅助信息和紧凑状态不小于 10px。
- `.workstation-badge` 由运营控制台基础样式负责，不依赖 `CommerceView` 懒加载后的全局 CSS。

## 响应式规则

- 1024px 及以上使用完整侧栏。
- 768-1023px 使用 76px 常驻紧凑侧栏，保留图标、选中态和待办数量；不切换为遮罩抽屉。
- 767px 及以下使用抽屉导航，隐藏非关键工位标签，顶栏标题允许省略，所有工作区限制在视口宽度内。
- 620px 及以下的桌台工具栏、规则编辑和关联桌台改为单列或双列收缩，禁止依赖整页横向滚动。
- 不使用装饰渐变球、光斑或与经营信息无关的背景装饰。

当前四张商品图片仅用于验证布局，不能作为正式菜单素材。正式上线应拍摄实际出品，确保客人收到的商品与图片一致。

## 拍摄标准

- 使用同一机位、背景、灯光和后期标准。
- 酒水必须呈现实际杯型、装饰物和门店出品份量。
- 果盘、小食必须拍摄实际摆盘，不使用水果原料图或无关菜品图。
- 禁止使用水印、品牌不明的酒瓶、过度修图和虚构 AI 商品。
- 每张图片保留主体安全区，兼容手机方图和桌面横向裁切。

## 验收标准

- 390x844 手机无横向溢出，商品名称和价格完整显示。
- 六个服务入口和个性化提交在首屏内可操作。
- 加购后总金额和支付按钮立即反馈。
- 图片加载失败时仍显示商品名称、价格和可操作按钮。
- 弱网首屏优先加载文字和操作，图片不得阻断点单。
- 顾客端加购按钮为品牌红，微信支付按钮为微信绿，两者不得被员工端主按钮颜色覆盖。
- 768、900、1023px 下侧栏常驻且工作区无横向溢出；390x844 下员工顶栏、岗位首页和桌台工具栏无横向溢出。
- 首次进入员工端和访问商业工作台后，工位标识的尺寸、字体和显示状态保持一致。
