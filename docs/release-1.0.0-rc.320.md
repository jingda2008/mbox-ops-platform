# 门店后台与微信小程序 1.0.0-rc.320

员工从桌台的「协助点单 → 代客现金购票」选择场次、票档和桌数，核对会员手机号并请顾客确认条款。原购票单实收后出票赠分，有收款权限的员工可以从同一窗口登记；其他员工交收银按购票单号收款。每张票的退现和赠分按原单对账。

顾客自行购票使用微信。已有现金待收单继续显示金额和原单号。数据库迁移 375 区分员工代办和顾客在小程序授权的联系记录；历史交易凭证按原记录读取。

2026-11-27 门店生产完成部署，数据库 375，提交 3b05adec。实际顾客菜单返回 4 个票档，均无自助现金入口。微信开发者工具回执确认 1.0.0-rc.320 开发版上传成功，正式发布及现场现金交接仍待验。
