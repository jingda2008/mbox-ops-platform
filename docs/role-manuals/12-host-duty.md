# 李艳、Tom、Jerry、Tyke：门迎兼岗说明书

冷言志不承担门迎工作。门迎由李艳安排，Tom、Jerry、Tyke按当班负荷兼任。

## 有预约客人

1. 在预约页搜索姓名、客户编号或手机号掩码信息。
2. 核对人数、时间、区域、定金状态和接待备注。
3. 点击确认到店；有桌后选择安排入座。
4. 确认系统分配的主服务员和候补，面对面交接生日、忌口等信息。

注意：门迎不能根据客人截图自行确认定金到账，定金由三沐按支付事实确认。

## 临时到店

1. 先看可用桌和候补队列，不口头承诺尚未释放的桌台。
2. 有桌时录入人数、来源、销售归属和低消确认后开台。
3. 无桌时登记候补，系统按顺序、人数和区域推荐桌台。
4. 通知客人后锁桌，客人确认再安排入座；放弃时释放锁桌。

## 迟到预约

联系客人后填写预计到店时间和联系记录，使用“迟到保留”。超过规则或客人放弃时释放保留。不能只在微信群说“帮我留一下”。

## 案例：8人临客要求卡座

B01仍有客人，B02为预约保留。门迎不能让8人先坐到B02，也不能把预约状态直接改为空闲。应登记候补并说明预计等待；由李艳判断其他区域方案或联系预约客人，任何释放都有系统记录。

## 入座完成标准

桌台状态已占用、人数正确、主服务员明确、低消已说明、桌码有效、特殊需求完成交接。只把客人带到桌边但未交接，不算门迎完成。
