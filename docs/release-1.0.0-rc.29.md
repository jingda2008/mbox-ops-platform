# M-Box 1.0.0-rc.29 验证发布说明

## 本次修复

- 店长、主管、运营负责人和老板在具备`table.close`权限时，可从“订单与出品 -> 出品履约”直接取消未送达商品，不再要求出品岗先报告缺货或错品。
- 取消动作增加二次确认、原因分类和情况说明，操作者、商品、桌台、原因及结果进入审计记录。
- 取消只关闭当前出品任务，不自动修改原订单、桌账、支付或退款；系统根据收款状态提示店长转到收银工作台继续处理。
- 店长取消权限使用当班有效岗位集合判断，兼岗或临时岗位调整后仍按实时权限生效；普通服务员、调酒师和厨房岗位不能越权取消。

## 验证结果

- 李艳账号浏览器实测：建立精酿啤酒订单、进入出品履约、填写原因并取消，任务从履约队列消失且返回财务处理提示。
- Cloud Run修订`mbox-ops-validation-rc29-kdscancel`承载100%验证流量；云端李艳账号确认当前未完成出品正确显示取消入口，验收过程未修改现场订单。
- KDS权限与经理取消API测试通过；无权限岗位取消请求仍返回403。
- Vitest共114个测试文件、800项测试通过；Playwright共13项跨客户端和岗位流程测试通过。
- 213条经营TC基线仍为147条通过、50条未执行、16条阻塞；本版本仍为员工验证发布。
