# M-BOX微信小程序个人信息保存规则

内部规则版本：MBOX-RETENTION-20260914-V2<br>
拟生效日期：与正式隐私政策同步<br>
适用主体：上海超嗨文化传媒有限公司、M-BOX陆家嘴店

本规则用于支撑《M-BOX微信小程序隐私政策》中的保存期限说明。正式发布前，应由经营负责人确认期限和法律依据，并确保系统配置、清理任务、备份处置及人工流程能够实际执行。没有执行能力的期限不得对外承诺。

## 一、通用原则

1. 只在实现明确目的所需的最短期间保存个人信息。
2. 保存期限从相应业务目的结束之日开始计算；存在未完成支付、退款、投诉、诉讼、监管调查或依法保全时，可以暂停清除，并记录依据和结束条件。
3. 期限届满后，对可识别个人的信息执行删除、不可逆匿名化或受控密文清除。仅删除页面展示或本地缓存不等于完成服务端处置。
4. 备份中的数据按照备份轮换周期自然退出；恢复备份时必须重新执行已到期数据的清理，不得使已删除信息重新投入日常使用。
5. 法律法规规定更长期限的，从其规定；法定保留期内仅用于保存、审计、争议处理和履行法定义务。

## 二、保存期限基线

| 信息类别 | 业务目的结束时间 | 保存期限基线 | 到期处理 |
| --- | --- | --- | --- |
| 微信一次性登录凭证、手机号授权临时凭证 | 完成当次验证或凭证失效 | 不作业务长期保存 | 验证后立即丢弃，不写入日志 |
| 短期登录、预约及桌台会话令牌 | 会话到期、关桌或主动退出 | 至系统短期会话到期 | 删除令牌或使其不可继续使用 |
| 无订单的匿名购物车和临时操作标识 | 购物车失效或桌次结束 | 30日以内 | 删除或匿名化 |
| 微信OpenID等服务身份标识 | 会员或需识别身份的服务终止 | 终止后1年；交易依法需关联的部分按交易期限隔离保存 | 删除密文或不可逆匿名化；保留交易关联的最小内部编号 |
| 已验证会员手机号 | 用户停用手机号、注销会员且无未结事项 | 目的结束后30日 | 受控清除手机号密文，保留不含明文的处置和审计记录 |
| 活动报名手机号 | 活动结束、取消或退款完成且无争议 | 目的结束后180日 | 受控清除手机号密文，保留非敏感报名和财务记录 |
| 预约称呼和联系方式 | 预约完成、取消或退款完成且无争议 | 目的结束后180日 | 删除或去标识化联系方式 |
| 会员昵称、生日月日及到店偏好 | 用户清空、注销会员或信息连续2年未使用 | 满足任一条件后30日内 | 删除或匿名化；依法关联的交易记录除外 |
| 可能涉及健康的饮食说明 | 用户清空、相应服务结束或连续1年未使用 | 取最先到达的条件 | 优先删除，不进入营销画像 |
| 投诉、服务请求及处理记录 | 处理完毕且无后续争议 | 1年 | 删除自由文本中的个人信息或整体匿名化；依法需保存的证据除外 |
| 点歌、祝福语和自由文本备注 | 履行完成且无争议 | 90日 | 删除或匿名化自由文本 |
| 订阅通知授权及发送记录 | 授权失效、撤回或对应服务终止 | 终止后1年 | 删除收件标识，保留必要的授权或撤回证明 |
| 营销授权、拒绝和撤回证明 | 授权到期或撤回 | 3年 | 删除可直接联系信息，保留最小化的授权合规证明 |
| 商品、订单、支付、退款、优惠、积分、对账及售后交易记录 | 交易完成或售后结束 | 不少于3年；税务、支付或其他规则要求更长的从其规定 | 期限届满且无争议后删除、匿名化或归档限制使用 |
| 网络、安全、风控和异常日志 | 日志产生 | 180日 | 自动轮换删除；确认安全事件或争议所需部分转入受控保全 |
| 隐私权利请求及处理记录 | 请求办结 | 3年 | 删除身份材料，保留最小化处理证明 |

## 三、系统执行要求

1. `activity_registration_contact`采用“业务目的结束后180日”规则。
2. `verified_membership_phone`采用“业务目的结束后30日”规则。
3. 两类联系方式均须完成起草、独立审批、发布和定时处置配置，未发布规则时不得假定系统会自动清除。
4. 订单、支付、退款和审计记录不得因用户停用手机号而删除，但应解除不必要的明文联系方式关联。
5. 清理任务必须具备幂等、失败重试、执行审计、法律保全跳过和备份恢复后重新处置能力。
6. 每季度抽查到期数据、未执行清理、长期法律保全及异常读取；发现超期应立即限制使用并补做处置。

## 四、对外答复口径

对外隐私政策使用“最短必要期限+主要类别期限+法定例外”的表达。收到用户删除或注销请求时，应先核验身份和未结订单、退款、投诉，再分别处理联系方式、偏好、本地缓存和依法必须保存的交易记录，不得笼统答复“全部立即删除”或“任何信息都不能删除”。
