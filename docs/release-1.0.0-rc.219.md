# 1.0.0-rc.219 维护清单与财务保护函数兼容修复

旧版systemd将SSH登录的临时session scope列入unit-files，导致只读准备和正式切换之间清单摘要必然不同。本版只排除精确numeric/static临时会话行，原持久服务和启停状态仍按字节绑定，新增writer及状态变化仍拒绝。

rc.218原生跨迁移账号演练还发现：历史关桌保护definer保留旧owner，无法调用新维护者的私有补收校验。242将这一个既有函数统一至三个私有校验函数与准入表的共同维护owner，未知/不一致owner拒绝；原函数正文、固定search_path和关桌金额/权限校验不变，公共及运行角色不能直接执行。001—241及已发布产物保持原样，应用就绪要求242。

新增跨账号升级回归复现原权限错误，校验owner不一致时拒绝，并用真实受限LOGIN运行完整关桌补收、原款后到、合付、积分、推荐和财务复核正反例。完整CI、原生正常/向前恢复、真实生产RDS与OSS及公开路由验收仍需分别记录。生产首次升级继续计划维护，失败保持停写并向前修复；仅走正式deploy-release.sh。本说明不代表已部署、小程序上传或真实渠道/现场验收。
