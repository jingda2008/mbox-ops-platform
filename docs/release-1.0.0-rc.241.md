# 1.0.0-rc.241 收银复核读取恢复

营业中三沐账号打开收银复核时，收银列表请求超过网页8秒读取限时，页面显示“暂时没有接上收银数据”。生产应用、Caddy和数据库均正常；只读测量显示50条收银订单的首段SQL约9.6秒，另外8段查询均在数毫秒。执行计划中，历史关桌未提交付款的子查询在RLS下重复扫描历史付款表。

本版仅将该子查询里付款表的连接限定为按已选付款事实主键读取，避免优化器展开成全表扫描。生产同一批只读数据上，原查询9.664秒、候选查询2.480秒，50条原始订单结果逐字段相同；无资金写入。前端8秒限时、退款及补收判断均不改变。另将“原订单权益与归属恢复”卡片从通用两列布局改为占满内容宽度，手机不再挤入38像素图标列。

本地定向收银、关桌补收回归及完整工程检查见CI；正式标签CI、备份、OSS读回、生产切换后实时接口及现场账号验收仍须分别留证。本版不包含小程序源码变更。
