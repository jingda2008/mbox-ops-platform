# 1.0.0-rc.267 活动交付与经营仪表盘

合并此前未交付的活动与兴趣卡 v3 候选，并实现已确认的经营仪表盘与员工网页 V1.3。复用现有支付、退款审批、打印队列、费用台账和岗位权限，保持连续扫码、按份发号及一次取餐操作。

数据库由274迁移到282；经营报表新增活动购买归属和购买时冻结成本。历史未记录成本保持未知，不使用现价回填。净收按收退款发生日，经营收入按原购买日，二者明确分列。

前台改动包括顾客双端的加餐、卡申请、售卖时段说明与原请求查询。服务端和员工网页部署不等于微信或支付宝小程序正式发布。

本次用户明确暂不发布支付宝；保留对应源代码与本地编译验证，不上传、不提审、不发布。

完整范围、验收、旧代码覆盖核对和实际发布证据见 [本次交付台账](owner-dashboard-v13-implementation.md)，需求见 [V1.3](owner-dashboard-v13-requirements.md) 与 [活动v3](activity-card-v3-requirements.md)。正式发布前执行绑定本版的兼容保护、备份与恢复核查；真实支付、实际出纸和现场牌号演练保留独立验收。
