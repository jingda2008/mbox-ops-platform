# M-BOX 1.0.0-rc.59 客户搜索与开台推荐场景

## 本次范围

- 客户扫码点单后，无论位于今夜推荐、组合、酒水或小食，都能直接使用菜单搜索。
- 搜索覆盖商品名称、SKU、分类、规格、介绍和标签；金色搜索入口与高对比搜索框提高发现性。
- 临客开台增加可选同行场景：约会、朋友、兄弟、闺蜜、商务、庆祝。
- AI值班经理可从“L01两位约会开台”等自然语言中提取同一场景，并调用统一服务端开台工具执行。
- 同行场景只绑定本次桌次，与人数共同参与菜单推荐排序；快速选择继续补充节奏、口味和停留时间。
- 不选择同行场景仍可正常开台，旧桌次保持兼容。

## 数据边界

- 同行场景是本桌本次消费的运营上下文，不是永久客户身份标签。
- 场景随桌次运营快照保存，转台沿用同一桌次，翻台后新桌次不会读取上一桌场景。
- 历史快照保留用于经营分析和审计，不向下一桌客户暴露。
- 推荐仍先校验商品启用、库存可售、人数、成本毛利和履约状态；场景只影响合格候选的排序。

## 验证结果

- 代码检查、类型检查、Lint、小程序静态检查和生产构建通过。
- 135个测试文件、1037项自动化测试通过。
- 42项浏览器经营流程通过，覆盖客户点单、员工开台、移动端布局、预约、订单、支付与岗位权限。
- 430×932手机截图确认搜索入口、搜索框和六项同行场景均无横向溢出。

## 发布边界

本版本部署到阿里云验证环境。发布不修改已有订单、支付、退款、库存或预约状态，也不自动补写历史桌次的同行场景。发生异常时按镜像摘要回滚至`v1.0.0-rc.58`。
