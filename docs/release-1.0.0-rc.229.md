## 固定CI发现与兼容补验

首个候选ff8f4a9的CI35895561547中，数据库2700通过/14失败，原因是CI管理员名mbox令pgcrypto安装在mbox命名空间，受限LOGIN的默认路径不可见；生产pgcrypto位于public，不能将此错误误报为当前生产收款故障。应用查询和三处数据库触发器统一改用内建SHA256，受限测试固定pg_catalog搜索路径后15项通过，保留全部真实归属、政策和并发断言。此处取代早期“零迁移候选”描述；最终CI/在线兼容性/正式发布尚未完成，生产保持rc.228。
