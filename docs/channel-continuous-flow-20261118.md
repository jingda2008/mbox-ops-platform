# 周边店优惠：一页完成发券

适用已部署的rc300；员工刷新正式网页后使用，发布验证见[发布记录](release-1.0.0-rc.300.md)。

1. 营销进入“周边店合作”，选店长，点“复制这位店长上一批配置”；首次合作在“首次配置”登记，保存后自动选中。
2. 在“配置本次优惠”填写领取和使用时间，核对优惠、次数与佣金。点“核对配置，进入下一步”，看清摘要后点“确认生成待审批批次”。
3. 页面自动保留本批次和优惠号码。“配置检查与补齐”出现缺项时，点旁边按钮在本页补齐；员工权限仍由管理员授权，账户由财务独立复核。
4. 另一管理员用自己的账号打开同一页面，在“继续处理已有批次”选对应商家与优惠号码，点“核对并审批本批次”，核对开关、填写依据后确认。创建人不能自行审批。
5. 营销点“刷新本批审批状态”，确认后点“下载本批推广图”，微信人工发原图给对应店长。
6. 下载后自动展开“发送与合作跟进”，填“已人工发送”和说明，保存；自动关联本批次。对方仍可在官网自行下载。

**注意：**下载不等于已发送。断网提示结果未知时恢复原操作，不另建一批。刷新失败或本批次未查到时先核对，系统不会自动换成其他批次。额度、库存和时间在领取时实时校验；页面配置检查不预留。额度不足到“营业配置”调整，不能仅改图片日期。

日常不必重复进入首次配置或财务。到店绑定仍由服务员在实际桌台操作；佣金结算仍由财务和合作店长接力。本次升级不改变这些岗位职责，不自动给生产商家发券或授权。
