# Tom、Jerry、Tyke：服务员系统与工作说明书

## 责任区

- Tom：大厅休闲区、散客区、商务卡座区主责。
- Jerry：舞台互动区、社交嗨玩区主责。
- Tyke：全店第一候补，主责忙碌、暂停或超时后接管；同时可承担普通服务。

三人均可兼门迎和取送。门迎操作另见[门迎兼岗说明书](12-host-duty.md)。

## 首页先做什么

1. 看“我的任务”和红色/黄色风险。
2. 看责任桌台和待点单桌台。
3. 看已制作待取送商品。
4. 有投诉、身体不适、买单时，优先级高于普通加水。

## 服务任务标准

接单：表示本人承担责任。  
到桌：人已到客人面前并开始沟通。  
完成：水、柠檬、点单、买单等实际动作已完成，必要时客人已确认。

案例：客人点击“加水”。Tom接单后拿水到L01，面对客人后点到桌，倒水完成再点完成。不能在吧台接水时就点完成。

## 协助点单

1. 在订单/KDS选择正确桌台，进入全屏菜单。
2. 用图片向客人介绍商品，确认数量、口味、忌口和备注。
3. 打开购物车复核商品和总额。
4. 下单后选择客人扫码支付、扫客户付款码或由收银处理。
5. 收到明确支付成功信号后说明已完成；支付处理中不要催客人重复付。

## 客人情绪与主动服务

- 开心/互动：可介绍演出和点歌，给自然破冰机会。
- 听歌/安静：减少打扰，必要节点轻声询问。
- 微醺：主动补水，关注身体状态，不继续强推酒水。
- 庆祝：询问称呼、生日歌、礼物或合影需求，再走权益流程。

心情点击不是投诉，也不需要向客人播报“系统已记录”。员工应把它当作服务提示。

## 取送

KDS显示已制作 -> 核对桌号/品项/数量 -> 点击已取走 -> 送到正确客人 -> 点击已送达。发现错品不要送，立即报告错品并等待补做处置。

## 候补接管案例

Jerry正在处理投诉，I02又发起买单。Tyke收到候补任务后接单、到桌并说明“Jerry正在处理紧急事项，我来为您结账”，完成后在系统闭环。不能只口头说帮忙而不接管任务。
