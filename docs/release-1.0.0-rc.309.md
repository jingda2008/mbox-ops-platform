# 1.0.0-rc.309 会员整桌演出票

会员实付购票后逐桌出票赠分，后台沿用订桌记录确认桌号。旧桌单可经会员确认使用积分；错户冲正、改期和退菜可沿原票与原餐单追溯。个人退票可在原案分摊已抵菜款、核定门店承担金额，由会员确认，收银在原单收取应补金额后按原票退款。门店责任可单独办理。营业日报列示票款、餐饮现金、会员积分和门店承担。

后台数据库从 schema 322 升至 363，共41份迁移。门店资料、原支付渠道与岗位权限沿用既有配置。核对原收退款、逐票权益、重复回执及桌位占用的验收记录见[票务验收](member-table-tickets-acceptance-20261123.md)。小程序真机、真实渠道回单和现场交班凭证待补。发布版本与开售安排分别记录。
