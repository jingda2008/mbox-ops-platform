# 门店后台 1.0.0-rc.315

前一线上版本为 1.0.0-rc.314、schema 367。本候选包含门票购票会员识别、原票售后、适用桌区及桌号草稿，以及按原单积分版本计算补收和退款。指定桌号票档仍限草稿。门店如启用每 20 元积 1 分，由有权限的员工独立审批生效时间。

数据库升级到 372。按阿里云运营机的兼容边界发布流程，排空写入并验证备份与恢复证据后迁移。已恢复写入时若出现故障，停止写入、保全在途交易，使用兼容 372 的修复版本。值班经理与财务需按原案核对补菜款、原路退款、门店承担及积分流水。

后台、数据库与微信正式版分别发版。微信开发包为 `1.0.0-rc.314-ui.1`。详见[部署验证、交接与现场验收](wechat-rc314-ui1-deployment-prep-20261124.md)。
