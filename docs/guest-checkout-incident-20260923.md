## 修复

身份保存只更新原本允许更新的凭据字段，不再更新 `principal_id`。冲突更新必须匹配原主体及原外部身份 ID；不匹配则拒绝并回滚，避免把并发新身份误当成已保存成功。数据库授权、历史数据、小程序包和数据库 schema 均不需要调整。
