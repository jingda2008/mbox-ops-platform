# 微信推广券领取与我的优惠券展示修复

更新时间：2026-11-26 09:34 CST

## 修复范围

基于2026-11-26重新获取的主干 `6fd19ee0`（门店发布文档为rc317/schema372），使用独立工作区保留原工作区未提交改动。此处版本仅指核对过的代码及发布文档；本轮未登录微信版本管理平台核实客户手机正在使用的包。

确认的问题：推广领券按钮未采用主操作样式，且排在多段规则之后；个人“我的优惠券”只读取会员权益券，推广券需要另进“餐后推荐优惠”，容易误以为领取失败。未发现或声称修复某位客户真实券记录丢失，未修改会员归属或并户个案。

## 客户操作

微信扫码/长按推广图 → 点醒目的“立即领取优惠券” → “查看我的优惠券” → 在推广券卡片点“去点单使用” → 核对所选券和本桌（未确认桌号先扫桌码） → 确认后进入点单。

已经绑定但中断点单的券可从“继续本次点单”重新核对本桌后继续。服务器确认仍属于本桌才进入点单，不重新领取或增加额度。已兑现、过期、撤销的券保留状态查看入口，不当作新券使用。赠品仍按原实际赠送/出品流程处理；不会因为领券或打开点单页就扣库存。

## 具体改动

- 领取主按钮移到优惠名称/内容后、规则之前，深绿色底白字、至少52px高；领取后提供“查看我的优惠券”。新领取成功切回全部筛选，避免停在“已过期”等分类看不见新券。
- “我的优惠券”同时读取已有会员权益与推广券，直接展示名称、优惠、来源、适用商品、有效期、状态及点单入口。
- 两种券分别处理分页和读失败。一端失败不隐藏另一端，不把未读取/失败显示成“暂无”；页面重进自动刷新，换账号/迟到响应不带出原账号记录。
- 从我的优惠券携带所选券编号；核对本人券包，需要时读取后续分页，不能把同批另一张券替换成所选券。页面打开只读，不自动领取或绑定。
- 复用原扫码、确认桌号、原操作回执恢复与绑定接口。只有确认成功、账号/桌次未改变且页面仍有效才进入点单；断网不假成功，切后台或迟到响应不突然跳转。换桌后须重新核对。
- 不改服务端计价、会员并户、库存、退款或佣金规则；会员券与推广券同页展示不意味着允许叠加，最终以原报价规则为准。
