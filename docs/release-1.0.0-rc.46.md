# M-BOX 1.0.0-rc.46 菜单销售路径与成本基线

## 本版完成

1. 客户点单页新增“今夜特别推荐”销售路径：同屏比较三款适合方案，可选快速选择和摇一摇，也可直接浏览组合、酒水、小食与搜索。
2. 商品卡和详情统一展示图片、内容、单点合计、组合节省、预计出品时间与加购数量，移动端和平板保持单屏可用。
3. 新增81项V2/V3菜单商品、17个组合及完整图片资源；首次升级按SKU一次性导入并留下审计，后续管理员修改不会被重启覆盖。
4. 根据《MBOX定价与成本_完整版.xlsx》补齐鸡尾酒、瓶酒成本；工作簿缺项采用已核准保守成本上限，组合成本按组件自动汇总。
5. 组合下单在服务端展开为履约组件，客户账单仍只显示组合商品，出品、库存和绩效不再丢失组件信息或重复计算收入。
6. 新增推荐曝光、快速选择、摇一摇、详情、接受、升级和购物车放弃事件，为后续AI排序和经营分析提供数据闭环。

## 数据迁移

- 新增数据库迁移：`019_guest_recommendation_events.sql`。
- 新增菜单迁移：`runtime.menu_catalog_2026_07_27_v1_imported.v1`。
- 菜单迁移仅执行一次，按SKU更新或补充商品，保留既有商品ID与运营中的售罄、供应时间状态。
- 成本与商品来源见`config/menu-cost-basis-2026-07-27.json`和`config/menu-catalog-2026-07-27.json`。

## 发布验证

- 全量静态检查、972项单元/集成测试和生产构建。
- 29项Playwright客户、员工、预约、打印、KDS、损益和移动端流程。
- PostgreSQL迁移校验、强制RLS、规范化运营投影和容器构建。
- 阿里云候选容器必须在独立端口验证81项菜单、组合成本脱敏、真实员工登录和固定桌码客户入口后才能切流。

## 发布边界

本版仍为门店验证环境。线上支付仍为模拟模式，微信/星驿真实资金、退款、打印机和其他门店硬件尚未完成生产联调，不能标记为正式商业营业上线。
