# 兴趣卡专属菜品图片修复

## 事实和原因

2026-10-24 10:55 CST只读核验：WMLS普通兴趣卡已由实际运营人员开放，关联11款专属菜品，全部具有完整JPEG资产，普通菜单可见均为false，所属wmls分类可见。11款原图及列表缩略图逐项读取，10款各返回404；花枝丸复用普通菜单图片可正常读取。截图中如烟可显示，但当次线上原图也404，缓存只是可能解释，未经手机验证。

菜单已使用`customer_has_card_menu_item`支持兴趣卡；媒体读取却仅承认`guest_visible=true`的商品，导致合法持卡菜单与图片发布条件不一致。并非图片没有上传，也不是缺少企业微信绑定。

## 最小修复与边界

仅修改`MediaAssetRepository.publicBytes`的菜单资产引用条件：普通公开引用保持原逻辑，或至少一位有效持卡人按既有`customer_has_card_menu_item`规则可见该专属菜品。复用原有有效卡、社交条件及基础/卡专属可见时段，不另造一套资格规则。商品停用、渠道和分类隐藏继续拦截。

普通卡停止新申请不撤销已持卡权益，图片跟随既有规则；旧版卡仍按原项目状态及社交门槛。草稿、没有有效持卡人、停用关联、非专属关联不单独公开隐藏图片。

沿用原公开媒体URL，只返回图片字节；它不是个人持卡鉴权接口，不返回会员或权益记录，亦不授予菜单/下单访问。已经下载的图片不会被远程删除；新读取/条件缓存回源仍先检查可用引用。没有更改公开菜单图片既有缓存合同。

不改生产菜品可见设置、价格、供应时段、卡记录或员工权限，不重传图片。无数据库迁移；微信小程序源码不变，无需重新上传提审，支付宝不发布。
