# M-BOX Ops Platform 1.0.0-rc.5

发布日期：2026-07-17

## 北京时间统一

- 门店和预约配置固定使用 `Asia/Shanghai`，旧运行数据启动时自动校正并记录审计日志。
- 员工端顶部明确区分“营业日”和实时“北京时间”，桌面、平板和手机布局均可见。
- 预约、员工排班、歌手排班、授权有效期等本地时间输入统一按北京时间解析，不再依赖操作设备时区。
- 支付、库存、任务提醒、候位、配置记录和离线快照等时间统一按北京时间展示。
- 权益赠送的每日额度按北京时间自然日计算，修复北京时间零点附近跨日误判。

## 时间数据约定

- 数据库和接口继续以 ISO 8601 UTC 时间保存绝对时刻，避免排序、审计和跨服务调用产生歧义。
- 界面展示、营业规则和人工输入转换统一使用中国标准时间（UTC+8）。
- “营业日”仍由门店交班/日结流程推进，凌晨营业可继续归属前一营业日，不等同于北京时间日历日期。
