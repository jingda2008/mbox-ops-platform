# 1.0.0-rc.305 门店客诉、财务核对和出库成本

本版更新后台及员工网页，保留数据库 schema 320。本次授权范围内的生产核对均为只读，历史支付、成本及实物交付由原岗位凭证核实。

经理可以接手已结台的原客诉并在跟进后记录结果。财务核对显示原支付尝试金额和关联原单当前待收。延后结算仅对新销售出库记录锁定余额时的有效成本，未知成本留空；经营看板显示本期缺成本流水数。

本地隔离数据库 4776 项通过、1 项跳过，四项手机浏览器专项通过。正式部署身份、运行回读另记；真实资金、门店双手机、工位出品和采购原件继续按[岗位验收单](store-operations-field-acceptance-20261122.md)核验。
