# 1.0.0-rc.215 员工后台修复与后厨合批

本候选基于主线 `5c4bde7de5ed154ab3dd9227a64751dcc65293eb`，整合员工后台 SYS-287—303 的17项修复和60项文案处置、SYS-304—306 后厨合批工作台。用户于2026-09-21明确授权检查代码、提交、合并和部署。

## 行为与数据

- 后厨按商品、规格及两类备注保守合批；开做固定原份数，实际出锅释放设备，按桌分盘备齐后进入服务员取送。备齐和送达保持独立。
- 库存损耗超限或零免审批数量时提交另一人复核；审批时重查库存。原操作按员工保存并恢复，避免未知回执导致重复扣减。
- 会员七类规则的起草、审批、发布职责分开，通知发布保持三人分离；修复配置入口、输入精度、迟到响应、弹窗权限、报表状态和移动端布局。
- 审查新增修复：同品项已有旧流程开做份数时，直接备齐只选待制作份数；不得把旧在制份数计入新批次。隔离数据库先复现失败，再验证原份数、库存与重放。
- 新增迁移 `223_inventory_waste_review.sql`、`224_kitchen_production_batches.sql`，目标 schema `224`；门店配置保持 `2026.09.20-v25`。
- `MBOX_KITCHEN_BATCH_BOARD_ENABLED` 缺省为关闭；正式开关状态以部署配置和运行时读回为准。停止新增仍可恢复和处理原批次。

本地审查记录见 [发布检查记录](review-release-20260921.md)。来源工作区的139个文件逐一校验后复制至独立发布分支；保留原工作区和原始失败证据。源头的历史本地测试记录不冒充最终合并提交的CI证据。
