# 冷言志：副店长与调酒师系统和工作说明书

## 岗位定位

冷言志主要负责现场管理和主吧台调酒，不承担门迎工作。高峰时负责吧台产能、出品质量、缺货处置、服务升级和店长协同，不固定站在门口接待客人。

## 首页与功能

- 任务：处理分配给副店长的投诉、升级和现场协调任务。
- 订单/KDS：查看主吧台制作队列，开始制作、完成制作、报告缺货或质量问题。
- 库存/存酒：查看吧台原料、预警和存酒；可发起调整，审批按权限升级。
- 现场/预约：用于管理判断和店长协同，不作为门迎排队入口。
- 收银/权益/点歌：只处理副店长权限内的现场协调，不代替收银员或舞台运营。

## 调酒标准流程

1. 按KDS制作顺序和SLA处理，先处理已经超时或临近超时的单。
2. 点击“开始制作”后才开始占用制作责任。
3. 核对桌号、商品、数量、备注和过敏/口味信息。
4. 制作完成后点击“完成制作”，系统自动进入取送流程。
5. 与取送人当面核对，不把酒放在吧台后直接点送达。

## 缺货案例

制作招牌鸡尾酒时发现关键基酒不足：

1. 在对应KDS点“报告缺货”，不要先做错误替代品。
2. 判断是取消该项、换品还是补做；涉及客人选择时通知服务员到桌确认。
3. 库存异常同步给李艳和护古，保留原订单与异常记录。
4. 客人同意换品后走正式订单/授权流程，不口头改价。

## 管理案例

吧台同时积压8单，服务区又有普通加水呼叫。冷言志不离开吧台去门迎，也不盲目接所有任务；应让Tyke或当区服务员处理加水，自己调整制作顺序并向李艳报告预计恢复时间。

## 禁止事项

- 不承担排队迎宾、预约核销和门口固定接待。
- 不把“制作完成”点成“已送达”。
- 不因熟客要求跳过赠送、折扣或换品授权。
