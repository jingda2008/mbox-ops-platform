## 操作变化

- 同页顺序：选商家 → 配优惠 → 核对并生成 → 独立审批 → 下载发图 → 登记发送。创建商家/活动后自动带入，生成后保留准确批次；审批入口定位本批，下载后展开本批发送登记。
- 首次配置、财务与效果收起；缺活动入口、全店额度、推荐人联系人、官网账号或已核实账户时直接提示并定位相应办理区。配置检查不承诺额度或库存预留。
- 复制当前店长上一批规则，四个时间重新填写；金额、折扣、赠品只显示相关字段。审批、入口和推荐人开关回显真实状态，带旧状态快照防覆盖。
- 保留仅员工代领模式的推广图下载并明确提示顾客不能自行领取；两入口均关闭则阻止主流程下载。切换批次清空跟进草稿，快捷入口发现其他标签页未知操作时直接提供原回执恢复。
- 生成前核对摘要无写入，修改表单使摘要失效。独立审批、自审禁止、旧请求回执与实时权限校验保留。
- 跟进关联当前批次；下载不自动记发送，登记不会代发微信。刷新失败禁止主流程写入和下载；当前批次缺失不改选其他批次。相同登录会话重进保留选择，账号间隔离。
- 服务端按明确批次读取，确保旧批次及所属商家/活动不被最近100条窗口遗漏。佣金账户仅额外返回是否已核实，不暴露账户资料。
