# 1.0.0-rc.232 隐私读取回退与微信会员手机号登录

包含已合并的 PR #296（`39148473ad86686df00554f1f79209c02009290b`）。门店没有当前已发布隐私政策、也没有撤回记录时，公开接口返回仓库内 2026-09-14 送审正文，避免顾客页显示“隐私政策暂时无法读取”。已发布版本仍优先返回；已有撤回且没有当前发布时，不拿送审稿冒充现行政策。

schema 246 将隐私内容校验改为 PostgreSQL 内建 SHA256，不再调用未限定 schema 的 `pgcrypto` `digest()`。这不是员工独立发布，不写入生产隐私行，不代填批准人或员工身份。SYS-201 继续开放。

微信入会、找回和更换手机号声明 `phoneAuthorizationProvider=wechat`，避免超长或带 `+/=` 的微信凭证被当成支付宝拒绝。资料页在引导接口失败时仍单独读取已发布会员条款，不再误报“会员协议尚未发布”。支付宝隐私读取改为与微信相同的匿名请求。

最低 schema 246。服务端发布包只含员工网页、规范化服务和数据库，明确排除微信小程序。`miniprogram/` 的会员手机号与资料页条款修复必须在合并提交上另行上传微信开发者工具，不能用本标签的 `mbox-normalized-1.0.0-rc.232-*.tar.gz` 代替小程序上传。支付宝源码有匿名隐私读取调整，本说明不把它记成已上传。

经营 TC 登记仍按既有口径保持未执行/阻塞，不把本候选写成全部 P0/P1 已通过。标签 CI、不可变产物和生产切换另记；本文件建立时尚未部署。
