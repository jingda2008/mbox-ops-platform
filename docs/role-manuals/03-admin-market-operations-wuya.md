# 乌鸦：系统管理员与市场运营总监说明书

## 岗位目标

保证账号、配置、主数据和市场权益规则可用、可追溯。乌鸦不是收银员、服务员或退款审批人，不在营业中用管理员账号代替现场岗位操作。

## 系统功能

| 页面 | 可以做什么 | 不能做什么 |
|---|---|---|
| 现场 | 查看全店运行和异常 | 不代替服务员完成任务 |
| 预约 | 查看预约数据和来源效果 | 不确认定金到账 |
| 会员权益 | 配置权益、活动和通知规则 | 不绕过审批直接补偿客人 |
| 布局 | 维护桌台基础关系 | 不在客人已入座时随意改桌台 |
| 主数据 | 人员、班次、岗位、权限、商品、档口、区域 | 不删除仍被历史订单引用的数据 |
| 配置 | 保存草稿、发布、回滚和版本审计 | 不在高峰同时修改多项规则 |

## 新员工配置流程

1. 在主数据新增员工，使用稳定内部ID和真实姓名。
2. 分配主岗位、必要的附加岗位、责任区域和技能。
3. 配置班次、桌台主责/候补和经营授权。
4. 由本人用独立PIN登录，核对首页入口。
5. 用允许和禁止动作各测一次，确认服务端拒绝越权。

案例：新增临时服务员时，只给服务员岗位和负责区域，不因为他偶尔帮忙收银就永久授予收银权限。临时补位应通过当班岗位或明确授权完成。

## 配置发布流程

草稿修改 -> 填写原因 -> 复核差异 -> 发布版本 -> PC/平板/手机冒烟 -> 记录结果。  
错误版本使用回滚功能，不直接改数据库。

## 市场活动流程

1. 明确目标人群、权益成本、有效期和触达渠道。
2. 先预览可发人数、可触达人数和预计成本。
3. 护古或有权人员批准后发放。
4. 查看服务号/企微通知的排队、成功、失败和重试状态。
5. 活动后比较到店、核销、客单和投诉，不只看发送数量。
