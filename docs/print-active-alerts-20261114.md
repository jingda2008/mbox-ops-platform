# 打印故障网页主动提醒 — 2026-11-14

用户要求打印故障主动通知服务员或管理员，并明确选择员工网页／收银电脑。已同步最新主干 ee4d20aa／rc293／schema315，接入其持久故障认领与核验流程。本次修改员工网页和后台只读查询；现有打印桥上报失败即可触发网页提醒，无须为了这项提醒安装尚未经过现场验收的 1.0.12 候选包。

## 行为

- 员工登录后的所有页面，包括吧台、后厨专用屏，都挂载打印提醒。网页可见时每 10 秒读取，重新回到页面、恢复网络时立即读取。接口是 `GET /api/hardware/print-alerts`，禁用缓存。
- 失败及结果不确定的任务立即进入提醒；待领取或正在提交的任务，当前阶段等待超过 90 秒提示核对，不将等待直接判定为漏纸。未来调度的任务及刚领取的旧任务不误报。
- 持续至少 3 分钟的任务／持久故障在管理员页面突出显示；票据生成失败缺少首次失败时间，不用创建时间冒充故障持续时长。服务员无需打开设备管理，也能看到吧台／后厨匿名数量与核对说明；不会因此获得收银、票据明细、补打或设备配置权限。后台每次按当前员工权限重新裁剪。
- 声音必须由用户点击“开启打印提醒声音”激活，避免浏览器自动播放限制。开启时播放测试音；新异常立即提醒，同一未恢复异常每分钟重复提醒一次。“暂缓声音 5 分钟”不改变任务状态，新异常或首次升级提醒可打断暂缓。
- 处理说明引导先核对电子出品单和实体票，再检查纸卷、电源、连接、打印桥。结果不确定时不自动补打。任务转为完成／取消后实时更新；持久故障保留至人工核验，认领不代表已修复；已有成功补打任务时原失败记录保留，但不重复告警。
- 读取失败保留上次数量并明确标记“打印监测连接中断”，不能把网络故障显示成无异常。401/403清除旧数据并停止读取。切换账号或退出时停止旧轮询和声音。

## 边界

这是一项网页在线提醒，不是微信通知、离线推送或手机锁屏唤醒。页面隐藏、浏览器挂起、电脑休眠或关闭页面时无法保证及时提醒。建议收银电脑保持一个已登录页面可见，现场点击声音按钮确认扬声器可听见。

轮询增加每个可见授权页面约 6 次／分钟的只读查询；页面隐藏时停止。提醒按最多五个岗位/阶段聚合，不返回顾客、商品、桌号、金额或日志原文，避免重复票逐张刷屏。待处理历史任务会以汇总形式出现；同一问题可能同时显示任务异常与终端诊断，二者不合计为独立事故数；没有批量清除或重放历史订单。

“打印监测中”仅表示正在读取后台状态，不能证明打印机实际出纸。打印桥未检测到的缺纸、卡纸或Windows假成功，仍可能没有告警；1.0.12的结束调用修复仍须独立Windows与纸票验收。页面提醒被看见、声音被听见和人员实际处理也是不同证据。
