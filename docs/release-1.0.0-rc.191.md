# 1.0.0-rc.191 退款履约、退库与桌台状态

退款确认成功后，完全退款的未制作商品停止出品，原库存预留释放；延期结账无预留的直扣订单按原sale流水减已有return记录恢复；如旧链路已经扣库存，则按原扣减及已有退库记录返还剩余量，并记录审计。已开始制作、制作后失败、已做好和已送达不自动返还原料。部分金额不推算商品数量；退多收款不取消已足额结清的销售。

桌台增加已退款、含退款、已取消及已退/净收金额，真实新欠款仍优先显示。点单详情保留已退款取消商品及原制作送达历史。原金额、支付退款流水不删除。
