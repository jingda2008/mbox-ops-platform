# M-BOX 陆家嘴店正式人员与系统岗位

更新时间：2026-07-17

| 人员 | 系统岗位 | 现场兼岗 | 系统职责边界 |
|---|---|---|---|
| 陈方宇 | 老板 | 重大事项最终负责人 | 全店经营结果、重大资金与风险的最终授权 |
| 护古 | 运营负责人 | 经营执行与异常接管 | 全店运营、配置、审批、退款、库存与营业日执行责任 |
| 乌鸦 | 系统管理员、市场运营 | 无 | 系统配置、员工与排班、市场权益规则；不直接收款或处理桌边任务 |
| 挞挞 | 市场设计 | 无 | 查看预约、权益和演出信息；无收款、退款和运营配置权限 |
| 付淳羽 | 新媒体舞台运营 | 生日与点歌服务 | 舞台、点歌、生日服务和现场内容协同；无收款和退款权限 |
| 李艳 | 店长 | 门迎、服务、取送 | 全店值班、投诉、桌台、预约、出品协调、收款退款与库存审批 |
| 冷言志 | 调酒师、副店长 | 现场管理 | 值班协调、投诉、吧台出品和质量管理；不承担门迎职责，退款审批升级店长 |
| 三沐 | 收银员 | 无 | 核对账单、收款、物理POS报送和退款申请；不能审批退款 |
| Tom | 服务员 | 门迎、取送 | 休闲区、散客区、卡座服务，协助预约、点单、收款和出品取送 |
| Jerry | 服务员 | 门迎、取送 | 舞台互动区、社交区服务，协助预约、点单、收款和出品取送 |
| Tyke | 全店候补、服务员 | 门迎、取送 | 全店服务候补，主责繁忙或离岗时接管任务 |
| 申良良 | 后厨 | 冷菜、热厨 | 后厨制作、缺货和出品状态；无桌台收款权限 |
| 阿金 | 调音灯光 | 无 | 查看演出和点歌信息；无桌台、收款和经营配置权限 |

## 运行原则

- 李艳、Tom、Jerry、Tyke可在当班时执行门迎职责；冷言志不参与门迎排班。
- Tom主责休闲区、散客区和卡座；Jerry主责互动区和社交区；Tyke为全店第一候补。
- 冷言志主责主吧台出品和现场管理，申良良主责后厨；商品完成后由三名服务员取送，李艳可协调补位。
- 投诉先由冷言志或李艳处理，超权限事项升级护古，重大风险最终升级陈方宇。
- PIN属于个人身份凭证，不得共享；同一设备当日只验证一次门店口令，员工切换仍须输入本人PIN。
