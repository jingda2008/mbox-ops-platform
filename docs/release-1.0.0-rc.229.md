# 1.0.0-rc.229 发布后权限补验与环境前检

运行账号不能UPDATE不可变/受保护政策表，旧查询的行锁因此失败；部分旧集成测试使用管理员账号掩盖了错误。本版修复微信通知授权、预约变更确认、顾客转桌、成本更正、员工业绩与退款冲回、观察更正、联系保留策略及活动积分退款。保留现有身份、权限、幂等、准确政策外键、发送前复核和追加审计；使用可变父行/事务锁或原有限定函数串行化，不赋予营业账号新的数据权限。

发布前新增连续公网TLS/身份检查、远端Bash空数组兼容检查、清单哈希绑定的公开配置权限设置和正式镜像默认用户可读性验证。私密配置保持原权限，全部原发布门禁继续执行。

本地定向通知/预约受限PG15项、其余五组36项通过；全量源码检查通过。固定SHA完整CI、正式镜像及生产发布仍待验证，不能将准备状态当作已部署。数据库仍schema242，无新增迁移，不需要更新小程序包。
