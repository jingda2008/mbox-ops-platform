# M-BOX 界面定位与权限发布专项TC

版本：`1.0.0-rc.72`本地候选
日期：`2026-08-13`
范围：客户、预约、会员、员工与管理员Web页面；规范化员工权限、审批额度、数据范围、岗位入口与配置权威服务
原则：本专项不改写历史213条经营TC状态，发布后仍需手机、平板和管理PC实机复验。

| ACP-015 | P0 | 岗位旧`capabilities`数组仍含已撤销能力，但规范化权限关联已删除 | KDS、支付、退款、通知和调价只认规范化权限关联与有效个人例外；旧数组不得恢复已撤销权限 | PostgreSQL回归通过 |

## 人工验收要求

1. 乌鸦在管理PC、iPhone和安卓手机各发布一次无资金权限的测试变更，再恢复原值。
2. 每次记录员工、岗位、变更前后值、原因、北京时间、审计ID和页面截图。
3. 审批额度、数据范围和岗位入口在管理员控制中心验收；真实退款仍保留人工审批与审计，库存成本及设备连接参数仍在各自业务模块验收。
4. 任何提示错误、页面未自动定位、部分生效或最后管理员被锁死均判定P0/P1失败，不允许部署扩大验证。
5. 本地自动化通过只证明候选代码，不代表已部署；未核对云端提交SHA前不得将本专项标记为线上通过。
