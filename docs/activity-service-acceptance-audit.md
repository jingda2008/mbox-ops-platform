1. 用户已于 2026-10-22 21:50 CST 明确选择“先保留原审核，顾客一键申请（改动最少）”。顾客本人提交整份退订申请，进入原授权员工独立复核与原渠道执行；首期不增加自动审核退款。现有未使用、关联单、冻结及真实申请人检查已实现并测试，符合该确认口径；真实退款验收另验。

4. 顾客一份一份购买、逐份填人数和付款；每份有独立请求和结果。现场连续办理逐份恢复，不使用一个全成全败的大批量核销事务。
