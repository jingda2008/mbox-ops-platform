# M-Box 1.0.0-rc.24 验证发布说明

## 北京时间06:00自动切换营业日

- 营业日不按自然日零点切换：00:00至05:59继续归属前一营业日，06:00进入新营业日。
- 服务常驻时在06:00自动执行；Cloud Run休眠或停机期间错过切换时，下一次实例启动自动逐日补切。
- 自动切日会归档未完成服务、出品、桌次、候位、SOP和演出状态，原记录、未响应结果和审计事件完整保留。
- 新营业日优先启用已排班人员；没有次日排班时复制上一营业日有效班次，并留下班次连续性审计。
- 自动切换时间在 `运营规则 -> 桌台低消与提醒` 中配置，当前启用并固定为北京时间06:00。

## 财务控制

- 已由经理复核且账务快照未变化的交班，在06:00自动关账。
- 尚未提交、未复核或复核后账务变化的营业日只标记为待复核，不会伪造实收或跳过经理审批。
- 收银工作台支持按营业日查看历史结算；原营业日收银可以补交，经理复核后自动完成历史财务关账。
- 自动切日与财务关账分离，支付、退款、物理POS和差异继续归属原营业日。
