# 1.0.0-rc.213 四平台团购券核销

版本：`1.0.0-rc.213`。本版将收银端团购券核销纳入正式发布候选：员工可在「收银与退款」查询并核销**大众点评、美团、抖音、快手**券码。先按券码或扫码查询，确认后再向平台消耗，本地留下核销记录与尝试流水。不改支付宝/微信支付，也不扩展其它 OTA。

凭证与门店号只从受保护的服务器环境变量读取，不进入浏览器或仓库。`MBOX_VOUCHER_MODE` 为 `disabled` / `test` / `uat` / `production`。验证环境可用 `test` 模拟平台结果；缺一组平台变量则该平台显示「未配置」，不会误核销。本候选**不部署生产、不设置 `MBOX_VOUCHER_MODE=production`、不写入真实密钥**。

## 数据与门店配置

- 规范化迁移 `222_group_voucher_platform_verification.sql`：核销表增加平台码与平台回执字段，新增只追加的查询/核销尝试流水；OWNER / MANAGER / CASHIER 授予 `commercial.voucher.view` 与 `commercial.voucher.redeem`。
