# M-BOX 经营能力升级 1.0.0-rc.15

## 本次交付

| 需求 | 验证版能力 | 关键控制 |
| --- | --- | --- |
| 防重复点单 | 每次上单前核对；短时间相同购物车再次确认；每桌每分钟上限 | 客户端提醒与服务端指纹校验同时执行，幂等键继续兜底 |
| 货品码与采购 | 商品/原料绑定二维码或条形码；扫码识别；采购批次记录实时进价 | 码值唯一、整数品类拒绝小数、采购与库存流水同一事务 |
| 鸡尾酒损耗 | 现调鸡尾酒及其配方原料可配置合理损耗率 | 范围内自动入账并留审计，超限仍需第二人复核 |
| 双打印机 | 酒水与小吃按工作站/品类拆成独立打印任务 | 队列幂等、失败回执、尝试次数、设备桥接接口 |
| 预约资料 | 中文客户ID、手机/微信、预约卡图片、5秒岗位同步 | 联系方式至少一项，图片只展示脱敏联系信息 |
| 预约定金 | 总开关、默认规则、按区域定金/低消/抵扣率 | 客户提交前显示位置规则；预约保存规则金额快照 |
| 赠送权限 | 复用既有按岗位模板、单笔额度、日额度、审批权限 | 原因必填、申请与审批分离、完整留痕 |
| 客户标签 | 新客/老客/消费层级标签字典与会员标签维护 | 按权限显示，修改原因和操作者留痕 |
| 团购核销 | 平台、活动、券面额、结算额与桌次关联 | 券码只保存脱敏值和摘要，同一券不可重复核销 |
| 员工业绩 | 员工 × 商品品类的数量、订单、销售额、成本、毛利 | 依据桌次销售归属，不用下单账号冒充业绩归属 |
| 线上打赏 | 总开关、对象类型、预设金额、自定义金额上下限 | 默认关闭；支付通道与结算主体完成后才能正式开放 |

## 额外补强

- 所有新增写操作都有权限校验、幂等记录、操作原因和审计事件。
- 经营工具按岗位权限裁剪：收银只核销，库存岗位只操作库存，管理岗位才能发布规则和打印配置。
- 打印任务在订单真正提交或支付成功后生成，草稿订单不会提前出纸。
- 预约订单由预约页面每5秒刷新，同时受运营台2秒全局刷新驱动。
- 采购历史按批次保留，不用最新采购价覆盖旧批次。

## 外部联调边界

1. 物理打印需补充两台打印机的品牌、型号、IP/USB连接方式和厂商SDK，完成安卓或PC本地打印桥联调后才算真实出纸验收。
2. 线上打赏保持关闭，直到微信/星驿商户侧确认打赏交易场景、收款主体、退款与分账规则。
3. 预约定金的在线自动支付仍受支付服务商生产商户参数和KYC阻塞；当前可登记外部支付单并确认到账。
4. 213条经营TC的门店现场项与真实支付项不得由单元测试代替。
