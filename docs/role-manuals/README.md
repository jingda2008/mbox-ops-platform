# M-BOX 陆家嘴店岗位使用说明书

版本：1.0（验证环境）  
适用门店：M-BOX 陆家嘴店  
系统时间：北京时间（Asia/Shanghai）

## 使用顺序

1. 全员先阅读[通用登录与交接](00-common-login-and-handover.md)。
2. 每人阅读自己的岗位说明书；兼任门迎的人员还需阅读门迎兼岗说明。
3. 店长在第一次实操时按说明书中的案例逐项演练，不能只口头培训。
4. 每个动作必须使用本人账号。共享账号、代点完成、先做后补记录均视为未完成。

## 统一状态语言

| 系统状态 | 现场含义 | 不等于 |
|---|---|---|
| 已接单 | 已有人负责，马上执行 | 已经到桌或已经完成 |
| 已到桌 | 员工已经面对客人并开始处理 | 客人已经满意 |
| 已完成 | 员工动作完成，信息已记录 | 可以省略客户确认或交接 |
| 已制作 | 出品口制作完成 | 已送到客人桌上 |
| 已取走 | 取送人员已核对并拿走 | 已送达 |
| 已送达 | 客人已收到且桌号、品项核对无误 | 只放在传菜口或邻桌 |
| 支付处理中 | 已发起但未取得最终结果 | 支付成功 |
| 待对账 | 已有人工作业记录，等待凭证核对 | 渠道已确认到账 |

## 责任升级顺序

服务员或出品岗位无法完成时：本人说明原因 -> Tyke候补或当区同事 -> 李艳店长 -> 护古运营负责人 -> 陈方宇老板。  
吧台制作与现场管理问题：冷言志 -> 李艳 -> 护古。冷言志不承担门迎职责。  
系统配置和账号问题：乌鸦 -> 护古；支付事实不清时同时通知三沐和李艳。
