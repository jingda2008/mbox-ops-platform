## 业务边界与上线要求

本次负责人记录与全局责任排班独立：改变某一桌次负责人不会改写其他桌台排班，也不会自动授予收款、退款、出品等岗位能力。旧客户端在没有明确主责任安排时会收到拒绝，需使用新版员工 Web 开台或先安排主服务员。交接以授权操作人的明确指定为准，未新增接手者双人确认流程。

原有顾客页面的公开员工资料、自动任务派发及全局责任排班规则不是本次新增员工记录页面的授权范围；本次只开放员工身份下的服务记录，不开放给顾客。共享设备记录只证明授权账号进行了系统操作；现场没有登记的服务不能被补造为已知事实。实际操作历史以系统已有事件为来源，员工账号用于区分重名，交接姓名按当时快照展示。

上线需要先执行标准发布和schema270迁移，并独立验证现网个人员工登录、旧客户端缺少负责人时的提示、店长代开台/交接、翻台后的历史及门店实际服务流程。不得将本轮本地通过写成生产已生效或现场验收完成。
