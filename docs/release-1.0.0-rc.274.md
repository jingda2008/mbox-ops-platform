# 1.0.0-rc.274 桌次最低消费双模式

开台可选“提交时达标”或“先预收款，分次点单”。模式一按本次开台已生效商品加当前购物车的优惠前金额检查，未达标返回明确差额并保留商品及备注，达标后允许小额追加。模式二先预收足额再分次点单，每单按真实优惠后应付从已授权的原付款逐笔分摊。

差额收费固定关闭。商品不足只显示待处理，继续点单、累计权限内减免或保留财务待办；没有差额收款接口。用户自行核实经营适用依据。

余额不足时先补充共享预收款再提交，补充需付款人明确共享同意；不会把单笔代付悄悄转成共享充值。首版不提供单笔差额支付和真实合拆账，人员换桌及物理合坐继续使用既有独立桌次账，不迁移资金；整桌转桌保留同一桌次、门槛和原付款。

会员、优惠券和积分沿用原报价和消费扣减，达标用标准价快照。退菜按已批准份次扣减累计金额，拆退套餐按已确认的剩余商品原单价累计，退菜处理中不能提前退结余，原资金退款不恢复已消费的预收余额；多人共同支付的商品退回各原付款。单纯价格补偿保留有效商品累计。未消费余额走已有申请、异人复核、渠道执行及结果查询，重复通知不重复记账。门店原因无法履约由有权限员工记录减免，未自动代替经营决策。

新增迁移284–294。既有桌次默认order_gate、金额0；新模式只在新开台主动选择。分摊、减免、共享撤销及闭台待办保持不可改写的历史。物理闭台不清空旧余额，迟到付款及退款留在旧桌次；新桌次余额、累计及授权全新。
