# M-BOX 1.0.0-rc.63 桌面岗位导航收敛修复

## 问题修复

- 修复员工首页和手机底部已简化，但桌面左侧栏仍直接展示全部授权模块的问题。
- 店长李艳默认只显示首页、现场调度、任务、预约和收银与退款。
- 库存、会员、经营工具、设备、演出、布局和主数据等低频模块统一收进“更多功能”。

## 权限与操作边界

- 本次只收敛默认展示，不删除员工已经具备的合法权限。
- 指标卡、任务提示、语音命令和系统跳转仍可直接进入已授权的低频模块。
- 进入低频模块时“更多功能”自动展开；返回岗位常用模块后自动收起。
- 手机抽屉继续提供完整授权入口，并避免重复打开或入口位于可视区域外。

## 验证与发布边界

- 增加李艳桌面侧栏默认入口数量和低频模块展开回归。
- 岗位、移动端、订单/KDS、收银、经营工具、预约和打印专项浏览器流程通过。
- 本次没有数据库结构迁移，不修改订单、支付、退款、库存、预约和既有桌次数据。
- 当前真实微信、星驿支付、退款、物理POS和日结仍未完成生产联调。
- 213条经营TC仍有66条发布阻塞项，本版本只批准阿里云验证环境使用，不代表正式商业生产验收完成。

## 发布与回滚

- 发布目标：阿里云验证环境。
- 发布镜像必须来自主分支成功CI的不可变镜像资产。
- 候选容器通过就绪、提交SHA、镜像摘要和数据库投影一致性验证后才能切流。
- 异常时回滚至上一已验证容器。
