# 1.0.0-rc.211 后厨稳定性与微信会员二维码

本版合并后厨队列修复和独立工作树中的微信会员二维码预览。用户已授权检查、提交、合并和部署。功能与故障证据见 [后厨修复记录](kitchen-queue-fixes-20260919.md) 和 [微信二维码记录](wechat-member-qr-preview-20260919.md)。

后台刷新短暂失败保留过期快照并禁止确认；轮询合并在途请求，确认后的权威读取才解锁任务。待确认命令按员工隔离并使用原数量原幂等编号恢复，旧版没有员工归属的记录不自动迁移或重发。本人历史展示本人实际完成份数和姓名/时间，支持部分送达；修复提示自动滚动、取消失败的整表回滚和配送合单提前解锁。

微信会员二维码支持点开放大，关闭按钮/遮罩关闭，离页与重载收起，加载失败或缺码时不可打开。不改变会员身份与二维码内容。本版支付宝代码保持不变。SYS-253 修正旧的23页断言为当前25页，并保留逐页布局回归。

无新数据库迁移，目标 schema 221。发布前备份及 OSS 读回、候选健康、公共页面渲染及镜像/提交身份仍须通过；保留 rc.210 回滚基线。新历史字段为可选兼容字段，不改写历史审计、订单、库存或财务。

既有本地数据库2303项通过、浏览器15项通过；本次整合后复验及CI绑定最终候选提交。TC登记继承已有领域证据，不代表本次全部现场重新执行。
