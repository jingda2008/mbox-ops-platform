# M-BOX Ops Platform 1.0.0-rc.11

发布日期：2026-07-18

## 服务完成闭环

- 客户点击产生的服务任务，由当前责任员工或有权接管人按“接单、到桌、完成服务”执行。
- 员工点击完成后任务直接进入关闭终态，不再等待客户二次确认。
- 任务会立即从服务员任务队列、岗位首页待办数字、离线快照和客户服务进度中移除。
- 完成动作保留责任人、处理结果、完成时间、幂等键和`service.closed_by_staff.v1`审计事件。
- 投诉等高优先级任务仍只能由系统分配的责任人或有权接管人完成，普通服务员不能越权关闭。

## 兼容与再次服务

- 历史遗留的`completed`任务按已完成处理，不继续占用员工任务负荷。
- 旧客户端的客户反馈接口暂时保留兼容；新客户页面不再展示“已解决/仍未解决”确认按钮。
- 客人再次提出相同需求或投诉时建立并关联新的服务记录，原处理责任和耗时不被覆盖。
