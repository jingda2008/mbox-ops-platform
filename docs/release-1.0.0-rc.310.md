# 1.0.0-rc.310 整桌票与收银手机用分

包含[rc.309 的整桌演出票功能](release-1.0.0-rc.309.md)，数据库目标为 schema 363。rc.309 的主线浏览器复验发现原挂桌单用分表单控件高度仅21至27像素，生产后台当时仍为 rc.308。此版将展开项、三个输入框及两个按钮的触控高度统一到至少44像素，浏览器回归会展开表单再测量。

部署范围为门店后台、服务与数据库。票档暂不开售。微信正式版和现场收退款另行验收。
