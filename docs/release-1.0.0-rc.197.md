# M-BOX 1.0.0-rc.197

员工手机恢复前台后，若制作队列返回在线资格失效，客户端先通过既有认证心跳续期，再读取一次服务端操作权限。实际撤销、硬过期及重新核验后的拒绝仍保留，不在前端放行制作，不重放制作命令。正常队列不增加请求。

盘点退回后提供逐物料“重新盘点”入口，重新填写实测数量并提交新单。保留旧单退回结果、独立审批及库存变动保护；不自动清理或批准生产待办。
