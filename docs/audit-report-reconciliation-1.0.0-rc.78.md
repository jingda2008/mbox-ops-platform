## 报告中不应改变的结论

1. 模拟支付通过不等于真实支付已接通。
2. 自动化测试通过不等于员工、设备和真实晚高峰现场验收完成。
3. 真实退款、付款码、客户扫码、回调、查单、撤销、日终对账仍是P0外部门禁。
4. 打印机、物理POS、耳机、摄像头、微信小程序和公众号尚未形成现场证据。
5. 当前候选只能部署到阿里云开发验证环境，不能宣称商业支付正式上线。

## 新增风险与处理

- 同桌多人允许分别扫码和查看本桌已点，但相同篮子在45秒内再次提交需要明确确认；不同篮子和不同客户不会被合并。
- 客户与整桌每分钟限频分别默认5单和20单，整桌阈值不得低于客户阈值。
- 退款申请人不能审批自己的申请；店长可审批但不执行，收银可申请和执行但不审批，老板具备完整权限时仍受异人审批约束。
- 线上退款进入处理中后，员工页面没有手工标记成功入口；只有验签后的支付渠道回调可以确认成功。
- 现金和物理POS退款必须填写与原收款分离的退款凭证。

## 放行判断

工程候选通过全部自动化、真实PostgreSQL、浏览器、性能和部署后核对后，可作为无真实资金的员工验证版。真实支付、真实退款、硬件与岗位现场验收未完成前，不放行商业资金。
