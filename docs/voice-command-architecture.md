# M-Box 全岗位语音命令架构

## 1. 产品原则

语音命令是现有岗位页面的另一种入口，不是第二套业务系统。语音和手工操作必须共用：

- 当前员工签名会话、岗位和兼职角色；
- 现有权限、数据范围、审批额度和离线限制；
- 现有订单、桌台、支付、库存、会员、演出 API；
- 幂等键、北京时间营业日、审计日志和事件中心。

任何 AI 模型只能生成结构化“命令建议”，不能直接修改数据库。

## 2. 双模式交互

员工登录后可随时切换：

1. **岗位页面：** 处理复杂信息、异常、批量配置和最终结果。
2. **语音命令：** 说自然语言、查看系统理解、确认后执行或跳转。

切换员工、会话失效或重新登录时自动回到岗位页面，避免共享设备把上一个员工的待确认命令带给下一个员工。

## 3. 统一命令链路

```text
设备麦克风/文字输入
  -> 语音转写
  -> 意图和实体提取
  -> 确定性命令解析器
  -> 当前员工权限与数据范围校验
  -> 风险分级和参数完整性校验
  -> 人工确认/审批
  -> 现有业务 API
  -> 业务事件、审计和结果反馈
```

AI 输出必须经过结构化校验，例如：

```json
{
  "intent": "table.open",
  "entities": { "tableCode": "K2", "partySize": 4 },
  "missingFields": [],
  "confidence": 0.96
}
```

系统根据 `intent` 重新查找桌台、权限和实时状态，不能相信 AI 返回的权限结论或金额。

## 4. 风险分级

| 等级 | 示例 | 处理方式 |
| --- | --- | --- |
| L0 查询/导航 | 查看我的任务、今晚谁演出、打开库存 | 可直接展示结果或打开有权页面 |
| L1 低风险操作 | 接单、到桌、K2 开台、标记制作完成 | 显示对象与影响，一次确认后调用原 API |
| L2 经营/资金操作 | 转桌、结台、赠送、折扣、排班发布、退款 | 明确复述金额/对象/原因，二次确认；超限进入原审批链 |
| L3 安全配置 | 修改 PIN、权限、支付密钥、删除审计、批量改价 | 不允许纯语音直接完成，只能打开受控管理页面 |

## 5. 各岗位优先命令

| 岗位 | 第一批高频命令 |
| --- | --- |
| 老板/运营负责人 | 查看经营风险、待审批、异常账务、今晚经营摘要 |
| 系统管理员 | 查看健康状态、失败事件、配置版本、人员与权限 |
| 店长/副店长 | 开台、转桌、替补调度、投诉接管、排班与演出调整 |
| 服务员/门迎/传菜 | 开台、查看责任桌、接单、到桌、完成、暂未点单、协助点单 |
| 调酒师/厨房 | 查看待制作、开始制作、缺货、制作完成、呼叫取送 |
| 收银员 | 查看待收款、生成支付码、扫付款码、POS 报送、发起退款申请 |
| 舞台/灯光 | 查看当前和下一场、歌手到场、演出开始/结束、异常上报 |

兼职员工的命令能力取当班有效角色权限并集，但每条命令仍按数据范围和审批额度单独校验。

## 6. 防错规则

- 桌号、人名、金额或目标不唯一时必须追问，禁止猜测。
- 低置信度转写只显示文字，不生成可执行确认按钮。
- 确认卡必须显示命令对象、当前状态、执行影响和操作者。
- 确认卡超时或业务修订号变化后失效，执行前重新校验。
- 所有写命令使用幂等键，重复说、重复点击和网络重试不得重复执行。
- 离线时沿用现有限制：只开放已经支持离线队列的服务任务动作。
- 语音转写失败时保留文字输入；语音服务不可用不能影响岗位页面。
- 设备只申请使用期间的麦克风权限，系统不保存原始录音；如未来需要留存必须单独取得员工授权并配置留存期限。

## 7. 落地阶段

### 阶段 A：安全入口（已完成）

- 登录后双模式切换；
- 浏览器语音转写和文字兜底；
- 角色专属常用命令；
- 权限过滤、命令确认、返回原岗位页面；
- 桌面、平板和手机响应式布局。

### 阶段 B：确定性高频操作

先接入 20 个不需要大模型的高频命令，包括开台、查看任务、接单、到桌、完成、KDS 制作状态、桌台查询和演出查询。每个命令直接复用现有 API，并建立独立 TC。

### 阶段 C：AI 意图理解

引入云端语音识别和大模型结构化解析，处理口语、同义词和连续对话。模型只负责理解，不负责权限、金额计算、状态判断和写库。

### 阶段 D：耳机与主动助手

事件中心把桌台超时、出品超时、投诉和替补调度转成耳机播报；员工可语音回应“收到”“我去”“转给 Tyke”。需要控制播报频次、安静时段和优先级，避免信息疲劳。

## 8. 商业化验收指标

- 命令理解正确率按岗位和意图分别统计，不使用单一平均值掩盖高风险错误；
- 高风险误执行为零，越权执行为零，重复写入为零；
- 高频操作从进入页面到完成的中位点击数不超过 2 次；
- 语音不可用时 5 秒内可切回岗位页面；
- 每条命令可追溯原话文本、解析结果、确认人、审批人、API 结果和业务事件；
- 300 人营业压力场景下，语音服务降级不得影响点单、KDS、支付和服务任务主链路。
