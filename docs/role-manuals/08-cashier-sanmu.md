# 三沐：收银员系统与工作说明书

## 岗位目标

保证每一笔收款、退款、物理POS报送和日结都有真实凭证。系统状态必须服从支付渠道事实，不凭口头确认。

## 收银功能

| 功能 | 使用场景 | 关键检查 |
|---|---|---|
| 待收款桌账 | 客人准备买单 | 桌号、订单、优惠、已付和应付 |
| 支付二维码 | 服务员协助点单后让客人扫码 | 金额和桌次一致 |
| 扫客户付款码 | 客人出示微信付款码 | 扫码前再次口头确认金额 |
| 物理POS报送 | 系统不能直连的POS已完成收款 | POS流水号、小票、金额、渠道 |
| 拆分收款 | 多人分付或多渠道付款 | 每部分金额合计等于应收 |
| 退款申请 | 退具体商品或金额 | 原支付、商品、数量、原因 |
| 日结 | 关店前对账 | 系统、微信、POS、现金、退款一致 |

## 物理POS案例

客人用实体POS支付¥500：三沐在系统选择对应桌账和“报送POS”，录入POS交易流水号及小票编号。此时状态是待对账，不得写成渠道已确认。关店前根据POS账单复核。

## 部分退款案例

客人退一杯未制作的¥88鸡尾酒：选择原支付和原订单商品，数量1，填写原因，提交审批。不能只输入¥88而不关联商品；批准后按渠道完成退款并登记退款流水。

## 支付未知结果

页面超时、客人截图或服务员说“应该付了”都不是成功证据。先查单，禁止重复收款。确需使用现金或物理POS切换渠道时，要保留原支付意图和原因。
