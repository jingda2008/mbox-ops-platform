# M-BOX 1.0.0-rc.64 岗位高频入口可配置升级

## 升级目标

- 所有岗位继续默认只展示少量高频入口，避免现场操作页面被低频功能占满。
- 管理员可以按岗位选择并排序1至4个高频入口。
- 多岗位或特殊员工可以设置个人入口覆盖；未设置时自动跟随岗位。
- “更多功能”继续保留本人全部合法权限，不因界面收敛删除业务能力。

## 配置入口

- `主数据 → 岗位/高频入口 → 岗位高频入口`：配置岗位默认值，保存到配置草稿，发布后统一生效。
- `主数据 → 人员 → 岗位、权限与入口 → 个人高频入口`：设置员工个人覆盖，保存后立即生效。
- 已选入口支持前移、后移和恢复默认；桌面侧栏、手机底部和岗位首页使用同一顺序。

## 权限与审计

- 只能选择该岗位或员工当前有权使用的模块。
- 权限或兼任岗位变化后，系统自动剔除已经失效的高频入口。
- 岗位默认值随配置版本发布、回滚；员工个人覆盖写入员工资料变更审计。
- 个人覆盖优先于岗位默认，多岗位员工未设置个人覆盖时按岗位默认顺序合并，最多显示4项。
