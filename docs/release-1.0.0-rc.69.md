# M-BOX 1.0.0-rc.69 协助点单与现场商品赠送恢复

## 目标

本候选恢复规范化员工工作台中已开台桌位的协助点单与现场商品赠送，并明确区分现场商品赠送和客户运营权益。会员生日、召回和日常运营权益不进入现场桌台操作。

## 业务流程

- 员工在现场工作台选择已开台桌位后，可进入桌号锁定的全屏协助点单页面。
- 协助点单支持商品搜索、分类、数量、出品备注、挂桌账和立即结算。
- 具备`order.gift`权限的员工可赠送现场商品；系统按当前岗位额度校验，并要求填写赠送原因。
- 赠送授权来源由服务端解析，客户端不能指定或伪造额度来源。
- 商品赠送生成正常订单、库存消耗、出品任务、审计事件和消息事件，但应付金额为零。
- 客户运营权益继续由独立权益接口负责发放、预约和核销，不在现场桌台操作中展示。

## 数据库

- 新增规范化迁移`036_pricing_authorization_source_reuse.sql`。
- 客户权益仍保持同一桌次一次性消费约束。
- 员工岗位额度可用于同一桌次的多笔独立赠送订单，每一笔仍重新校验在职状态、权限、额度、币种和订单金额。

## 验证

- API、权限、审计和前端定向测试通过。
- 规范化移动端浏览器流程通过，包括李艳登录、选择W01、协助点单和商品赠送。
- 规范化PostgreSQL全套测试通过，包括迁移036和并发授权约束。
- PR提交级数据库、浏览器、性能、质量和最终验证门禁通过后方可合并。

- 本版本用于阿里云开发验证环境，不代表商业生产验收完成。
- 星驿真实支付、退款、物理打印、弱网和连续真实营业班次仍需独立现场验收。
- 支付与硬件未安装不阻止本验证版本部署，但相关能力不得标记为已完成。
