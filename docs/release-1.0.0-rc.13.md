# M-BOX Ops Platform 1.0.0-rc.13

发布日期：2026-07-18

## 服务员工桌台操作

- 服务员、区域候补、服务专员和领班在负责区域内可直接开台、转桌、加桌、合台、拆回及结台翻台。
- 门迎可直接开台接客；开台权限从预约管理中拆分为独立的“开台接客”，不再要求服务员拥有完整预约管理权限。
- 系统按员工的主岗位、兼职岗位和个人附加权限计算实际能力，不再只读取主岗位。
- 客人离店后，服务员工可从现场桌台一键发起结台；成功后桌台立即恢复可用，客户无需确认。

## 风险控制

- 未支付商品、未完成出品、处理中退款、锁定权益、进行中点歌或未拆回桌组会阻止结台，并返回具体原因。
- 低消未达标时，服务员工不能直接结台；只有店长、运营负责人或老板填写原因后可以豁免。
- 服务岗位继续受负责区域限制，不会看到或操作无责任范围的桌台。
- 开台、转桌、桌组操作和结台均写入操作人、桌次、时间与原因审计记录。

## 配置兼容

- 线上已有的内置岗位配置会通过一次性迁移补齐基础桌台权限。
- 迁移采用岗位能力指纹判断，不扩展自定义岗位，也不覆盖管理员之后主动撤销的权限。
- 后台岗位配置新增“开台接客”选项，所有权限仍可按门店实际人员调整。
