# M-BOX 1.0.0-rc.200

盘点复核新增勾选、全选当前页、选择可通过/需重盘单据、批量通过及统一原因批量退回。只处理操作者本次明确选中的当前页单据；翻页、刷新、切换账号或列表状态清空选择，避免处理未看到的盘点。

每单继续调用原审批接口，独立权限、禁止自审、库存变化校验、事务和审计不变。批次一次确认，逐单列出成功及未完成结果；一单冲突不会阻止其他单据，网络未确认时重试沿用该单原请求。已完成审核后的汇总读取失败独立提示。

没有批准、退回或重盘任何生产单据。历史500/330ml包装冲突继续待门店核对；过期盘点可批量退回，不能强行通过。发布仅员工网页交互变更，无数据库迁移，schema203不变。既有数量售后、支付和服务号配置须保留。
