# M-Box 1.0.0-rc.25 验证发布说明

## 性能修复

- 员工工作台与其他大体积JSON响应启用gzip压缩；云端店长快照实际传输约92KB，不再重复传输接近1MB的明文JSON。
- 员工轮询快照只携带全部实时任务和有限近期历史；完整经营、任务、审计和未响应记录继续保存在数据库，不做删除。
- 每秒运营调度先在只读快照上判断是否有营业日、SOP、出品或任务升级需要处理；空闲时不再获取整店聚合写锁。
- SOP外部动作、客户通知和在线员工清理增加只读预判；没有到期工作时不进入写事务。

## 云端实测

- 修复前完整工作台服务端耗时约0.61至0.76秒，响应约995KB；修复后服务端耗时0.18秒，压缩响应约93KB。
- 修复前任务与心跳写操作常见约2.0至2.5秒；修复后任务写操作约1.1至1.5秒。
- 剩余写入延迟来自验证环境的Cloud SQL `db-f1-micro`，以及当前单门店聚合状态每次写入需要更新完整JSONB；正式商业化前需要升级数据库规格并逐步拆分高频经营表。
- Cloud Run修订：`mbox-ops-validation-rc25-speed`，已承载100%验证流量；`mbox-ops-validation-rc24-businessday2`保留0%流量用于回退。
