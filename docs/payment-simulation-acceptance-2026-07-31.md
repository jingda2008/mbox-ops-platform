## 新增异常验证

1. 验签通过不等于业务可信。金额、币种、商户或支付意图任一不匹配，系统均拒绝入账。
2. 同一成功通知并发提交20次，只保留一条支付通知和一次成功状态。
3. 支付成功后到达的 `processing` 或 `failed` 通知被拒绝，成功状态不会回滚。
4. 被拒绝的异常通知不会写入支付通知列表，也不会填入渠道交易号或支付时间。

## 正式支付放行条件

以下证据齐全后，才可把对应生产TC从“阻塞”改为“通过”：

1. 星驿UAT或生产商户参数、签名公钥、回调白名单和HTTPS域名配置完成。
2. 客户扫码、员工扫码、付款码三条真实小额支付各至少成功一次。
3. 超时查单、重复回调、错误金额/商户通知在真实通道下验证。
4. 商品级部分退款、全额退款、失败重试和重复退款验证到账。
5. 下载渠道账单，与系统流水、实体POS和现金日结逐笔对账。
6. 保存脱敏请求ID、渠道交易号、退款号、截图、操作者和审批人证据。
