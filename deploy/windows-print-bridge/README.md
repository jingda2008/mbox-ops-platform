该服务安装在门店 Windows 电脑，开机自动运行，不使用员工账号，也不需要浏览器或后台页面常驻。电脑只通过 HTTPS 主动领取本店打印任务。

## 安装前现场登记

1. 在 Windows 中安装两台打印机驱动并分别打印系统测试页。
2. 记录 USB 收银/吧台打印机和后厨网口打印机的完整 Windows 队列名称。
3. 记录后厨打印机型号和 IP；确认佳博 GP-D802 的驱动、纸宽和切纸设置。
4. 准备受支持的 Node.js 可执行文件和 WinSW 服务包装程序。安装脚本不会联网下载第三方二进制文件；生产安装应填写来源方提供的 SHA-256。

## 安装

1. 在后台“设备与打印”生成 10 分钟一次性配对码。
2. 以 Windows 管理员身份运行：

```powershell
.\install.ps1 `
  -NodeExecutable 'C:\Program Files\nodejs\node.exe' `
  -WinSwExecutable 'C:\Install\WinSW-x64.exe' `
  -NodeSha256 '<现场核对的SHA256>' `
  -WinSwSha256 '<现场核对的SHA256>' `
  -PairingCode '<后台一次性配对码>'
```

3. 回到后台登记打印机，队列名称必须与 Windows 完全一致；再配置吧台、后厨、收银三个分流。
4. 分别执行测试打印，并用酒水、小吃、混合订单和支付成功场景完成实体纸单验收。

## 防重复边界

打印桥在出纸前写入本地日志，Windows 接受打印任务后再登记完成。若电脑恰好在“打印机已出纸、完成日志尚未落盘”的极短窗口断电，或任务交给Windows队列后出现超时/异常，软件无法从物理世界证明是否已出纸，因此会把任务标记为“上次结果不明”，停止自动重复出纸并交给人工核对。只有能明确证明尚未提交Windows队列的错误才会自动重试。该设计优先防止重复制作和重复给客人小票，但不能宣称物理打印具备绝对一次性。

## 故障处理

- 打印失败不回滚订单、支付、库存或电子出品任务。
- 重试前必须确认打印机是否已经实际出纸。
- USB 与网口打印机彼此独立；一台故障不会阻塞另一台的任务。
- 日志位于安装目录，配对凭据和防重复日志位于 `%ProgramData%\MBOX\PrintBridge`，仅 SYSTEM 与本机管理员可读。
- 卸载默认保留凭据与防重复日志；只有明确执行 `uninstall.ps1 -PurgeCredentials` 才删除。

## 已配对终端升级至1.0.3（一键包r2）

在确认当前纸票已出完的营业间隙，解压升级包，双击 `MBOX-OneClick-Upgrade.cmd`，并在Windows管理员授权提示中选择“是”。不需要打开后台生成配对码，也不需要重新选择打印机。

一键程序自动申请管理员权限，用系统级互斥防止同时升级，读取真实服务路径及数据目录，核对包清单、现有配对及版本。连续检查本地记录、MBOX打印任务和打印子进程后备份并停止服务；停服后再检查，确认无在途任务才替换3个程序文件。读取失败不当作队列为空，包不会降级更新版本，也不会删除或修改防重复记录。

停止/复制/校验/启动/稳定运行检查都包含在恢复流程中。复制开始后先确认服务停止才恢复文件，并校验恢复内容及原服务状态。恢复失败明确显示需运维接手，不能显示成功。中文结果窗口不会随管理员子进程结束而一闪消失；状态结果存于实际安装目录的`upgrade-last-result.json`，不记录凭据或票据正文。

使用`scripts/build-print-bridge-upgrade.py <新的输出目录>`生成完整ZIP；脚本生成逐文件SHA256清单并将PS1转为UTF-8 BOM，兼容Windows PowerShell中文脚本。参考[Microsoft编码说明](https://learn.microsoft.com/en-us/powershell/module/microsoft.powershell.core/about/about_character_encoding)。哈希仅验证完整性，本包没有代码签名。必须从完整解压目录运行，不能单独复制upgrade.ps1。自定义`-InstallDirectory`仅用于核对，必须与真实服务路径一致。

旧1.0.0桥没有协作暂停领取接口，停服前后检查仍不能消除极短竞争窗口；只在票据出完的营业间隙使用。r2是本地验证候选：PowerShell语法及事务故障模拟不能代替Windows服务、UAC、驱动和真实出纸验收。不得宣称绝对不中断或保证任何环境自动回退。

等待后台心跳刷新并读回版本1.0.3，再由现场核对一张新测试票；遇到未知结果先核实是否已出纸，不能直接重发。此脚本尚需Windows现场执行验证，不能从本地包生成认定升级完成。
