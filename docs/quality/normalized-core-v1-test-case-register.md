## 判定规则

- “通过”必须有本次代码的自动化、数据库或真实浏览器证据。
- “部分通过”不能计入P0发布通过率。
- 真实支付、退款、打印、通知或硬件未联调时，不允许用模拟结果替代。
- 阿里云现有员工系统保持不动；规范化候选未切流前不称为已部署。
