## 业务及数据边界

普通收款委托原应收计算，退款使用独立授权和流水证据，原日消费与实际收款日分离；补收不重复出品、库存或积分。仅未来关桌建立欠款快照，schema300及门店权限配置v30获用户授权。既有订单、支付、退款、日结和历史欠款不得回填或改写；477条历史候选继续只读核对，不能当成真实欠款认定。

标准部署入口为deploy/aliyun/deploy-release.sh。切换时需停旧写入方、使用新备份及OSS验证，保留开放桌次，不以关桌或改账通过门禁；恢复写入后禁止盲退不兼容旧应用。部署前后只读对照历史应收、关闭营业日、业务事实及权限配置。真实支付、退款到账、真机和实物打印仍需现场验收。

当前仅候选准备，尚未部署。准确PR/CI/标签、镜像、备份、切换和只读核验结果取得后追加。
