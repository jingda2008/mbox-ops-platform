# M-BOX 1.0.0-rc.45 AI经营分析与即时交互

## 本版完成

1. AI助理新增权限安全的经营分析能力，可用自然语言查询营业日、桌台、商品、客户和员工业绩等统计结果，不向员工开放任意SQL。
2. 新增规范化经营分析索引，减少整店JSON聚合读取，为后续多维统计和报表扩展提供稳定基础。
3. 客户服务、预约、候补和高频操作采用即时前端反馈、异步提交、幂等保护和失败恢复，降低等待感。
4. 客户端触感反馈调整为克制模式：浏览菜单和调整数量不震动，明确的服务、订单、点歌和支付确认使用轻微反馈。
5. 更新正式运行依赖并通过生产依赖安全审计。

## 版本治理

- 包版本、锁文件、Changelog、发布说明和Git标签由CI自动核对。
- 仅允许从已合并到`main`的版本提交创建`v1.0.0-rc.45`标签。
- 标签触发完整CI；全部检查通过后自动创建GitHub预发布。
- 阿里云验证环境必须运行该标签对应的不可变镜像，并在发布清单记录Commit、镜像摘要、数据库备份和回滚容器。

## 数据库

- 新增迁移：`018_analytics_query_foundation.sql`。
- 迁移保持向前兼容；发布前必须完成备份，旧容器只作为应用回滚点，不覆盖发布后产生的经营数据。

## 验证范围

- 全量静态检查、单元测试、构建和生产依赖审计。
- Playwright客户及员工关键流程。
- PostgreSQL迁移校验、强制RLS和规范化读取路径校验。
- 阿里云候选容器就绪检查、真实员工权限登录、客户入口和发布来源一致性检查。

本版仍为员工验证环境版本。真实在线支付、退款、打印机和其他门店硬件尚未完成生产联调，不能标记为正式商业营业上线。
