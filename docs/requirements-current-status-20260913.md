## 3. 金额与兼容边界

1. **部分付款规则已明确。** 按原商品应退与原实付扣除成功及在途退款的余额较小者退款；例如原价100、已收40、停30，退30、剩余应收70、净收10、待收60。原一次审核继续，现金仍需实际交付记录，不自动扣补款。
2. **原优惠/套餐/权益金额。** 单套有原单点价的套餐已按保留商品原价重算；没有原单价、多套合并行未留逐套归属、券/积分部分退回政策未确认的情况，保持原申请待核，不把其他完整套餐一并改成单点价。消费赠送积分冲回与花掉积分返还是不同流程。
3. **旧制作失败/旧重做。** 保留旧异常与材料证据、原处理入口；目前不承诺这些旧行直接部分迁移。新普通数量行的暂停、补送、逐代重做、实际耗料及交接已按上述候选测试覆盖。
4. **现场事实。** 岗位拿到旧纸票、未开封实物已退回、现金确已交付，都需要现场事实；系统自动记录与原结果恢复可以减少操作，不能替人虚构完成。
