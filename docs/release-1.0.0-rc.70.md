# M-BOX 1.0.0-rc.70 可验证发布证据修复

## 目标

本候选保留`rc.69`的员工协助点单、按岗位额度赠送现场商品以及客户运营权益分离，并修复GitHub Actions制品额度耗尽后无法完成正式验证部署的问题。

## 发布证据

- 标签CI继续执行代码、数据库、浏览器、规范化移动端和持续负载门禁。
- CI通过后，将质量台账、性能报告和启动性能报告封装为独立SHA256校验包。
- 校验包与不可变Docker镜像存放在同一GitHub预发布中，仅承担短期传输职责。
- 发布流程校验提交SHA、CI运行编号、镜像摘要、外层归档SHA256及包内文件SHA256。
- 阿里云部署验证完成后，正式证据继续归档到私有OSS，不依赖GitHub Actions长期保存。

## 业务边界

- 现场已开台桌位保留`协助点单`与具备权限人员的`赠送商品`。
- 生日、召回和日常运营权益不进入现场桌台操作，继续由客户运营权益域管理。
- 退款等财务动作仍须人工审批和审计，本次未放宽任何财务权限。

## 发布边界

- 本版本用于阿里云开发验证环境，不代表商业生产验收完成。
- 星驿真实支付、退款、物理打印、弱网和连续真实营业班次仍需独立现场验收。
- 支付与硬件未安装不阻止本验证版本部署，但相关能力不得标记为已完成。
