# M-BOX 1.0.0-rc.53 桌台加座与开台区域修复

## 本次范围

- 修复666、A/B/C等正式桌台因其物理区域未配置为客户预约偏好而无法临客开台的问题。
- 临客、预约和候补入座统一改为“容量是建议值”：实际人数超过建议容量时仍可开台。
- 员工端明确显示建议人数和加座人数，切换桌台后人数恢复为默认建议，防止上一桌人数残留。
- 开台审计保存建议容量、实际人数和加座人数，供经营分析与现场复核。
- 线上预约区域是否开放仍由预约配置控制；本修复不会把停用区域重新开放给客户预约。

## 验证

- 临客开台、预约入座和候补入座定向回归通过。
- 666桌在缺少公开预约区域偏好的状态下可开台，8人落座记录为建议6位、加座2位。
- 代码检查和生产构建通过；发布前继续执行完整CI、浏览器流程和候选版本健康检查。

## 发布边界

本版本不修改支付、订单、库存和线上预约可售规则，不包含数据库结构迁移。桌台现场是否适合加座仍由员工依据消防通道和实际空间判断，系统只取消容量硬拦截并保留审计。
