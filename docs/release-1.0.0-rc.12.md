# M-BOX Ops Platform 1.0.0-rc.12

发布日期：2026-07-18

## 演出数据配置化

- 演出排班不再只编辑当日第一场，可选择任意历史或未来场次继续修改。
- 支持新建空白排班、复制当前排班、修改营业日、场次名称、状态、歌手、顺序和全部时间。
- 点歌开放、提前预约、演出延长协商及阈值均由排班逐轮配置。
- 修改营业日时轮次时间自动整体平移；存量异常日期提供一键对齐，未处理前禁止误发布。
- 歌手名称、照片、简介、风格、启停状态以及每首歌曲、原唱、时长、价格和可见状态继续由后台维护。
- 客户端只读取当前营业日已配置的有效歌手、排班和歌单，不依赖前端固定名单。

## 岗位操作简化

- 老板、运营负责人、管理员、店长、服务员、调酒师、厨房、收银、门迎、传菜与自定义岗位首页统一增加“现在先做”入口。
- 首页一次只突出最高优先事项，其余事项放入“接下来”，减少员工判断和查找步骤。
- 导航按岗位改成直接业务语言，例如“我的桌台、点单与送餐、酒水制作、预约与入座、收银与退款”。
- 权限、责任范围、审批和审计规则保持不变，界面简化不会扩大员工权限。

## 配置结果反馈

- 配置草稿、正式发布、版本回滚、桌台经营规则、人员主数据、权益规则和演出配置均明确返回成功或失败。
- 成功提示使用绿色边界，失败或未保存使用红色边界，不再通过静默刷新暗示结果。
- 所有演出配置写操作在提交期间禁用重复点击，完成后刷新到服务器最新版本。
