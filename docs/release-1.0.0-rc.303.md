# 1.0.0-rc.303 支付回执保护与吧台出单恢复

本版处理 A10 暴露的付款成功到业务入账之间的竞态。后台以已验签回执保护原付款、权益与出品，修正退款提示，恢复准时付款订单时只生成一次制作任务和票源。迁移 318 和 319 更新数据库的翻台和预收核对逻辑。历史订单不批量重放。

微信与支付宝小程序源码同步修复了付款结果未知时的退出处理。平台上传、审核及正式发布有各自的回执。后台部署和顾客端版本须分别核验。

候选以远端主干 rc302、数据库 317 为基线，回退目标为现网 rc302。发布前依照正式流程复核迁移、不可变制品、备份、回退目标和入口。现场制作、打印及真实渠道款项仍按原单核对。完整故障及本地复现证据见[商业化清单](commercialization-pending-checklist.md)。

支付宝官方编译器在上一版已存在的预收处理可选链处失败。已改成显式原付款标识比对，新增静态门禁先在原代码上复现，再以官方编译器验证全部 23 页通过。
