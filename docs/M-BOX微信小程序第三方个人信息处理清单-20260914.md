# M-BOX微信小程序第三方个人信息处理清单

版本：MBOX-THIRD-PARTY-20260914-V2  
更新日期：2026年9月14日

本清单是《M-BOX微信小程序隐私政策》的组成部分，说明M-BOX微信小程序在提供登录、支付、客服和基础设施服务时涉及的第三方个人信息处理情况。实际处理范围以用户主动使用的功能为限。

## 1. 微信及企业微信

- 服务提供方：深圳市腾讯计算机系统有限公司及提供相关微信服务的关联主体
- 使用场景：小程序运行、微信登录、手机号授权、扫码、订阅消息、分享及企业微信客服
- 可能处理的信息：微信一次性登录凭证、OpenID等用户标识、用户选择授权的手机号、微信昵称或头像选择结果、扫码结果、订阅选择、客服会话所需信息、设备和网络安全信息
- 处理目的：建立安全会话、完成用户选择的功能、发送经授权的服务通知、建立客服会话及保障服务安全
- 处理方式：通过微信小程序原生接口和组件按用户主动操作调用
- 用户选择：手机号、扫码、通知、头像和客服等能力均可拒绝；拒绝后的影响以隐私政策对应功能说明为准
- 规则入口：以微信客户端及腾讯隐私保护平台公示的最新规则为准

## 2. 微信支付

- 服务提供方：财付通支付科技有限公司
- 使用场景：微信支付、退款、查单、对账和交易安全
- 可能处理的信息：订单号、交易金额、商户信息、付款人标识、客户端IP、支付或退款状态、交易时间及风控所需信息
- 处理目的：完成用户主动发起的付款或退款、核对交易结果、处理差错和防范交易风险
- 处理方式：小程序调用微信支付界面，服务端通过签约支付链路提交必要交易信息并接收可信交易结果
- 规则入口：财付通隐私政策及微信支付页面向用户展示的规则

## 3. 星驿付

- 服务提供方：福建星驿支付科技有限公司；如本店签约文件或支付页面展示的法定主体名称不同，以有效签约及支付页面为准并同步更新本清单
- 使用场景：支付预下单、退款、交易查询、支付回调和对账
- 可能处理的信息：商户订单号、支付或退款金额、付款人标识、微信AppID、客户端IP、支付方式、交易时间、支付或退款状态及风险校验信息
- 处理目的：完成支付和退款、核验交易结果、对账及防范支付风险
- 处理方式：M-BOX服务端通过加密网络请求与签名验证接口传输最小必要信息
- 规则入口：星驿付官方网站、签约文件及支付页面公示的最新规则

## 4. 阿里云

- 服务提供方：阿里云计算有限公司及提供具体云服务的关联主体
- 使用场景：服务器、数据库、对象存储、网络安全、备份和运行日志
- 可能处理的信息：存储于M-BOX系统中的必要业务信息、IP地址、请求时间、请求结果、异常和安全日志
- 处理目的：运行小程序后台、保存业务数据、提供图片等资源、保障网络安全和恢复能力
- 处理方式：作为受托基础设施服务方，在M-BOX配置、权限和合同约束下处理
- 规则入口：阿里云官方网站及所使用云产品公示的隐私和安全规则

## 5. 当前不使用的第三方处理

当前微信小程序代码未嵌入独立的广告、跨应用追踪或用户画像类第三方SDK，不向活动合作方出售或提供会员及报名名单用于合作方自行营销。

如未来新增SDK、统计、地图、短信、广告、内容识别或其他第三方服务，应当在启用前完成必要性和安全评估，更新本清单和隐私政策，并在需要时重新取得用户同意；不得先收集、后补告知。
