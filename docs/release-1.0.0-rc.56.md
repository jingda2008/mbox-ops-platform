# M-BOX 1.0.0-rc.56 公众号预约座位图手机优化

## 本次范围

- 将座位图由固定像素裁切改为按区域比例缩放，图片和可点击桌位在不同手机宽度下保持一致。
- 修正S区正式桌号为S01-S07，确保所有S桌显示状态图层并可点击。
- 将区域调整为室内全景、舞台侧和室外区域；室内不再出现W桌，室外统一显示W01-W17。
- 室内全景使用更紧凑、半透明的桌位状态标记，保留底图桌号和空间关系；舞台侧和室外保留更易点击的放大标记。
- 缩小座位选择步骤的品牌栏、步骤栏、标题、说明、图例和底部操作栏，使390×844手机首屏可同时看到区域、座位图、桌位详情和下一步。
- 点击桌位后自动将预约状态、建议人数、定金、最低消费和下一步操作带入可见区域。

## 验证要求

- 390×844、430×932及360×800手机视口不得出现横向溢出。
- 室内全景必须显示S01-S07，且不得显示W01-W17。
- 室外区域必须显示W01-W17，且不得显示S01-S07或VIP桌。
- 舞台侧只展示舞台附近桌位，并保持桌号、底图和点击层位置一致。
- 点击任一桌位后，桌位详情必须进入当前视口；不可预约桌位只能查看状态，不能进入下一步。
- 预约提交、后台桌号同步和同桌同时段防撞规则保持不变。

## 发布边界

本版本只部署到阿里云验证环境。预约申请不会自动扣款；真实定金仍需门店确认金额和抵扣规则后，通过后续支付流程完成。正式公众号入口、ICP备案、微信业务域名、模板或订阅通知、真实支付和门店岗位验收仍是商业生产发布前置条件。
