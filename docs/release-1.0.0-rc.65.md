# M-BOX 1.0.0-rc.65 日志、并发与凭证安全修复

## 升级目标

- 消除高峰期多个整店状态写入同时争抢 PostgreSQL 连接导致的连接池超时。
- 区分系统故障、正常业务拒绝和客户端主动断开，避免值班人员被错误告警淹没。
- 阻止桌码和客户会话凭证进入应用及代理访问日志。
- 让服务任务和 KDS 在多设备重复点击时收敛到唯一终态。

## 核心改动

- 单应用实例内的聚合状态写入进入有上限、有等待时限的串行队列；读取仍可使用其余连接。
- 写事务先锁定轻量修订号；本进程缓存修订一致时不再重复读取和解析整份状态文档。
- 队列满、队列等待超时和数据库连接异常统一返回可恢复的 `503 PERSISTENCE_UNAVAILABLE`。
- 结台阻断、任务状态冲突等业务条件返回明确 4xx 编码，不再作为 5xx 系统错误记录。
- 新固定桌码使用 `?table=桌号#token=凭证`，页面通过 POST 正文交换短会话；不支持旧查询参数凭证入口。
- 应用请求日志和 Caddy 访问日志同时脱敏 token、微信 code 及其他会话字段。
- 数据库迁移 `022` 补齐客户推荐行为事件约束。

## 验证结果

- 单元与集成测试：141 个测试文件、1085 项全部通过。
- 浏览器流程：修正旧拦截规则后全量重跑，49 项全部通过。
- 300 人、60 并发本地读取压力：900 请求，错误率 0，HTTP P95 33.75ms。
- 隔离 PostgreSQL、5 连接、启用规范化投影：50 次并发写和 20 次强制新鲜读取全部完成；写 P95 731.66ms，读 P95 112.06ms，连接等待 0，投影修订一致。
- Caddy 2.10.2 配置适配和验证通过。
