# M-BOX 1.0.0-rc.39 打印任务下钻与现场处理

## 目标

把经营概览中的“待打印任务”和“打印失败”从只读数字升级为现场可处理入口，让值班人员知道哪一桌、哪张订单、哪些商品、发往哪台打印机，并在权限范围内完成回执或故障恢复。

## 本轮升级

- “待打印任务”和“打印失败”统计卡可点击，自动进入对应筛选的打印任务页。
- 新增全部、待打印、失败、已打印四种状态筛选。
- 任务展开后显示桌台、订单、打印路由、目标设备、连接方式、尝试次数、商品规格和数量。
- 待打印任务支持确认已打印或选择具体故障原因。
- 失败任务支持重新加入打印队列，或确认已人工补打。
- 管理员可从任务页直接进入打印机与酒水/小吃分流设置。
- 查看与操作权限分离：无出品或配置权限的岗位只能查看；所有操作继续由服务端校验并写入审计记录。
- 已打印任务不可重复修改；只有失败任务可以重排，重排本身不会虚增打印尝试次数。

## 交互与适配

- 桌面端任务摘要保持单行扫描，点击后在原位展开，不跳失上下文。
- 手机端详情自动改为双列信息和纵向操作区，430×932 视口无横向溢出。
- 空队列提供明确状态说明，不再只显示数字 0。
- 所有处理动作都有成功或失败反馈，失败原因不会静默丢失。

## 验证

- 122 个测试文件、859 条自动测试通过，生产构建通过。
- 24 条跨客户端浏览器流程通过，其中新增 2 条打印任务桌面与手机专项流程。
- 桌面和手机实机尺寸视觉检查通过，页面无运行错误和横向溢出。
- 生产依赖安全审计未发现高危或严重漏洞。
- 213 条经营 TC 仍有 66 条 P0/P1 发布阻断，本版不改变商业发布门禁结论。
