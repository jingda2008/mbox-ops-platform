# 1.0.0-rc.231 权限时序与出品闭环说明

默认员工鉴权使用数据库微秒时间，避免应用毫秒时钟落后于刚提交的权限撤回；角色审批权限使用同一数据库时钟，显式历史时刻仍可查询。没有放宽员工、租户门店、设备或支付权限。

历史跨日关闭的旧整行商品，仅当有原始出品记录、没有送达审计、没有按份记录且桌次确有自动截止事件时，显示“有出品记录；送达未登记；桌次已跨日结束”，历史列表与导出一致。该说明不推断取消原因，不回写制作/送达，不修改正确收退款、应收和库存。

三屏功能已启用但无启用设备时，服务端单独报告设备未配置，页面提示在实际门店取餐平板设置。保留“取走即送达、手机不二次确认”；不把开发电脑伪装为门店取餐设备。

无新迁移，schema245；使用标准不可变产物发布程序。17组隔离PostgreSQL回归363项通过，含真实受限LOGIN时钟偏差/微秒/立即撤销50次及原交接重放失败用例；常规2140项通过，数据库环境相关1125项在常规命令中跳过，不能算已测。最终源码CI、正式发布和现场设备/实物验收分别留证，不以候选代替上线。
