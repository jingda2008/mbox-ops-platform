1. **设备负责人：开机、联网、看桥接。**打开打印电脑及吧台/后厨打印机，确认纸张和网络。查看原`MBoxPrintBridge`服务；若停止，由有权限的设备负责人启动一次。已运行但没有通信时，不连续重启。后台“全部 → 设备与打印”刷新，确认打印桥新鲜在线；离线按钮上点“检测/重连”不能替代启动已经离线的电脑。
2. **仍离线或纸张异常时才使用检查包。**把`MBOX-Print-ReadOnly-20261023.zip`完整解压到打印电脑桌面的新文件夹，双击`MBOX-Check-Printing.cmd`。将同目录生成的`MBOX-Check-Result-…zip`交回本对话定位。它不安装、不停止服务、不改驱动/配对/队列、不下单、不出纸，不读取配对凭据或订单正文。读取受限就保留报告，不关闭Windows安全设置。当前Mac只核对了包完整性，未执行Windows现场检测。
3. **厨房和吧台：各确认一张纸。**桥接恢复后，由乌鸦或陈方宇使用原“设备与打印”，填写原因“班前打印检查”，对吧台、后厨实际设备各点一次“测试打印”。核对正确机器、中文、纸宽/切纸和份数。显示“已提交/成功”后仍要看实物；未出纸先查原结果和Windows队列，不反复点击，也不补打10月2日历史制作单。
4. **新业务启用前由领班验完整链。**指定一个新套餐，含实际需分流的菜品，走报名→核销→每份一号→发牌→各岗制作票→分批取走→按号交付。厨房核对仅有自己岗位菜品、数量和备注；普通测试票不能证明号码/分流正确。缺纸恢复使用同一原任务核查，只在确认未出纸后按原重试/补打规则处理。不要再次核销制造第二份餐。

桥接未恢复时先不接收依赖自动出单的新活动核销；已收款或已核销事项由领班查原号、原任务，使用原制作屏/人工交接继续履约，记录已制作数量，恢复后避免把迟到纸票再做一遍。无依据远程重启云服务器，不能修复现场电脑断电或缺纸。
