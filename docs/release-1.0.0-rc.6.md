# M-BOX Ops Platform 1.0.0-rc.6

发布日期：2026-07-17

## 永久桌贴二维码

- 明确实体桌码为长期静态凭证，扫码后再换取当前桌次最长60分钟的临时会话。
- 结台、翻台、转桌及单桌换码会撤销旧会话，静态桌码不能直接下单或呼叫服务。
- 正式桌码默认输出到门店固定目录，不再按营业日生成。

## 每日门店验证

- 门店口令验证成功后签发有效至下一个北京时间零点的当日凭证。
- 同一设备切换员工时无需重复输入门店口令，只需选择员工并输入该员工PIN。
- 北京时间跨日后自动要求重新验证门店口令；当日凭证不能代替员工身份会话。

## 匿名顾客与行为事件

- 未注册顾客首次进入时获得随机匿名ID，不使用浏览器指纹或人脸推断身份。
- 独立PostgreSQL档案表和事件表记录桌次、来源、北京时间、情绪、服务、菜单、购物车、订单、支付与点歌等关键行为。
- 服务员协助点单使用稳定的到店访次ID，保留商品、数量、金额和桌次分析链路。
- 小程序微信认证支持携带匿名ID，认证后关联内部微信主体，绑定会员后继续关联会员ID，原始事件不被覆盖。
- 客户端不能伪造支付、订单或服务完成事件，分析属性使用白名单且事件按幂等键去重。

## 验证

- 桌码静态凭证、每日门店凭证、员工切换、北京时间跨日、匿名ID持续性、事件幂等、服务员协助点单和微信身份合并均有自动化测试。
- 隐私和识别边界见 `docs/static-table-qr-and-guest-identity.md`。
