# M-BOX 1.0.0-rc.54 现场开台与责任区边界修复

## 本次范围

- 点击空台后，在该桌台所在区域就地展开人数、销售归属和确认开台控件。
- 开台成功后自动收起选择并停留在“全店现场”，不再强制跳入全屏点单。
- 现场桌台按员工后台配置的责任区展示；取消李艳的 W 区责任后，W 区不再出现在其现场操作台。
- 店长仍可查看全店经营指标和管理信息，但不能在未负责区域执行开台。
- 手工开台接口与 AI 值班经理开台使用同一责任区校验，不能从其他入口绕过。

## 验证

- 权限、桌台开台和 AI 执行定向回归通过。
- 完整单元测试、生产构建、代码检查及岗位浏览器流程通过后方可发布。
- 1024×768 平板视口验证就地开台面板无横向溢出。
- 开台成功后验证选择面板关闭、页面标题仍为“全店现场”且 URL 未进入订单页面。

## 发布边界

本版本不修改数据库结构、订单、支付、退款、库存、桌码或客户会话。责任区配置只限制员工现场桌台展示和开台执行；店长的全店数据监督、报表和管理能力保持不变。
