# M-BOX 1.0.0-rc.82 验证支付配置边界修复候选

## 本版目的

修复验证服务器明确关闭星驿支付并使用模拟支付时，规范化服务仍被残留的机构号、商户号和回调地址误判为已启用支付，继而因尚未配置星驿公钥而拒绝启动的问题。

## 本版变化

- 验证环境设置`MBOX_POSTAR_ENABLED=false`且未显式选择支付服务商时，保留的UAT参数不再启用真实支付模块。
- 显式设置`MBOX_PAYMENT_PROVIDER=postar`时仍按完整配置校验，不受旧关闭开关影响。
- 商业生产环境继续强制要求支付服务商、机构号、商户号、公钥、回调地址、真实支付模式和工作进程配置。
- 保留`rc.81`的不可变OCI镜像身份校验，以及`rc.80`的同桌订单、员工协助点单和客人接力支付能力。

## 自动化验收

- 覆盖验证环境关闭支付但保留UAT参数的回归测试。
- 覆盖显式支付服务商不能被旧关闭开关绕过的回归测试。
- 覆盖生产环境不能使用旧关闭开关绕过支付必填项的回归测试。
- 执行完整质量、数据库、浏览器、规范化数据库、规范化浏览器、持续负载和不可变镜像发布门禁。

## 验收边界

本版用于开发验证环境，保持模拟支付。没有发起真实支付或退款，也不代表星驿生产验签公钥、真实渠道回调、主动查单、对账或物理设备已通过商业验收。
