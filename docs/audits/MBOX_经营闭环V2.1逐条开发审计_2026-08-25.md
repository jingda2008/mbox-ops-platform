## 5. 当前开放问题

### P1：发布前应关闭

1. **跨营业日异常处理入口仍非全部精确可操作。** 收银页能看到精确事实，但库存预留、定价授权、点歌、体验计划、会员兑换、升级要约等跨模块入口未全部做到“点击即定位该事实并提供有权限的处理动作”。
2. **年度资格纠正后的自动撤销执行器不完整。** 普通等级权益已有退款/等级处理，年度 grant 的 `revocationPolicy` 仍需在资格纠正事件后自动评估，而不能只依赖人工异常结案。
3. **正式门店配置证据缺失。** 代码默认值已是银卡 5,000、金卡 20,000，但尚未证明门店已发布版本、正式赠品、无酒精替代、配方、库存和成本都已配置。

### P2：性能与维护

1. Web 构建存在单个约 607KB 的员工端 JavaScript 分块警告，需要在性能阶段按真实设备评估是否拆包。
2. 会员公开聚合读在单个 PostgreSQL 客户端上的并发查询有升级技术债；当前可运行，但升级 `pg` 前应改为顺序或独立只读连接。
