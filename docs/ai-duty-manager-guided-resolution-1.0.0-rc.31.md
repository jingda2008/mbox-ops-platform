# AI值班经理引导处置 RC.31

## 目标

让员工打开AI值班经理后，不需要理解系统模块，直接看到当前最应该处理的事项，并用一次点击完成接管、留痕和业务定位。

## 本版行为

- 风险由确定性规则产生并按紧急程度排序，大模型不直接修改业务数据。
- 每项风险包含目标对象、检索条件和面向现场的AI处置建议。
- “接管并处理”一次完成责任人留痕、打开有权限的业务页和定位具体对象。
- 已接管事项显示“继续处理”，源业务完成后自动从巡场清单关闭并保留事件记录。
- 预约风险自动切到本营业日、按客人姓名筛选并高亮预约。
- 服务风险自动筛选对应桌台；出品风险自动进入履约模式并高亮对应桌台任务。
- 控件数、热词数、声线等技术信息收进“语音偏好与识别状态”，不占用主要处置界面。

## 权限和审计

- 一键接管仍由原岗位权限判断；无权人员只能进入其可见范围，不能越权执行。
- 业务操作继续复用原页面的权限、校验、二次确认和审计记录。
- 延后和误报仅向具备管理权限的员工开放，误报必须保留复核说明。

## 验收重点

1. 李艳看到待确认预约后，点击一次即可进入对应预约，而不是预约首页。
2. 点击时事件变为已接管；完成预约确认后，风险自动关闭。
3. 手机宽度下主动作、建议和关键信息不横向溢出。
4. 语音和文字对话仍可使用，但不会遮挡当前最高优先事项。
