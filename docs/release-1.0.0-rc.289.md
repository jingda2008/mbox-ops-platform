## 修复

线上rc287实际收银查询已复现G1原单在“未支付”筛选下被漏掉；普通收款人员额外受到历史核对权限限制。修复筛选，并在员工点击收款方式时同事务确认展示的原单应收和创建支付，不再先调用另一核对接口。原单金额默认全额，可分次收取；失败回滚，应收确认本身不算实收。既有调整应收/无欠款决定保留为可选操作。

历史收款按普通收款桌台范围或既有历史收款权限执行，支付方式权限仍独立校验；不改生产员工角色记录。原单依据过期、超额、重复到账和跨门店操作继续拦截。营业中待接单、已接单、制作中均可收款，支付不伪造送达或恢复取消制作，不重开跨日桌次。

保留rc288的页面更新提示和未知回执保护。首次部署后已打开的旧网页须手动刷新；缓存只是截图与公网脚本差异的一种解释，未认定为唯一根因。
