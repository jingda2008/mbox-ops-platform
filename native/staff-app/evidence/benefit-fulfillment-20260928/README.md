# 原生权益兑付增量（本地）

最后更新：2026-09-28 10:48 CST。

## 已实现

- iOS / Android 独立原生“权益兑付 · 礼遇与点心”入口，依当前兑付权限显示。生日/节日礼遇暂留与当前营业日每日点心队列，桌号/会员号/权益名称模糊筛选，待核销优先。
- 原会员、桌次、权益、暂留、数量绑定；原赠品/允许替代商品及替代理由；取消未核销暂留须原因；当面核对确认；已核销记录不能再次核销或按未核销暂留取消。
- 原始请求本机保存、同键回执恢复；服务端native操作命名空间、无限期成功回执、当前权限重检、员工绑定。已核销/取消后不依赖已消失的队列行恢复结果。处理失败明确未提交；提交状态未知时仍保留原请求。
- 复用原赠品订单适配器和库存/履约链；核销不代表制作或送达。显示每日点心历史状态及当前出品状态，不混用。网页版现有接口和回执格式保留，无新迁移。
