# M-BOX 1.0.0-rc.79 网页入口发布门禁候选

## 本版目的

保留 `rc.78` 已完成的审计整改，在发布前后增加真实浏览器入口验证，避免只检查 API 健康状态而遗漏固定桌码、预约或员工深层网址。

## 本版变化

- 发布冒烟同时检查首页、`/guest?table=W01`、`/reserve` 和 `/staff/live`。
- 网页检查使用真实浏览器 `Accept` 请求头，要求返回 200、HTML 类型和有效页面外壳。
- 非网页接口请求仍返回结构化 404，不把未知 API 错误兜底成前端页面。
- 蓝绿切流前后的同一检查失败时自动停止发布或恢复上一版本。

## 验收边界

本版没有改变点单、预约、支付、退款、库存或岗位业务逻辑。真实支付、实体 POS、打印、通知、硬件和员工现场演练仍属于商业发布阻断项；本版只能作为阿里云开发验证版本。

详细业务整改沿用 [rc.78 审计复核](audit-report-reconciliation-1.0.0-rc.78.md)，本版新增门禁见 [rc.79 增量 TC](tc-release-route-gate-1.0.0-rc.79.md)。
