# M-BOX Ops Platform 1.0.0-rc.3

发布日期：2026-07-17

## 桌次与服务隔离

- 所有服务需求绑定不可变的桌次 ID，不再只依赖桌号和开台时间判断归属。
- 结台和翻台时，上一桌需求从实时客户页与员工任务池中移除。
- 未响应、已响应未完成、员工完成但客户未确认等状态完整归档，保留责任人、时间线和事件记录用于服务分析。
- 旧桌次二维码继续失效，新桌次不会继承上一桌的需求、订单或提示。

## 开台可用性

- 临客开台仍由员工操作，不需要客户确认。
- 原主服务员离线、暂停或不在班时，系统自动选择在线候补、当班管理人员或当前操作员工临时接管；当前操作人不因缺少区域排班记录而被卡住。
- 自动接管会更新桌台责任链并写入审计，避免出现按钮可点但接口无法开台。

## 客户购物车

- 手机端底部汇总区同时显示已选商品件数与合计金额，减少客户来回查找。
