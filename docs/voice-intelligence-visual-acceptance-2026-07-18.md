# 语音智能与视觉专项验收基线（2026-07-18）

## 1. 验收边界

- 版本基线：`1.0.0-rc.13` 增量变更。
- 范围：全岗位语音命令、动态业务字典、连续命令智能体、执行反馈、客户/服务员/店长关键页面视觉与跨流程联动。
- 环境：隔离 JSON 数据仓库、本地真实浏览器、桌面/平板/手机视口；通过后发布到 Google Cloud Run 验证环境。
- 发布原则：本专项基线不替代 213 条经营 TC。原经营验收中的 P0/P1 未通过项仍然阻止商业生产发布。
- 状态定义：`通过` 表示已有自动化或本轮浏览器证据；`门店待执行` 表示必须使用真实平板、耳机或嘈杂现场复验。

## 5. 本轮结论

- 共 53 条专项 TC：50 条通过，3 条门店设备/噪声待执行。
- 自动化覆盖解析、动态字典、候选消歧、高风险双确认、连续命令和页面反馈验证。
- 浏览器覆盖客户、服务员、店长三类视角与手机、平板、桌面三类视口。
- 云端修订 `mbox-ops-validation-voice-mobile` 已通过 `/api/live`、`/api/ready`、安全响应头和 Tom 登录态真实中文录音转写；手机键盘布局与反馈消失已通过320px和390px真实浏览器视口检查。
