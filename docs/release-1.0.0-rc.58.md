# M-BOX 1.0.0-rc.58 退款额度权限热修复

## 本次范围

- 退款审批按钮同时校验申请人与审批人分离、退款审批权限和当前员工的退款审批额度。
- 当前员工有审批权限但额度不足时，页面显示本笔金额、本人额度和额度足够的候选审批人，不再提供必然失败的操作。
- 保留`rc.57`对乌鸦现金收款AI命令、重复预约警报和重复退款申请的修复。
- 修复TypeScript 6严格模式下硬件业务错误类的构建兼容问题，不改变硬件业务行为。

## 验证要求

- 李艳发起的628元退款继续保持待审批，李艳不能自批。
- 乌鸦退款审批额度为0，不得显示该退款的审批按钮。
- 只有不同于申请人、具备退款审批权限且额度不低于628元的员工可以看到审批动作。
- AI不得代替人工批准退款；退款、现金收款和对账继续保留人工确认与审计。
- 乌鸦输入“生成现金收款单”时仍应返回权限说明，不得生成可执行计划。
- 已确认或已接管的预约不得重复进入当前警报。

## 发布边界

本版本只部署到阿里云验证环境。现有退款不会自动批准或改变状态，必须由满足权限与额度条件、且不同于申请人的员工人工核对后处理。真实微信／星驿退款、物理POS退款、现金日结与对账仍需完成渠道和岗位验收。
