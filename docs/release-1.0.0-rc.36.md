# M-BOX 1.0.0-rc.36 AI真实执行与定时指派升级

## 本版完成

1. **开台真实执行**：李艳、Tom等有权限员工说“给L01开台，实际4位”，确认后直接调用服务端开台工具；必须提供人数，不再默认2人。
2. **连续追问补全**：员工先说“L01开台”，AI追问人数；下一句只说“4位”时仍能关联上一轮并生成正确开台计划。
3. **定时点名派单**：值班管理岗位说“5分钟后让Tom给L01加水”，系统创建可持久化的一次性SOP，到时才生成服务任务并指派、通知Tom。
4. **岗位权限隔离**：只有具备值班管理权限的员工可以指派其他员工；目标员工还必须具备服务执行权限和对应服务岗位。
5. **权威执行证据**：每次AI工具执行返回桌台状态、人数、任务状态、责任员工或计划时间，并写入幂等审计记录。
6. **失败不再伪装成功**：模型规划或网络失败时明确显示“本次没有执行任何操作”，不再退回前端模拟点击。
7. **员工可理解反馈**：计划明确区分“等待确认”“服务端正在校验并执行”“已由服务端确认”，失败步骤会停止后续执行。

## 经营流程

```text
员工语音或文字命令
→ 高频经营语义确定性解析
→ 员工确认执行计划
→ 服务端权限与实时状态复核
→ 真实业务写入和审计
→ 返回权威结果

定时指派
→ 创建一次性SOP执行记录
→ 到达计划时间
→ 生成Tom名下服务任务
→ Tom岗位页面显示并按接单、到桌、完成闭环
```
