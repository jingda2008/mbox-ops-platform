## 本次能力

- 管理员可按岗位配置并排序1至4个高频入口，特殊员工可以设置个人覆盖。
- 桌面侧栏、手机底部和岗位首页使用同一高频入口顺序，其他合法能力保留在“更多功能”。
- 入口配置继续受有效权限过滤，权限或兼任岗位变化后自动剔除失效入口。
- 未开台桌面的客户提示改为到店引导，不再使用容易误解为二维码故障或过期的措辞。
