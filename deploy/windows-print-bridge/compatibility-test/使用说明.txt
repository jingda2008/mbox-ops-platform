M-BOX 1.0.4 test2 加大字体及时间版 独立兼容试打（不是升级安装包）

1. 把整个 ZIP 解压到 Windows 桌面的新文件夹，不能直接在压缩包内运行。
2. 打印空闲时双击 MBOX-Test-Only.cmd。
3. 点“是”试打吧台。拍下完整纸票，检查中文、桌号字号、数量2、单价8、小计16、长备注和自动切纸。
4. 再打开同一入口，点“否”试打后厨，并注明对应打印机。

不替换营业程序，不停服务，不改配对/驱动/队列，不下单或改账，不补打历史任务。
使用已经登记的 batai 和 chufang 队列、80毫米配置；不存在的队列直接退出，不自动创建。
每台只尝试一次，不自动重试。已尝试标记保存在当前用户 LocalAppData/MBOX-Print-Compatibility-1.0.4-test2。
出现卡住、报错或没有纸时，不反复点击或重启打印服务；先核对队列和纸票，把提示反馈给开发人员。
窗口显示“提交”不代表物理成功。此试打运行在当前Windows用户下，不是营业服务身份验收。
只有两台实体试打通过后，才准备正式升级和服务身份验收；旧1.0.3升级包继续停用。
本轮测试重点是恢复原RAW/GBK/切纸兼容并验证文字强调，不代表参考图片全部布局已完成。

本版针对照片反馈：桌号3倍宽高，商品和合计2倍宽高，放大行后补空行，打印时间取电脑时钟并按北京时间显示。纸张会比上一版更长。
