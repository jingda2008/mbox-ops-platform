# M-BOX 1.0.0-rc.202

包含rc.201结账单标题及陆家嘴中心抬头，并将新手动整桌账单编号扩展为YYYYMMDD-HHMMSS-六位数字。日期按开票时刻的北京时间；票据号使用源请求UUID参与既有编号算法，保存在新票快照ticketReference，使现有1.0.9无需升级即可打印新号。重试/分页/补打读同一快照原号，原始桌次UUID保留在尾部备注和数据库sourceReference。

六位识别数字不承诺全局唯一，不作为付款/退款或核销主键。既有自动关桌归档票编号规则不变，历史票据不重写。新生成快照与旧票补打分开操作。

rc.201已合并并保留标签，未部署；本版作为用户追加编号后的完整候选。schema203、Windows驱动/RAW/切纸、资金库存和配置不变。验证及实际交付见[专项记录](checkout-ticket-branding-20260915.md)。
