# 1.0.0-rc.268 普通兴趣卡与旧版卡入口说明

员工误入旧版“五迷”草稿的社交加入条件配置，被缺失的企业微信账号阻塞；保存草稿也不会让顾客看到申请入口。本次仅调整员工网页入口和提示，复用现有普通兴趣卡创建、开放、申请和审批流程。

- 旧版接入页和卡项目列表明确标记普通兴趣卡/旧版卡，并提供会员卡页面直达入口。
- 提示普通兴趣卡无需绑定服务号或企微，草稿顾客不可见，开放申请需要既有发布权限；缺少旧版企微账号时说明原因。
- 隔离验证分人创建开放、顾客申请、授权员工审批、持卡与重复请求，并逐字段核对原旧卡未变。

发布范围为员工网页、随包服务端；数据库仍为schema282，无迁移或经营配置变更。微信小程序代码未改，不要求重新上传；支付宝不上传、不提审、不发布。

生产陈方宇补会员卡管理、新建WMLS（五迷）未开放普通兴趣卡草稿已获用户授权；因后台仍要求门店设备验证，用户本轮再次选择稍后登录，先完成可自动处理部分。实际补权限、建卡、商品价格配置和真实顾客/乌鸦审批验收仍须分别留存证据，不能以隔离测试代替。

交付及待办见[本次处理记录](interest-card-entry-20261023.md)。应用回滚候选为rc267，须按标准发布脚本核实同schema兼容，不回写旧卡或经营配置。
