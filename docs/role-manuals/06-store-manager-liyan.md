# 李艳：店长系统与工作说明书

## 岗位目标

李艳是当班现场第一负责人，负责人员到岗、门迎安排、桌台、服务、投诉、出品、收银和关店。普通问题在店长层闭环，重大资金或经营问题升级护古。

## 开店前

1. 检查当班员工在线、岗位、区域、档口和候补关系。
2. 检查预约、桌台、菜单售罄、库存、歌手排班和服务SLA。
3. 确认三沐、冷言志、申良良和服务团队设备可用。
4. 指定当班门迎：李艳、Tom、Jerry或Tyke；不安排冷言志门迎。

## 高频功能

| 场景 | 系统路径 | 现场动作 |
|---|---|---|
| 临客入店 | 预约 -> 登记候补/安排入座 | 核人数、区域、低消和主服务员 |
| 客人换桌 | 现场 -> 原桌 -> 目标桌 -> 确认转桌 | 先核容量、占用、订单和客人物品 |
| 主责忙碌 | 任务 -> 查看风险 -> 候补接管 | 明确谁去、去做什么、多久反馈 |
| 投诉 | 任务 -> 投诉 -> 接单/到桌/完成 | 2分钟内到桌，记录补偿和客人反馈 |
| 出品超时 | 订单/KDS -> 超时任务 | 找到具体档口和品项，不只催服务员 |
| 退款 | 收银/支付 -> 退款审批 | 核原支付、商品、原因和金额 |
| 关店 | 关闭桌次、清未完成任务、对账 | 每个差异有负责人和截止时间 |

## 换桌案例

L01四位客人希望转到L04：先确认L04可用且容量足够；系统执行转桌后，原桌释放、目标桌占用，但订单和支付仍属于同一桌次。不得在L04重新开一张单，也不得让客人继续使用旧桌二维码。

## 投诉案例

客人说“叫了三次没人来”：李艳先到桌承认等待事实，查看任务时间线，立即解决当前需求；再决定是否赠送。不能先争论客人是否真的点过，也不能让服务员自行删除超时记录。
