# 周边店推广：最简操作卡

核对时间：2026-11-18 10:24 CST。目的：合作店长发专属图，顾客来消费；系统记录推荐来源、优惠和佣金。

**后续本地优化，尚未部署：**已增加“复制这位店长上一批配置”、按优惠类型显示字段及开关状态回显。以下保留现行正式版本操作与当时检查结果；新版简化操作及测试见[本地优化记录](channel-config-ease-20261118.md)，部署前正式网页不会出现新按钮。

## 首次设置：管理员、营销、财务办好一次

1. **授权**：员工网页 → 系统配置 → 权限管理。营销及另一发布人需“查看＋管理周边店合作”；服务员需“核验周边店合作优惠券”及本桌操作权限；财务及复核人需“查看＋审核周边店合作结算”。发布后重新登录。
2. **登记商家**：工作台 → 周边店合作 →“1. 登记合作店和推荐店长”，填店名、店长、佣金结算主体、登记依据并保存。选“当前推荐店长”，生成官网开通链接，单独交本人设置账号。已有账号不要每天重置。
3. **启用与额度**：“营业配置、发券审批与异常处理”中设置全店总上限；到“2. 建立活动总额度”建活动。再选“活动及两入口开关”，同时勾选“确认启用、A员工代办、B顾客自领”。选“推荐人权限及联系人”，启用推荐人、允许本人确认结算单、选择酒吧联系人。
4. **收款资料**：“周边店合作财务”登记结算账户资料依据，由另一员工独立复核。确定佣金比例、计佣商品和观察期。

## 每天发图：营销操作，另一管理员发布

1. **生成**：选店长 →“3. 生成每日专属推广批次”→填当天优惠、数量、领取/使用时间、商品范围及佣金条款→生成暂停批次。
2. **发布**：另一管理员进入“独立审批发布或停发批次”，按新生成的优惠号码选中批次，核对后勾“确认启用”→确认办理。
3. **发送**：点该批次“下载推广图，单独发送”，核对店名、优惠、号码、有效期及适用商品，再发给对应店长；在“4. 登记发送与合作跟进”登记已发送。对方也能在官网 `/cooperation/` 下载自己的图。

**首轮填表示例（仅示例，未配置生产）**：1家商户、1批10张，金额优惠20元、满200元使用，每人1张、每客组1次、不叠加；领取为当天18:00—23:00，使用为当天18:00—次日02:00；佣金10%、观察7天。只选择已核定毛利的商品；计佣商品不另选时与优惠适用商品相同。条款版本可填“周边合作V1”，摘要写明“指定商品优惠后净实收计佣，退款冲减，客组结束并通过7天观察后结算”，生成原因写实际活动依据。

若只有这一批，全店和活动均至少需要10张发券额度、10份承诺额度、200元优惠成本额度。**这是优惠支出上限，不是广告投放费。额度累计使用，换日期不会自动清零；下批不足时须按实际计划调整总上限。**金额券不填百分比封顶、不选赠品。推广图必须用原图，不能改旧图上的日期冒充新批次。

## 到店以后：服务员、收银、财务接力

- **顾客**：微信扫一扫或长按识别推广图 → 打开优惠页 → 点领取；首次按提示登录本人会员账号。也可到店由员工代领，无需提前领取。
- **服务员**：打开实际桌台 →“周边店合作·核验绑定本桌”→输入图上优惠号码→选顾客或扫本人会员码→“查看优惠与顾客已有券”→确认绑定。复用已领券，不重复发；核对推荐店与优惠后再点单。官方小程序码由顾客微信识别，员工网页不要拿“扫描旧版业务二维码”扫它。
- **收银/出品**：顾客自点、员工代点都核对同一应付额；完成收款及出品后核对已兑现。赠品另点兑现，走正常出品送达；绑定不代表已经消费或核销。
- **转桌**：用系统转桌 → 新桌刷新绑定记录。原来源、次数及优惠上限跟随同一客组，不重新领券。断网结果未知时恢复原操作，不新建同一请求。
- **财务**：消费结束后重新核对原交易；退款会冲减计佣净实收。观察期届满后生成成熟结算单 → 合作店长官网确认 → 独立审批 → 登记线下付款待查账 → 实际付款并查账 → 另一员工核实结果。系统登记不会自动银行转账。

结算例：指定商品200元，减20元，实收180元，按10%计佣为18元；若再发生属于计佣商品的成功退款20元，则合格净实收160元、佣金16元。最终以实际分摊、退款及核算结果为准。
