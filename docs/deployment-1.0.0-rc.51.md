## 本次范围

- 员工协助点单固定显示“正常下单”和“权限赠送”，不再因权限异常静默隐藏赠送入口。
- 无赠送权限、岗位额度为零、缺少个人授权或授权过期时，页面显示具体原因并由服务端继续拒绝越权提交。
- 李艳、护古、老板及内置服务员授权改为长期有效；一次性迁移只延长内置授权，不覆盖管理员后续调整。
- 系统管理员乌鸦可以配置员工赠送和折扣权限，单笔配置上限5000元；仍不能替员工下单、赠送或收款。
- 赠送订单保持零支付、原因必填、商品范围和额度受服务端校验，并进入审计。
