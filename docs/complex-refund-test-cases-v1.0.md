# M-BOX 复杂现场退单测试案例 V1.0

执行日期：2026-07-31  
适用版本：1.0.0-rc.60  
范围：订单取消、商品退款、出品异常、预约定金、付费点歌、POS、现金、库存、桌账、跨营业日和AI权限。

## 状态定义

- **自动化通过**：代码、接口或浏览器测试已执行通过。
- **真实通道待执行**：必须使用星驿/微信真实商户或渠道账单证明。
- **门店现场待执行**：必须由真实员工、设备、现金或实物完成。
- **产品缺口**：当前缺少确定性业务能力，不能用模拟测试冒充通过。

## 放行要求

满足以下条件后，才能称“复杂现场退单完整验收”：

1. CRF-025 至 CRF-029、CRF-033 至 CRF-036 的产品缺口有明确业务决策和实现。
2. 星驿/微信完成真实小额部分退款、整单退款、失败重试和到账验证。
3. 实体POS和现金由三沐、李艳使用真实设备与实物完成现场验收。
4. 每笔证据包含原订单、商品、桌次、退款号、渠道交易号、申请人、审批人、时间和脱敏截图。
