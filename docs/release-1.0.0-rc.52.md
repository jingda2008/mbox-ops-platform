# M-BOX 1.0.0-rc.52 员工操作与现场服务简化改造

## 本次范围

- 引入可配置的L0-L3服务流程：客情信息不进入待办，快速服务一次完成，责任任务两步闭环，高风险事务保留完整权限和审计。
- 合并同桌同类开放请求，记录请求次数、首次与最近时间，并允许候补和授权跨区员工完成低风险服务。
- 简化员工桌台操作，开台后直接进入点单，稳定保留正常点单、权限赠送和桌账明细入口。
- 新增忙时聚焦模式，压缩任务卡片，并使用局部乐观更新、异步提交和失败恢复减少页面等待。
- 将商品履约分为成品待取送、现制、服务型和无需履约四类；多岗位员工可完成并送达。
- 后台新增服务流程和商品履约配置，并通过迁移020补充规范化服务与订单履约字段。
- I01、I02、I03旧模拟桌及互动区不再进入运行态、员工责任区和操作台；旧记录关闭或归档后继续用于历史分析。

## 验证

- 135个测试文件、1021项程序与业务测试通过。
- 39项Playwright跨端经营流程通过。
- 300个客人流程、60并发、900个HTTP请求压力验证通过，服务端5xx为0。
- 数据库迁移、规范化投影、生产镜像、移动端布局及权限隔离均通过CI验证。
