# 阿金：调音灯光系统与工作说明书

## 岗位目标

根据当日演出排班和点歌状态完成舞台音响、灯光和话筒保障。系统岗位以查看为主，不操作桌台、收款、退款和经营配置。

## 可见功能

- 现场：首页了解当前营业和舞台区域状态。
- 演出/点歌：查看当前歌手、下一位歌手、演出时间、点歌状态和客人备注。

## 每轮演出流程

1. 提前查看当前与下一位歌手、开始时间和预计结束时间。
2. 演出前完成话筒、返听、伴奏、灯光场景和备用设备检查。
3. 点歌进入已接单后准备对应伴奏，不以客人口头要求替代系统确认。
4. 歌手开始演唱时与付淳羽保持状态一致。
5. 设备异常立即告诉付淳羽和李艳，说明影响范围和预计恢复时间。

案例：系统显示下一位歌手6分钟后登台，但上一位愿意延长。阿金不能自行调整排班；由付淳羽确认两位歌手和点歌队列、发布或记录调整后，再切换舞台方案。

## 禁止事项

- 不因现场口头插歌跳过点歌确认和收费流程。
- 不用调音灯光账号修改歌手资料或排班。
- 不把设备故障隐藏到演出结束后才上报。
