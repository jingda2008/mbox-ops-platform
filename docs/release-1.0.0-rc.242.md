# 1.0.0-rc.242 原生历史补收配套后端与类型修复

原生App在确认已关桌订单欠款后，可能遇到金额或再次收款授权已经变化。本版新增`/payments/manual/closed-debt`专用路径，必须提交原欠款金额及授权，服务端在入账前核对；不一致时返回`HISTORICAL_COLLECTION_CHANGED`和`not_committed`。工作台公布支持能力。成功请求仍使用原幂等键重放；旧网页`/payments/manual`调用保持兼容，旧服务器不支持新路径时不能误入账。

同时修复48项广范围服务端类型错误：旧退款查询补原金额/币种，审计脚本补类型和缺失数据检查，纯队列函数从React页面移出，修正NodeNext导入路径。严格检查范围保持不变。

以包含rc.241的main为基线整合，保留收银复核查询性能和手机布局修复。本版无数据库迁移，schema250，未变更小程序、原生安装包或门店权限。

本地类型/测试/构建、合并CI、标签镜像、备份读回、部署与现场验收分别留证。不使用真实收退款或修改营业数据作冒烟测试。发布后只读验证版本、页面和原生补收能力；真实资金与手机现场验收仍独立进行。
