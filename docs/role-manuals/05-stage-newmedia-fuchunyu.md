# 付淳羽：新媒体舞台运营系统与工作说明书

## 岗位目标

维护歌手资料、歌单和当日演出排班，完成生日、点歌和舞台互动闭环。点歌不是线上直接扣款：先确认可安排，再由服务员或现场人员收费并登记凭证。

## 演出/点歌功能

| 功能 | 使用方法 | 完成标准 |
|---|---|---|
| 歌手资料 | 录入照片、简介、亮点和风格标签 | 客人点击歌手能看到真实完整资料 |
| 歌手曲库 | 为每位歌手维护歌曲、原唱、时长和价格 | 只显示该歌手确实能唱的歌曲 |
| 演出排班 | 设置每轮歌手、开始/结束、点歌开放时间 | 当天排班与舞台实际一致 |
| 点歌确认 | 核对歌手、时间、歌曲和客人备注 | 可安排后才进入待现场付款 |
| 履约 | 收款登记后接单、开始演唱、完成 | 每个状态与现场同步 |
| 无法履约 | 说明原因并进入退款队列 | 客人得到反馈，资金有后续责任人 |

## 自定义点歌案例

客人点了一首歌单外歌曲：

1. 系统显示“待确认”，不能先向客人保证。
2. 询问当班歌手和舞台时间，确认是否能唱、是否需要延长。
3. 可以安排时点击确认，服务员到桌说明价格并现场收费。
4. 登记物理POS或现金凭证后，歌手再接单。
5. 不能安排时点击无法安排，用自然话术给客人备选歌曲。

## 排班注意

门店12:00营业不代表开始表演。白天可以正常显示下午茶和咖啡服务；演出按20:30后的具体排班显示。排班变化必须发布新版本，不能只在群里通知。
