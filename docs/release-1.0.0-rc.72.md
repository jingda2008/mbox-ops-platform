# M-BOX 1.0.0-rc.72 本地候选说明

日期：2026-08-13
状态：工程候选通过，尚未部署
线上基线：`1.0.0-rc.71`

## 本轮范围

- 固定桌码在未开台、无效入口和开台后的客户引导保持单一且可恢复，不再要求更换静态桌码。
- 公众号预约不提供具体桌位自选，不在申请阶段绑定桌台；保留位置偏好，门店确认后仅从约定到店时间开始保留10分钟，超时进入未到店流程。
- 所有异步操作的成功、失败和下一步提示在不打断输入的前提下自动进入视口。
- 管理员按岗位或员工配置权限、审批额度、数据范围和工作台入口；服务端整批事务写入、复核、审计和Outbox，失败全部回滚。
- 配置能力由服务端目录定义，前端不能创造未登记能力或替换入口地址；版本初始化按单项合并，不覆盖管理员已接管项目。
- KDS、支付、退款、通知和调价授权只认规范化权限关联与有效员工例外，不再使用旧岗位能力数组作为回退。
