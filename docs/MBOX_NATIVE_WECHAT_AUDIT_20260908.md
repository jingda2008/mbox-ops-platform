## 3. 已确认问题及依赖

### NA-01 / SYS-092（既有P1）：服务返回后持续禁用

原生复现步骤：加冰按钮 → 测试后台创建请求并返回201，但暂缓送达页面 → 点击“查看服务进展”离开服务页 → 放行原201响应 → 原生返回上页。

结果：`submittingId`仍是`ice`，加冰显示“正在通知”，其余服务按钮disabled=true；没有错误提示。请求并非仍在后台处理中，也不是支付查询锁住桌台。正常新建服务页可恢复，但同一页实例返回不会恢复。

依赖链：`pages/service/index.js:43`离页使请求代次失效 → `:98`跳过旧结果 → `:116`连finally清busy也因代次不一致跳过 → `onShow`仅读订单，不恢复写入状态 → WXML按`submittingId`禁用全部服务按钮。既有进展轮询、点单购物车/快捷服务同型风险仍按SYS-092一并修复，不能移除换桌保护。

修复标准：区分页面展示代次、桌次身份、写入尝试；离开再返回先恢复可操作状态并核对原请求，不能通过盲目重发制造重复需求。延迟成功/失败、响应丢失、同桌返回、换桌、轮询交错均补回归；不影响其他桌或整个点单页面。

证据：`service-lifecycle-held.json`、`service-lifecycle-release.json`、`service-lifecycle-stuck.png`、`service-lifecycle-disabled.json`。
