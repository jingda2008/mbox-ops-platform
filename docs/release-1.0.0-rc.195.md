# M-BOX 1.0.0-rc.195

本版本只增加微信服务号安全模式回调入口和可选配置，不修改既有支付、小程序、会员、库存、打印或门店业务行为。未提供服务号回调配置时，新路由不注册，运行行为与rc194一致。

`GET /api/wechat/service-account/callback`校验微信`msg_signature`、10分钟时间窗、AES-256-CBC/PKCS#7密文和解密尾部AppID，成功后仅返回解密的`echostr`。伪造签名、过期请求、无效密文或AppID不一致统一拒绝，不输出密钥和密文细节。

`POST`同样完成签名与解密，但关注、取消关注和消息事件的持久消费者及幂等身份绑定尚未接通，因此当前明确返回503，不伪装已接收。公众号身份绑定、模板审核、真实关注事件和真机送达仍按SYS-219开放。

PR #226 的完整质量、数据库、浏览器和性能检查已通过。正式发布仍须完成rc195不可变标签与发布CI、标准部署、三项生产配置安全注入、公网无参数拒绝检查，以及微信公众平台使用同一组Token/EncodingAESKey的真实URL校验。
