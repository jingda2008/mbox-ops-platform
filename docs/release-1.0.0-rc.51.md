# M-BOX 1.0.0-rc.51 赠送点单入口与授权有效期修复

## 本版完成

1. 员工协助点单固定显示“正常下单”和“权限赠送”两个订单类型，不再因授权异常静默隐藏。
2. 未配置、额度为0或授权过期时，点击“权限赠送”会显示具体原因，但服务端仍拒绝越权提交。
3. 修复李艳、冷言志、护古和陈方宇等系统预置经营授权随初始班次过期的问题。
4. 保留按员工配置赠送商品、分类、单次额度、累计额度、次数和有效期的管理能力。
5. 赠送订单继续按本人权限校验，客人零应付，商品、库存、成本、原因和操作人全部留痕。
6. 系统管理员乌鸦可配置经营授权，但未配置本人经营授权时不能亲自赠送或批准经营订单。

## 数据迁移

- 本版不新增SQL结构迁移。
- 对五条已知系统预置经营授权执行一次性有效期修复，不增加新员工授权，不改变额度或商品范围。
- 为系统管理员补齐经营授权配置权限和5000元配置上限，不增加本人赠送执行权限或支付权限。
- 迁移完成后写入审计事件；管理员后续修改、暂停或撤销授权时，系统不会再次覆盖。

## 发布验证

- 验证李艳同时看见“正常下单”和“权限赠送”，可以进入赠送点单。
- 验证Tom可按本人商品范围和额度创建零支付赠送订单。
- 验证Jerry未配置本人授权时看见入口和原因，但不能提交赠送。
- 验证赠送原因、库存、出品、审计和支付隔离逻辑保持有效。
- 候选版本通过后才切换正式流量；失败时保留1.0.0-rc.50回滚容器和数据库备份。

## 发布边界

本版只修复赠送入口和系统预置授权有效期，不扩大任何员工的角色权限。管理员仍需为非预置员工单独配置本人授权；退款、折扣和其他高风险操作不受本版影响。
