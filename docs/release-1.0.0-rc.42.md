# M-BOX 1.0.0-rc.42 经营损益中心

## 本版完成

1. **统一损益看板**：按北京时间和门店06:00营业日切换，展示日、周、月、季度、年度的净营收、成本、毛利、预计经营利润和利润率。
2. **营收权威口径**：只计入支付成功和已核销团购结算，扣除退款；物理POS待对账单独提示，不提前算作已确认收入；关联同一订单的支付与团购券自动去重。
3. **酒水与餐食成本**：优先使用订单触发的库存消耗及配方快照；未建立库存消耗的订单按下单成本快照列为预估并提示数据质量。
4. **完整经营费用**：支持员工、歌手、乐队、房租、水电煤、营销、支付手续费、维修、税费和其他费用，保留对方、单号、备注、录入人和审计记录。
5. **预计与实际双口径**：营业前可录入预算；账单晚到后以实际记录替代对应预估并自动重算历史周期，原记录不删除。
6. **周期成本**：支持每周、每月、每季度和每年的周期模板，可按发生日确认或按服务期逐日分摊；实际账单只能关联合法账期。
7. **采购移动平均成本**：实际收货时按现有库存与本批采购价更新商品或原料移动平均成本，历史订单和库存流水继续保留当时成本快照。
8. **权限与审计**：老板、运营负责人和店长可管理费用；收银员可查看损益但不能新增、作废或修改费用；所有写操作均需原因、幂等键和操作人审计。

## 财务口径

- 商品采购支出不在采购当天再次全部计入经营成本，避免与销售出库成本重复计算。
- 房租、月薪、演出包月费等可按服务期摊销；临时歌手、维修和一次性费用可在发生日确认。
- “已确认利润”只使用已确认收入与实际成本；“预计利润”同时纳入预估商品成本和待确认费用。
- 已作废费用不参与报表，但作废人、原因和时间继续保留。

## 专项验收

- 日、周、月、季度、年度边界计算通过。
- 迟到实际账单替代预估并重算历史月份通过。
- 周期成本展开、单账期实际替代和非法账期拒绝通过。
- 支付、退款、团购券跨期去重及POS待对账隔离通过。
- 库存真实消耗优先、订单成本预估兜底通过。
- 权限隔离、运行时旧角色迁移和费用写入审计通过。
- 桌面与iPhone宽度页面无横向溢出，费用录入后看板即时刷新。

## 发布边界

本版可进入员工验证环境。真实采购价、工资、歌手与乐队合同、房租、水电煤账单及税费仍须由门店按实际资料录入；系统不得用示例数据替代财务事实。213条经营TC与真实支付、硬件、门店网络和岗位现场签字的商业生产门禁不因本模块自动解除。
