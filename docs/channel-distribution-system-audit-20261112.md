## 2. 已复现的问题

### CHANNEL-WALLET-COST-20261112-08：顾客券包接口泄露赠品内部成本（P2）

- 位置：`server/normalized/channel-distribution-repository.ts:187`。
- 原因：wallet直接返回规则/赠品替换快照中的整个offer对象，包括costMinor；单独优惠预览虽然去除了成本，券包接口未去除。
- 复现：在临时测试库建立真实赠品/库存、本人领券；预览接口不含成本，但本人券包HTTP响应包含costMinor=100（测试样例金额，非门店真实成本）。
- 影响：当前界面未直接展示，但顾客接口响应可读取内部赠品成本；不属于跨顾客身份越权或银行密钥泄露。
- 修复方向：顾客和外部合作人分别定义字段白名单，避免返回内部规则整对象；覆盖初始赠品、替换赠品、券包与预览接口。
- 关闭条件：上述实际HTTP响应不含内部成本；商品、赠品数量、使用规则及原库存核销回归仍通过。

### CHANNEL-WALLET-PAGING-20261112-09：券包超过100条时旧有效券缺少自助使用入口（P2）

- 位置：`server/normalized/channel-distribution-repository.ts:192`；`miniprogram/pages/channel-coupons/index.wxml:9`、`:18`。
- 原因：券包只返回最新100条，无分页；推广页虽然取得既有券ID，却仅提示“下方可查看和使用”，实际使用按钮依赖券包列表。
- 复现：本人已有1张旧的有效券，再合法领取100张新券；重新打开旧券推广入口，预览明确显示旧券已领取，但券包100条中没有原券，页面无法选择该券自助使用。
- 影响：券没有丢失、额度没有重置；员工按本人和优惠号码仍可协助核验。此问题阻断部分顾客的自助路径，需在上线前补齐。
- 修复方向：提供分页/按状态查询，并确保推广入口能直接读取与使用本活动的本人有效券；不能只增大LIMIT。
- 关闭条件：超过100条、混合有效/过期券、合并身份、按旧图进入和本人权限场景均可找到正确券，仍不得访问他人券或重扣名额。
