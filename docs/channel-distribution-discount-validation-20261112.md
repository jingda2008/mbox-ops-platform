## 如何配置和使用

后台渠道推广批次选择“百分比减免”：九折填10，八五折填15；该字段是减免百分比，不是付款比例。填写减免封顶金额、适用商品、使用门槛、领取/使用时段及N/K/L；选择合作店长与活动，保存后按现有复核/开放流程执行。批次保存默认为暂停，不直接对外生效。

顾客扫描推广图领取到本人账户，到店绑定当前客组；或服务员使用图片优惠号码协助领取绑定。点单时确认渠道报价，后台按符合条件商品的累计金额计价。报价与当前人、桌、购物车绑定，失效需重算。当前渠道优惠与会员券/会员卡价/积分选择互斥。领取额度和客组限用规则保持不变。

## 本次模拟结果

| 情况 | 参数与结果 |
|---|---|
| 九折、八五折 | 100元分别减10元、15元；采用整数分计算，0.33元减15%按四舍五入减0.05元 |
| 混合购物车 | 适用饮品200元八五折，加不参与优惠商品30元；减30元，合计应付200元，不参与商品优惠为0 |
| 封顶及并发 | 八五折每次客组最多减20元；两个100元报价并发提交，只一笔成功减15元；另一笔重新报价减5元，应付95元；总减免20元，过时报价不生成订单 |
| 累计门槛 | 满200元八五折：第一笔100元未达门槛，原价；第二笔100元减30元应付70元，累计实付170元；不修改第一笔历史订单 |
| 转桌、加单及退款 | 原有测试本轮重跑：九折最多减15元，转桌前100元实付90，转后加100元实付95；净收185元按10%计佣18.50元，退20元后16.50元 |
| 全退不恢复已用封顶 | 100元八五折实付85元，成功全退85元；净收和应计佣金均0，已兑现15元优惠仍记已使用，不重新领用封顶 |
| 参数错误 | 减免为0、超过100%、非整数基点或封顶为0，服务端规则拒绝 |
| 顾客端显示 | 预览及本人券包均展示“优惠15%，最多¥20.00”，没有把减免15%解释成付15% |

重要：设置封顶后，不保证整单始终达到宣传折数。200元八五折但最多减20元，实付180元。建议文案“指定饮品八五折，单次客组最高优惠20元；满×元可用”，附适用商品、有效期、限用与互斥说明。
