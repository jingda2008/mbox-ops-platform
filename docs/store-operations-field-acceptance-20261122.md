## 当班岗位操作单

| 岗位 | 怎样操作 | 怎样算通过，留什么凭证 |
|---|---|---|
| 值班经理＋交班经理 | 用核对索引找出 9 条原客诉，逐条核实线下是否处理及后续负责人。在验收桌建一条投诉，结台并重新开同一桌号。经理甲用员工手机进入「任务」，在旧客诉上点「我来跟进」，经理乙刷新，核对桌次、创建时间和负责人；切换普通服务员检查权限。经理填写实际处理结果并完成，再刷新。 | 原客诉一直对应原桌次；两台手机显示同一跟进人，接手后仍在待办；普通员工不能认领或结案。完成事件只有一笔并保留处理结果，新桌次不受影响。留原任务号、两次岗位交接和事件时间；无实际处理结果的旧客诉保留跟进。 |
| 收银＋独立复核财务 | 通过原付款号在星驿商户账单中查终态，先查 67 笔人工待核和 1 笔 released，再依据独立账单复核 440 笔历史尝试。对照原单、其他成功收款、退款及渠道参考号。分别复核上述两笔取消单以及吧台交付记录。此项可由持账单权限的财务远程做。 | 同一订单只算一次。逐笔写明可验证的成功、失败、已关闭或尚无终态，保留脱敏渠道凭据和核对人。渠道成功须能与账内唯一到账对应；零待收的原单无需再向客人收款。缺账单或交付凭据的记录留待核。此次仅核对，不动历史款项或账务。 |
| 库管＋采购／成本会计 | 取橙宝橙汁（28 条）、橙宝菠萝汁（13 条）、汤力水（8 条）的原采购单和收货单；核对批次、瓶数、每瓶净含量、总额、配方用量与底账单位。对另 115 条按原物料和发生时间抽查当时凭据。 | 同一批次的采购总额、基础单位数量和可追溯单位成本相符，记录来源和差异。无法证明当时成本的留空。单据可预先远程核对，包装规格与实际用量由门店确认。 |
| 吧台／后厨＋库管 | 用已登记成本的原料制作一份延后结算单，再用同一物料做即时支付对照；记录出品数量、前后库存、所用配方及单位。另用批准的验收资料复核真实零与未知成本显示。 | 每次实际消耗只扣一次，数量与制作一致；新流水保留扣库时的单位成本，零和待核可区分，看板缺成本条数与对应营业日明细一致。留原单号、出库号、出品和报表照片。 |
| 两名楼面员工 | 在员工常用小屏打开已付款未结台的验收桌，从上方入口改人数；在提交后切换 Wi-Fi／移动网络，必要时点同一次保存的重试。另一部手机刷新核对。 | 入口易找到，保存期间显示正在保存人数；两端最终人数一致，一次有效修改对应一条审计，付款和桌台状态符合预期。记录机型、原桌次、时间和回显。 |
| 吧台／后厨出品员＋打印设备负责人 | 各工位按原单对照设备屏、纸票、份数和备注；在批准的测试时段断开打印桥后恢复，核对同一任务。 | 纸票确实从正确工位打印，内容与订单一致；恢复后无漏票或重复制作。留纸票照片、任务号和相应工位签收。 |
| 营销／顾客端＋收银＋财务 | 先核对微信生产版发布凭据。两台真机试新券领取、绑桌、消费核销；在受控缺货样例中复核保券及补货重试。用独立验收单另走批准的小额收款、原路退款和日结，审批按权限分岗。 | 领取与绑桌只登记权益，实际消费时核库存，重试只兑现一次。资金验证须有原交易、原路退款渠道结果及日结对应分录。保留版本、券号、订单号和脱敏渠道凭证。 |
| 店长／验收记录人 | 按当前版本的经营基线逐条分派，补做门店网络、交班缺岗、门迎、演出音响／灯光、硬件故障和应急恢复；将历史验收与本版重验分别登记。 | 每条保留执行岗位、实际时间、设备或工位、对象号、实际结果与凭证，失败留原记录并复测。没有外部凭据的资金项目保持待核。 |

每次验收登记执行人、时间、版本、设备、业务对象号、实际结果和脱敏凭证。原核对索引由门店本地保管。

## 挂账制作和收退款显示（候选版本，到店待验）

| 岗位 | 怎么操作 | 怎样算通过 |
| --- | --- | --- |
| 服务员 | 在同一验收桌用小屏分别提交员工挂桌账、员工立即结算，再由顾客自助点一单。另一部手机完成收款。保持开台，改一次人数，提交后切换网络再打开原桌。 | 明确选挂桌账的单显示未收齐、可制作。其他两单在各自收齐前均显示待收款。两端看到同一原单与相同人数，已付款仍开台，重试只有一笔修改或下单。 |
| 收银 | 用批准的验收单核对部分收款、合并收款、全退原单和未分配预收款。遇扫码结果未知，从原付款号查渠道。在“现场”和“收银与退款”按同一桌次和读取时间核对。 | 两页的原单累计已收、成功已退、净收、待收金额和原单数一致。合并现金只有一笔登记，各原单分摊之和等于现金总额。无重新收款授权的已全退原单显示“查看退款记录”。已结清但原扫码仍未决时，待收为零，保留原付款核对提示。未分配预收单列，已抵扣金额只进入对应原单一次。 |
| 吧台、后厨 | 同一张验收单各选一个对应工位商品。观察两工位屏幕、实际出纸、出品交接。按现场授权断开打印桥后恢复，回读原票。 | 员工挂账可制作，票上标明制票时待收。普通单支付中两个工位均无任务、无纸票。按分摊收齐后，每个相应工位可接对应商品一次。核对各自配置份数和实物，打印回执不替代交接签收。 |
| 值班经理、财务 | 对异常按桌次、原单号及原付款号核对。本次涉及的历史订单仅调阅渠道对账、退款凭证、现金交接与工位签收。 | 同一异常有一条可跟进提醒。VIP5 实物送达、VIP8 退款原因和现金交接均有独立证据后再签字；缺证保持待核。 |
