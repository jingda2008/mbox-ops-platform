- 以 origin/main 5ea213cc1b6d05e4ca9545e1fd1089e4b1281ced 为基线；近期本地和远端已提交分支均已包含在主线。稳定目录的13处修改是本次开发目录的子集，保留原目录。
- 新增 normalized schema198—202；旧迁移不修改。门店配置2026.09.13-v24，服务人员可申请退款，已支付仍由另一人一次审核，退款不超过原实付剩余额度。
- 数量售后正式配置 MBOX_QUANTITY_AFTER_SALES_ENABLED 默认false，验收候选通过后本店显式启用；同版本设false停止新增、保留原申请和制作/退款/实物恢复。不得在已有新数量事实后直接退回不认识schema202业务事实的rc191；故障优先同镜像关闭新增并恢复原流程。

- 保持已验收打印链路；Windows升级/诊断/恢复工具源码一并存档，不在本次后端部署时执行终端升级。被撤回1.0.3工具保持历史撤回标记，不能重新当最新安装包发放。
- 五份微信协议V2保持送审稿；主体、第三方及保存期限等事实未核实的内容，不通过本次代码发布写入正式协议版本。
