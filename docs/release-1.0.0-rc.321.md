# 门店后台 1.0.0-rc.321

员工可在「现场桌台 → 今天的消费条件」设置最低消费、门票或同时启用。未设置的营业日允许正常点单，无低消。购票人在分配桌台完成识别后整桌可以点单，两项同选时持票桌免低消，普通桌按开台金额。

员工整桌转移后，顾客扫新桌码进入原桌账，朋友可以下单、自己结账，购票人也可以从桌账代付。原桌重新开台使用新桌次。顾客凭条显示购票会员或本单实际获分会员的卡号、等级与脱敏手机号。下架后可以结束满足条件的场次，现场账单按原价、积分抵扣及实付展示。

数据库迁移 376、377 增加营业日规则、逐票桌次关联及按单读取获分人的能力。部署包包含员工后台、服务端与数据库。微信客户端独立发布。

2026 年 11 月 28 日 03:03（北京时间）门店后台已切换到主线提交 899dab0b。公网就绪检查读回 schema 377、可写及后台作业健康；首页、顾客桌台、预约和员工现场入口通过发布后检查。营业库只读核对时有 34 个已开桌次，当时营业日为 11 月 27 日，门票与低消均未启用。门店可按需设置营业日条件。本次未上传或发布微信客户端，原路支付和热敏打印以现场凭证验收。
