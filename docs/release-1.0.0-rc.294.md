# 1.0.0-rc.294 — 打印故障网页主动提醒

发布范围：后台/API/员工网页，继承主干schema315打印诊断；本次无新增迁移。用户明确要求“提交 合并 部署”，覆盖先前晚间等待安排。

员工网页每10秒按当前岗位读取打印失败、90秒积压和持久故障，提供处理指引；可主动启用声音、暂缓5分钟，持续3分钟突出管理员提醒。现行制作/送餐角色按数据范围裁剪，专用屏故障提示不遮挡操作。详见[实现和验证](print-active-alerts-20261114.md)。

原现场1.0.11桥兼容；不安装1.0.12或1.0.13候选，不重打历史任务，不修改员工权限。小程序/官网不另行上传。网页隐藏或电脑休眠时不能保证提醒；声音需点击激活，实体出纸和真实扬声器仍需现场验收。

## 发布门禁与回退

最终提交、主干和标签的完整CI必须通过；从标签生成不可变镜像与Release，按标准deploy-release.sh执行生产备份核验、schema315增量迁移、零流量候选、切流及正式入口验证。此前rc293候选未发布的诊断/开台竞态修复一并包含，不能只把本次UI变化视为全部上线差异。

原镜像与回滚容器由标准流程保留，故障使用rollback-activated-release.sh；schema315增量表保留，不降库。经营TC未执行/阻塞状态保持真实，RC工程验证不等于完成商业或门店实机验收。
