# M-BOX 1.0.0-rc.81 OCI镜像校验兼容修复候选

## 本版目的

保留`rc.80`的同桌订单与支付接力能力，修复阿里云激活脚本只接受OCI多架构索引、错误拒绝Docker合法单架构归档的问题。

## 本版变化

- 发布校验同时支持OCI镜像索引和单架构OCI镜像清单。
- 发布清单使用归档内带标签引用对象的摘要，不再使用受构建机Docker存储模式影响的本地镜像ID。
- 两种格式都继续校验归档SHA256、引用对象摘要、Linux/AMD64配置和镜像配置摘要。
- 镜像加载后再次比对Docker镜像ID、Git提交标签和版本标签，任何不一致均在迁移和切流前终止。
- 不修改支付、订单、库存、预约、权限或客户页面业务逻辑。

## 自动化验收

- 完整质量、浏览器、数据库、规范化数据库、规范化浏览器和持续负载测试。
- 阿里云发布流程静态约束测试，覆盖两种OCI媒体类型和最终镜像ID校验。
- 不可变发布包、OSS证据、数据库备份、候选健康检查、浏览器验收和自动回滚。

## 验收边界

本版用于开发验证环境发布。真实星驿支付、退款、物理打印机和微信正式身份仍须按独立联调计划验收；不得用模拟支付结果代替真实渠道回调或主动查单证据。
