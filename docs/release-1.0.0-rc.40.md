# M-BOX 1.0.0-rc.40 紧凑购物车操作栏

## 目标

缩小员工协助点单和顾客点单页面底部购物车的视觉占比，让商品菜单保留更多有效空间，同时维持现场快速操作所需的触控尺寸。

## 本轮升级

- 桌面端固定购物车栏高度由约 76px 缩小到 60px。
- 手机端固定购物车栏高度由约 70px 缩小到 60px。
- 压缩上下留白、图标、状态文字和主操作按钮宽度，保留现有配色和信息层级。
- 商品金额继续默认收起，需要时打开购物车明细核对。
- 购物车展开面板位置随底栏同步调整，不遮挡操作栏。
- 左侧购物车和右侧主操作区均保留至少 44px 的有效点击高度。

## 验证

- 桌面 1440x900 实测：底栏 60px、左右操作区 44px、无横向溢出。
- 手机 430x932 实测：底栏 60px、左右操作区 44px、无横向溢出。
- 新增桌面和手机尺寸防回归断言。
- 213 条经营 TC 的商业发布门禁结论不因本轮视觉调整而改变。
