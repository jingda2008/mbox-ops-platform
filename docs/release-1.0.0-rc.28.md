# M-Box 1.0.0-rc.28 验证发布说明

## 本次修复

- 员工工作台轮询由固定2秒改为自适应调度：数据变化时5秒、无变化时逐步退避到20秒，后台页面暂停，回到前台立即刷新，并保留单飞请求保护。
- 预约页面不再重复下载全店经营快照，仅在前台每10秒读取预约数据，回到前台立即同步。
- 北京时间和演出倒计时拆成独立叶子组件，秒级更新不再触发员工工作台或客户点单页整页渲染。
- 客户情绪图片改为WebP，六张图片由约356KB降至约48KB；菜单图片启用懒加载和异步解码。
- 指纹静态资源启用一年不可变缓存，品牌和菜单资源启用短期缓存与后台更新；HTML和敏感API继续禁止陈旧缓存。
- Service Worker保留离线应用外壳，并明确排除支付、会员、员工状态和其他敏感API数据。
- 服务端按经营状态版本缓存岗位投影、权限、指标和ETag，通知与SOP调度复用同一状态快照，减少PostgreSQL重复读取。
- 后台调度器由每秒一次调整为每2秒一次，并在同一轮任务中复用快照；发生写入后才重新读取已提交状态。

## 性能验证

- 本地10秒采样：员工端脚本执行时间下降约87.5%，客户页下降约73%。
- 1MB经营状态的后续条件请求稳定返回304，服务端本地耗时约3毫秒。
- 云端候选版本首次工作台请求后，连续条件请求均返回304和0字节；Cloud Run服务端处理约30至69毫秒。
- 300人次夜间负载测试共900个HTTP请求、1200项检查，失败率0%，HTTP p95为22.96毫秒，5xx为0。
- iPhone 14 Pro Max视口宽430像素，页面内容宽430像素，无横向溢出；云端冷启动约3.4秒，缓存后约1.5秒。
- Google Cloud验证环境位于境外，上海移动网络仍有约1秒级公网往返延迟；正式商用时需迁移到更接近门店的国内基础设施或CDN。
