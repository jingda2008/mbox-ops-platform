# M-Box 1.0.0-rc.26 验证发布说明

## 本次修复

- 营业日切换后，员工启动快照只下发当前营业日的桌次、任务、订单、出品、支付、库存流水、点歌、SOP、设备命令和现场审计；历史记录继续完整保存在数据库中。
- 历史支付、退款和预约定金不再进入新营业日的现场阻断；历史财务补交与复核继续通过按营业日结算接口处理。
- 切日时自动终止尚未完成的订单审批、权益锁定、盘点确认、库存审批、设备命令和打印任务，避免旧操作在次日继续执行。
- 客人点击情绪小手后先在本机立即高亮，服务任务异步送达；送达失败自动恢复原状态，不显示虚假成功。
- 服务任务返回后直接合入客户当前页面，情绪选择不再额外刷新整页数据。

## 性能实测

- 使用`rc.25`云端真实老板快照复算：员工启动JSON由约762KB降到约161KB，减少约79%。
- 线上gzip传输由约93KB降到约30KB。
- 历史桌次14→1、订单18→1、出品32→1、支付13→1、任务80→5，归档任务不再下发到现场工作台。
- 真实Cloud Run手机浏览器中，情绪小手在约67ms内高亮；模拟后台送达失败后可正确回滚，页面无横向溢出。
- 验证环境Cloud SQL仍为`db-f1-micro`，员工首次读取服务端耗时约1.8至2.2秒；本版本降低传输和渲染成本，但数据库聚合JSONB读取延迟仍需在商业化迁移中解决。
