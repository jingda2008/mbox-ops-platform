# 1.0.0-rc.270 菜品可选剩余份数

后台商品编辑可单独保存剩余可售份数，包含兴趣卡限定商品。留空沿用原管理，0售罄，正整数由原订单流程预留或扣减；取消按原规则释放，成交退款不自动补回，门店手动补充。禁止旧页面覆盖新销售数量，清空再启用不会被旧取消回执增加份数。

schema283只增加可空数量字段、预留流水及可售判断，现有商品全部默认NULL。复用原商品配置权限、幂等与审计；不改旧活动、旧卡、价格或原料成本。不代门店填写实际备货数字。

顾客继续使用原“暂时售罄”状态，无小程序源码改动，无需微信重新提审。支付宝不上传、提审或发布。

隔离数据库、完整回归、手机尺寸组件异常恢复及标准CI/发布分别记录在[实施记录](product-sale-quantity-20261024.md)。当前候选未部署，不能以测试代替线上或真实营业验收。应用回滚前须核对是否已启用份数限制；旧rc269不执行新限制，不可在存在已启用配置时直接回滚继续营业。
