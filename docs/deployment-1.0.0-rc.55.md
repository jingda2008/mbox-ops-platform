## 本次范围

- 公众号预约页提供“直接预约”和“座位自选”两条路径，不要求客人先进入独立营销页面。
- 座位自选使用正式61桌目录，并按舞台前、室内中区和室外区域聚焦展示。
- 客人选择桌位时可查看实时可预约状态、建议人数、定金和最低消费。
- 同一桌位同一经营时段由服务端事务防止重复预约；取消预约会释放桌位。
- 自选桌号、分配方式和预约信息进入店长预约台，定金继续保持门店人工确认边界。
- 店长任务工作台支持协助完成、亲自接管和安全转派；原任务、实际执行人和变更历史保留。
- 浏览器CI任务时限调整为25分钟，测试内容和发布门禁未减少。
