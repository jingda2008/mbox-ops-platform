M-BOX 打印桥 1.0.14，适用于正在运行的门店原版 1.0.13。
完整解压 ZIP 到一个新文件夹。在两台打印机没有待出小票时，双击 MBOX-OneClick-Upgrade.cmd，按 Windows 提示允许管理员操作。
升级程序核对版本、备份、检查队列及在途单、确认新版心跳。若提示仍有打印任务，请保留队列，先处理现场故障；不要清队列或强制升级。失败请保存 upgrade-last-result.json。
吧台和厨房使用原有配对、驱动和票面。仅观察 Windows 队列和驱动报告的状态。队列里看不到任务不能证明纸已出来。
安装后请通知运维核对版本、两个队列的观测时间和一笔正常营业单。安装不会自动打印测试票。
如提示队列有任务，可双击 MBOX-Check-Queues.cmd，在本文件夹生成 MBOX-Queues-日期时间.json，交给运维按桌号核对。这个检查也可以在升级前运行。
