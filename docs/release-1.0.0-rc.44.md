# M-BOX 1.0.0-rc.44 全员菜单搜索

## 本版完成

1. 客人扫码点单、客户平板点单和员工协助点单共用同一套菜单搜索能力。
2. 支持按商品名称、分类、规格、商品编号、描述和后台标签即时筛选。
3. 支持多个关键词组合查询，并统一处理大小写、全角字符和多余空格。
4. 搜索框显示匹配数量，支持一键清除；无结果时给出明确提示并可恢复完整菜单。
5. 手机端搜索框固定在分类栏下方，不遮挡菜单，不产生横向溢出。
6. 搜索只在已启用且当前入口有权展示的商品中执行，不会让客人看到内部或隐藏商品。

## 验证证据

- 菜单搜索单元测试：商品名、分类、规格、SKU、描述、标签、多关键词和字符归一化全部通过。
- Playwright客户手机端：搜索“啤酒”和“330ml”、清除恢复、无横向溢出通过。
- Playwright员工协助点单端：搜索“鸡尾酒”、清除恢复、后续购物车和支付流程通过。
- 全量检查：125个测试文件、933条测试通过；生产构建通过。

## 发布边界

本版仅进入员工验证环境。213条经营TC当前为147条通过、50条未执行、16条阻塞，仍有66条P0/P1未通过商业生产门禁；真实支付、退款、硬件和门店现场验收状态不因本次菜单搜索升级而改变。
