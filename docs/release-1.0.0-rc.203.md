# M-BOX 1.0.0-rc.203

本版整合主线结账单名称、陆家嘴中心抬头、新编号与连续补打追溯，以及侧会话退款复核权限配置。新增管理员“退款复核”入口，一次发布岗位复核权限和有效人民币单次额度，展示员工缺权限/缺额度/明确禁止情况。新授予权限缺额度时整批回滚；通过和驳回都保留禁止自审、权限、额度和原申请状态保护。

代码部署不自动配置真实人员或审核BAR2原退款。门店管理员须确定其他审核岗位及具体额度，发布后由合格员工处理原申请。原成功退款保持，不执行新退款。手机320px和桌面1280px配置/回读及隔离权限、票据、补打测试需在集成版本验证。

包含rc.201/202全部修改，两个旧标签未部署且保持不可变。Windows沿用现有1.0.9，schema203不变，支付/服务号和数量售后配置须完整保留。详见[结账单记录](checkout-ticket-branding-20260915.md)及[退款复核记录](refund-review-configuration-20260915.md)。
