## 修复后的操作

1. 管理员进入员工网页“系统配置”中的权限管理，选择岗位或员工例外。
2. 权限类别选“周边店合作”；搜索“周边店合作”“渠道”或内部权限代码均可找到对应项。
3. 按岗位授予下表能力并填写原因、发布权限修改。此处“发布”指管理员保存权限配置，不是部署程序；本轮没有在生产执行。
4. 员工刷新工作台或重新登录，可见独立“周边店合作”入口：`/staff/channel-partners`。不再依赖会员运营权限。旧`/staff/member-management#work=channel-partners`仍进入相同业务页并使用相同权限门禁。

| 岗位需求 | 最小合作权限 | 可操作范围 |
|---|---|---|
| 只查看 | 查看周边店合作 | 合作信息、批次和经营核对；不允许修改、核验或结算 |
| 营销管理 | 查看＋管理周边店合作 | 合作店、推荐人、活动、批次、推广图和独立审批；创建人与审批人分离规则不变 |
| 异常处理 | 查看＋更正周边店合作来源与权益 | 来源更正、撤销、延长等；续台仍受原有全桌查看权限控制 |
| 财务 | 查看＋审核周边店合作结算 | 佣金核对、结算与付款登记；原审批和资金规则保留 |
| 服务员核验 | 核验周边店合作优惠券＋原有桌台工作权限 | 在“现场”的已授权桌台绑定优惠，不因此获得合作管理后台 |

个人明确禁止优先于岗位授权。仅有管理/更正/结算动作权限但缺少查看权限时，不展示管理菜单；权限描述明确提示补充“查看”。权限管理员身份不会自动获得业务权限。外部合作店长继续使用官网合作后台，不授予员工权限。
