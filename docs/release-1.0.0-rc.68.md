# M-BOX 1.0.0-rc.68 性能、反馈与质量证据升级

## 目标

本候选重点修复高峰时每次操作都读取或写回整店聚合数据造成的长尾延迟，并把运行指标、TC真实覆盖度和独立质量复审纳入发布门禁。它不改变支付审批、库存事实或责任权限。

## P1整改

- 员工心跳写入独立租约表，不再改写整店revision；登录、退出和真实在线状态变化仍保留审计。
- 心跳权限校验使用轻量员工目录与租约，不再为每次心跳读取并克隆约7MB整店状态。
- 进程启动一次性载入租约，避免逐员工连接数据库。
- 中国时间转换复用格式化器，消除工作区投影中的重复高成本对象创建。
- 预约接口复用已鉴权状态，避免同一请求重复读取聚合数据。
- 同一匿名客人、同一桌次的会话轮询只持久化一次到访事件；并发请求合并，数据库幂等约束继续兜底。
- 重复点击已完成任务返回权威终态，不因旧页面或网络重试退回原状态。
- 员工首屏先展示工作区，非关键初始心跳延后执行；关键按钮保留即时反馈和失败恢复。

## 可观测性与指标

- 增加低基数规范化路由请求计数和延迟直方图，不把业务ID或令牌写入标签。
- 就绪探针公开数据库延迟、连接池总数/空闲/等待和变更队列状态。
- 增加历史日志分析工具，输出每条规范化路由的样本量、P50、P95、P99、最大值、状态码和关键错误信号。
- 指标目标和样本门槛见`docs/runtime-quality-standards.md`；样本不足不得判定通过。

## TC质量管理

- 保留213条经营基线和原始通过条件。
- 将“验收状态”和“工程覆盖度”分开，明确外部依赖、代码支持待现场验证、部分实现和真实能力缺口。
- 当前仍有67条P0/P1未通过商业发布门禁；验证版本上线不能替代真实支付、打印、弱网、应急和连续营业验收。

## 数据库

- 新增迁移`023_staff_presence_leases.sql`，按租户和门店隔离员工在线租约并强制RLS。
- 不迁移旧测试业务数据；部署候选前必须执行迁移并验证表、策略和索引。

## 发布边界

- 当前文档描述候选目标，不等于已部署或已通过复审。
- 只有全量检查、浏览器与压力测试、独立质量复审、不可变镜像候选验证、切流后指标和回滚证据全部通过，才允许替换`rc.67`验证环境。
- 商业生产还需真实支付退款、物理打印、弱网和连续至少3个真实营业晚班达到SLA。

## 本地验证结果

- `npm run check`：146个测试文件、1138项测试全部通过，lint、TC一致性、TypeScript和生产构建通过。
- `npm run test:e2e`：50条浏览器流程全部通过，覆盖客户服务、预约、推荐销售、角色权限、移动端、赠送、AI边界和即时反馈恢复。
- 支付与退单模拟：15个测试文件、165项测试全部通过；模拟不能替代星驿真实通道、退款回调和日结验收。
- PostgreSQL：23个迁移、85张强制RLS表、UTC/Asia/Shanghai时间矩阵、规范化经营投影及跨实例员工租约验证通过。
- `npm audit`：生产和开发依赖均为0漏洞。
- 双实例性能：2712次测量零失败，关键路由、连接池、队列和事件循环硬门禁通过；一个实例事件循环P95比50ms理想目标高0.266ms，保留告警。
- 独立质量复审仍为`DENY`：本地性能通过不能覆盖67条P0/P1经营阻断、阿里云资源证据、不可变镜像或真实现场验收。
- CI定义已补上双实例PostgreSQL性能作业和运行指标制品，但尚无提交级CI运行证据；本地证据不得冒充CI或云端结果。
- CI选定门禁完成后会生成绑定完整提交SHA和run id的质量证据总账，并校验测试状态、样本量、P95/P99与制品引用；通用方法见`docs/reusable-software-quality-method-v1.0.md`。

## 当前状态

- 版本：`1.0.0-rc.68`
- 状态：本地候选整改与测试中，独立质量复审结论为`DENY`，尚未部署。
- 已关闭：租约退出绕过、启动复活、跨实例KDS在线状态误判、PostgreSQL营业日时区偏移、并发就绪503误报。
- 性能通过：冷启动、缓存启动、客户会话、任务创建、任务动作、快速下单、心跳、预约、KDS、连接池及事件循环硬门禁。
- 性能告警：一个实例事件循环P95 50.266ms，略高于50ms理想目标；20并发聚合写极限观察出现快速下单P95 1587ms。
- 云端容量阻断：无法取得阿里云实时CPU、内存、OOM、容器重启与连接指标；历史双容器部署曾资源饱和。
- 验收阻断：仍有67条P0/P1未通过，且真实支付、打印、弱网和连续3个营业晚班未验收。
- 供应链：生产与开发依赖审计均为0漏洞；因最新版`@capacitor/assets 3.0.5`仍携带无修复的critical/high传递依赖，本候选移除图标再生成工具并保留现有iOS资产，上游修复前不重新生成安装包资产。
- 发布动作：可以继续形成提交和CI候选证据，但不得替换阿里云`rc.67`或批准商业生产，直到全量测试、云端资源核验及P0/P1现场门禁关闭。
