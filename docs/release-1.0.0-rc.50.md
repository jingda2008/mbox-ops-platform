1. 将陆家嘴店2026真实座位图接入桌台布局页。
2. 建立61个唯一正式桌位：VIP1-VIP5、666、888、L01-L07、A01-A08、B01-B08、C01-C07、S01-S07、W01-W17。

## 数据迁移

- 桌台采用增量迁移，不重置订单、支付、任务、会员、库存、预约和员工数据。
- 所有既有桌保留现场状态、人数、开台时间和已配置容量；图面估算只用于新建桌位。
- 旧I01-I03进入过渡区：营业桌继续服务，空闲旧桌暂停使用，不生成新的正式桌码。
- 新增分区和岗位责任范围仍可在后台继续调整。
- 本版不新增SQL结构迁移。
