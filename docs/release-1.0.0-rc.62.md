# M-BOX 1.0.0-rc.62 员工手机端岗位简化升级

## 岗位工作入口

- 将岗位高频入口与完整授权模块分离，每个岗位首页和手机底部只显示二至四个常用入口。
- 低频但已授权的功能继续保留在“更多”菜单中，不减少员工的合法工作能力。
- 增加舞台、新媒体、技术和营销岗位的独立工作入口与现场指标。

## 现场桌台与移动操作

- 服务、传送、吧台、厨房等执行岗位默认聚焦本人负责且正在营业、已预约或需要关注的桌台。
- 其他营业桌和空桌保留为按需展开，候补员工仍可查看并处理允许跨区完成的现场服务。
- 手机端增加固定岗位导航，压缩顶部、指标、快捷操作和空状态区域，减少工作中滚动和来回切换。
- 修正服务员负责桌台指标，空桌不再被计入当前营业责任桌数量。

## 权限可见性

- 库存、收银和会员权益页面仅展示当前员工有权执行的标签和操作。
- 页面简化不替代后端授权；所有写操作继续执行服务端岗位、权限和审计校验。
- 店长、管理员和老板仍可通过完整授权入口进行监督、配置和异常处理。

## 测试与风险边界

- 单元测试覆盖岗位首页、主入口与完整入口分离、岗位识别和权限泛滥回归。
- 浏览器测试覆盖手机底部导航、桌台聚焦、空桌展开以及库存、收银、会员权益权限裁剪。
- 本次没有数据库结构迁移，不修改订单、支付、退款、库存、预约和既有桌次数据。
- 当前真实微信、星驿支付、退款、物理POS和日结仍未完成生产联调。
- 213条经营TC仍有66条发布阻塞项，本版本只批准阿里云验证环境使用，不代表正式商业生产验收完成。

## 发布与回滚

- 发布目标：阿里云验证环境。
- 发布镜像必须来自主分支成功CI的不可变镜像资产。
- 候选容器通过就绪、提交SHA、镜像摘要和数据库投影一致性验证后才能切流。
- 异常时回滚至上一已验证容器。
