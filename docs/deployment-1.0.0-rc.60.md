## 本次能力

- 客人快速选择的不同答案会改变主推和对比商品，不再被固定价格梯度覆盖。
- 员工协助点单可选择立即付款或挂单消费；挂单不生成支付意图，但保留桌账应收。
- 退款申请明确记录订单处理和应收处理结果，并继续执行人工审批、职责分离和额度校验。
- 恢复待收只恢复原退款商品和金额；同一退款不能并发生成多笔重收单。
- 重收失败或过期后可以重试，重收成功前不能结台。
