# M-BOX AI值班经理 Qwen 接入说明

## 接入目标

AI值班经理通过阿里云百炼华北2（北京）业务空间专属域名调用Qwen。模型只负责理解自然语言并生成结构化计划，实际操作仍由M-BOX服务端校验员工身份、权限、现场状态、人工确认和审计规则。

退款、折扣、赠送、改价、库存审批、结台、转桌、配置发布和权限变更等高风险动作继续进入人工工作台，模型不得直接提交或声称完成。

## 运行配置

```dotenv
MBOX_ASSISTANT_PROVIDER=qwen_openai
MBOX_QWEN_API_KEY=<该业务空间的百炼API Key>
MBOX_QWEN_MODEL=qwen3.7-plus
MBOX_QWEN_ENDPOINT=https://ws-stvr4q76b04g9g7g.cn-beijing.maas.aliyuncs.com/compatible-mode/v1/chat/completions
MBOX_ASSISTANT_HTTP_TIMEOUT_MS=20000
```

API Key只允许保存在服务端秘密配置中，不得写入Git、前端构建、日志、二维码或员工设备。

## 上线顺序

1. 在百炼华北2（北京）创建该业务空间的专用API Key。
2. 权限限制为验证服务器公网IP和实际使用的Qwen模型。
3. 在候选容器设置Qwen配置，不改当前在线容器。
4. 验证健康检查显示`assistant=qwen_openai`和`assistantModel=qwen3.7-plus`。
5. 用店长、服务员各执行咨询、开台、定时派单和退款引导场景。
6. 核对业务状态、执行记录和审计事件后再切换流量。
7. 保留原Gemini配置作为短期回滚通道，稳定观察后再下线。

## 验收重点

- 自然语言回答不声称未发生的操作已经完成。
- `L01开台`必须追问实际人数，不能默认2人。
- `5分钟后让Tom给K2加水`生成定时任务，员工按权限确认后执行。
- 无权限员工不能通过模型绕过按钮和服务端权限。
- 退款只导航到人工流程，不由模型提交、批准或调用支付渠道。
- 模型超时、限流、余额不足或结构异常时，页面给出可恢复提示，快速命令仍可使用。
- 请求和日志不包含API Key、PIN、门店口令或客户敏感凭证。

## 回滚

候选验证失败时保持在线环境不变。切换后需要回滚时，将模型配置恢复为原Gemini通道并重启候选容器验证，再切换流量；业务数据库和已经发生的经营事实不随模型回滚。
