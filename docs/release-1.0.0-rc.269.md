# 1.0.0-rc.269 兴趣卡专属菜品图片

持卡人可以看到专属菜品，但上传图片接口只认可普通菜单可见标记，导致原图和缩略图404。本版让图片引用复用既有持卡可见条件，保留菜品和购买权限、定时窗口、旧卡门槛，以及普通卡关闭新申请后已经授予的权益。

范围仅服务端读取及测试，无数据库迁移（schema282），不改线上商品、价格、卡或权限。微信小程序无需重新上传提审；支付宝不上传、不提审、不发布。

专项15项及相关62项隔离测试已通过，正式CI/发布状态另行记录。见[问题与验证记录](card-menu-images-20261024.md)。发布后逐项验证WMLS的11张原图及11张缩略图，手机菜单重新进入另验。

应用回滚候选为rc268，使用标准发布/回滚流程，不回写经营数据。

发布门禁同时要求修复既有依赖安全问题：仅兼容更新fast-uri、fastify、zod锁版本，不变更公开接口或业务规则。
