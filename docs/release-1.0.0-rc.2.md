# M-BOX Ops Platform 1.0.0-rc.2

发布日期：2026-07-17

## 经营规则

- 门店默认营业时间调整为 12:00 至次日 02:00。
- 演出排班与门店营业时间解耦，新排班仍默认从 20:30 开始。
- 下午无演出时，客户页面显示咖啡与轻饮营业状态和今晚首场时间。

## 点歌流程

- 支持普通点歌、下一位歌手提前预约、当前歌手延长演出协商三种请求。
- 当前轮次剩余时间无法容纳歌曲时，仍可提交给服务员和歌手协商。
- 下一位歌手资料展示当日歌单；歌手到场前可按排班策略预约。
- 所有请求均先由现场确认歌手、时间和费用，再使用现金或物理 POS 收款。

## 版本与审计

- 演出排班按版本递增，并使用期望版本阻止旧页面覆盖新排班。
- 点歌请求保存排班版本、歌单价格版本和请求类型快照。
- 每次排班发布写入审计记录，既有请求不受后续配置修改影响。
