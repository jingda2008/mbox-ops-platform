# 门店后台 1.0.0-rc.316

本次修复同店已验证手机号重复入会和历史双会员的核验、审批及原券读取。沿用 rc.315 的数据库版本 372。营业库的会员关系在门店员工提交并经另一位员工审批后才会变更。

运维在门店私有配置中以 `MBOX_DUPLICATE_MEMBERSHIP_REVIEW_PAIR` 指定经核实的旧卡、保留卡内部记录编号，以逗号分隔。空配置关闭个案入口。上线后先用只读方式核对服务版本及个案状态，再由门店员工通过「账户恢复」办理，顾客用原微信核对会员号和原券。此次仅切换门店后台。

11 月 26 日北京时间 02:53，生产后台切换通过并恢复对外服务，数据库仍为 372。备份与部署证据均已归档，公网四个入口通过。上线后定向检查发现发布脚本丢弃了个案配置，门店个案仍未显示，修复跟进于 rc.317。
