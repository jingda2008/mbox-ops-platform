# 财务仪表盘与单金额录入

更新时间：2026-10-21 01:54 CST

## 已验证的问题和改动

- 代码原有查看和更正能力，但藏在经营页面折叠区，记录又在表单后；现在直接显示财务仪表盘，默认费用总览，可筛选日期、搜索名称/编号/往来方/备注/金额并查看详情。
- 原前端把金额与税额分开录入。新界面和请求使用单一金额，按输入金额记录，不做税额计算；原总金额保持，历史旧字段保留供旧客户端兼容，不重算历史账目。
- 保存后回到总览；录入或更正的费用与当前日期筛选不重叠时，自动转到该费用期间。读取失败隐藏汇总，不将失败显示成零。
- 更正记录保留原记录、原因和操作审计，合计仅纳入未被替代的有效记录。可勾选查看历史记录。汇总是匹配费用的整笔金额，不是期间分摊费用或现金流水。
- 周期规则支持修改金额、名称、分类、成本中心、付款处理、收款方和备注。保留原周期及日期；调整周期需结束原规则后新建。修改只影响尚未生成费用，包括未补记的历史期间；已生成费用从总览单独更正。后台校验原版本，防止覆盖他人修改，生成和修改按规则串行锁定。
- schema271只给现有和新建FINANCE角色增加commercial.cost.view/manage，保留其他既有授权与个人禁止项。工资和采购来源的创建、更正仍要求对应权限，不能借普通费用权限修改。
