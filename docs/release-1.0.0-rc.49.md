# M-BOX 1.0.0-rc.49 运营配置保存修复

## 本版完成

1. 修复部分历史服务类型没有“对客可见”字段时，保存运营配置草稿返回503的问题。
2. 未设置“对客可见”时继续保持未设置，不再向运行状态写入不能序列化的空字段。
3. 明确设置为显示或隐藏时仍按管理员选择保存，不改变现有业务含义。
4. 配置保存失败不会清理、覆盖或重置门店当前数据。

## 数据迁移

- 本版不新增数据库迁移。
- 不批量改写商品、订单、桌台、任务、排班或员工数据。
- 修复只作用于后续配置草稿保存过程。

## 发布验证

- 新增与线上失败请求同结构的配置保存回归测试。
- 保存完成后对完整运行状态执行PostgreSQL序列化校验。
- 发布时继续执行全部代码、浏览器、数据库和镜像门禁。

## 发布边界

本版是验证环境的运行稳定性修复。真实支付、退款、打印机、KDS设备和门店岗位验收状态不变。
