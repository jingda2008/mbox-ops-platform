# 全员通用：登录、点击反馈与交接

## 每日第一次登录

1. 打开门店系统地址。
2. 输入当天门店验证口令。当天同一设备验证成功后，切换员工不需要再次输入门店口令。
3. 选择本人姓名，输入本人四位 PIN。
4. 核对首页姓名和岗位。显示错误时立即退出，不要继续操作。

PIN只代表本人身份，不得发群、写在平板背面或交给同事代操作。连续错误5次，同一来源会锁定15分钟。

## 按钮反馈怎么判断

- 点击后按钮进入忙碌、页面出现成功提示或状态改变，才表示服务端已经收到。
- 没有反馈时不要连续猛点。先等3秒，再刷新一次查看状态。
- 支付、退款、赠送、库存调整不能因为页面慢就重复提交。
- 客人端红色对号表示需求已收到；员工端仍要完成“接单 -> 到桌 -> 完成”。

## 共享平板切换员工

1. 先查看是否有未同步离线动作。
2. 有未同步动作时，由原员工恢复网络并同步，或向接班人逐项交接。
3. 点击切换员工，选择新员工并输入新员工自己的PIN。
4. 新员工核对首页“我的任务”和责任桌台。

案例：Tom平板断网后完成了L01加水，但还没有同步。此时不能直接切给Jerry，否则Jerry看不到完整现场事实。Tom应先恢复网络，确认任务状态变为已完成，再切换。

## 每项工作完成标准

| 工作 | 完成标准 |
|---|---|
| 客人服务 | 到桌、完成动作、必要时确认客人已经收到 |
| 出品 | 制作完成后交给正确取送人，不能只口头说“好了” |
| 收款 | 系统状态、支付凭证和实际金额一致 |
| 退款 | 原支付、退款金额、商品分摊、渠道流水和审批完整 |
| 投诉 | 处理动作、补偿、客人反馈和负责人都有记录 |
| 交班 | 未完成事项有桌号、当前状态、接手人和截止时间 |

## 绝对禁止

- 不得用别人的账号操作。
- 不得把“支付处理中”口头说成“已付款”。
- 不得把已制作直接点成已送达。
- 不得为了清空红点虚假完成任务。
- 不得删除或修改记录来掩盖超时、投诉、错单和差异。
