## 组合场景

- 同一优惠并发扫码绑定：相同键/不同键都复用同一张券、同一绑定；整桌转移后原 HTTP 回执仍可恢复；同一报价并发消费只生成一个订单。
- 两张八五折，客组上限40元：首次优惠30元；拆桌后两桌共用余下10元；目标桌再转桌不重置。目标桌安全撤单释放一次，重新消费后旧桌报价失效。
- 上述客组原订单退款处理中：计佣冻结；退款成功后并发三次核算，净实收140元、累计佣金14元，只产生所需差额；优惠仍占用40元。
- 赠品售价10元与抵扣10元竞争客组15元上限：并发只允许一项先成功，另一项失败/报价失效且不留多余订单。赠品失败时原库存承诺仍为 reserved。
- 延续已有覆盖：拆桌存在未结订单则拒绝；异来源客组合桌拒绝；退款后已付佣金形成负余额；未知付款/原回执丢失禁止创建新付款。
